# APPT zero-order boundary: exact physical loss coordinates

Current status: complete author manuscript and finite author controls;
independent ordinary review pending. This package is private preparation
and has not been placed in the repository written-proof index.

[PAPER.md](PAPER.md) proves a uniform relative nearoptimality criterion
for every actual APPT density as m grows and nonnegative real orders tend
to zero, with arbitrary n>=m and arbitrary phase-parameter oscillations.
Positive orders use three exactly nonnegative losses from the actual
least eigenvalue and deflated pivot-normalized variance. The zero endpoint
uses a separate rank indicator. An actual family at a collapsing moving
tie realizes every variance limit in [0,1].

This credits the existing value formula and actual-state estimates. It
does not count a new major problem, solve every spectral body-law window,
give exact finite optimizers or add a Lean proof. See
[the map](THEOREM_MAP.md), [credited source binding](CREDITED_INPUTS.json),
[bounded literature scope](PRIMARY_SCOPE.json) and
[research record](RESEARCH_LOG.md). The standalone checks use exact
compressed physical integer spectra and arbitrary-precision diagnostics;
no sampled calculation is treated as an optimization over all APPT states.
