# Verification status

## What was checked for v1

- Complete proof texts were read, including the upstream arguments used by each extension.
- Separate adversarial mathematical reviews checked the transport midpoint and centering steps, limiting targets and Gaussian sharpness; the quadratic sieve's arithmetic hypotheses, entropy conditioning, scale ordering and exception restoration; and the geometric construction's scale quantifiers, covering constants, finite witnesses and compact assembly.
- Each PDF was rebuilt and every rendered page inspected. Final build logs contained no undefined references/citations or overfull boxes.
- SHA-256 hashes identify the exact released files.

## What these checks do not establish

- No external human peer review is claimed.
- No complete Lean/Comparator replay was run for these extensions. Upstream formalization files do not automatically cover modified theorems.
- A PDF build checks typesetting, not mathematical truth. Adversarial reading does not guarantee absence of every possible error.
- Literature comparison is ongoing; publication priority is not certified.
