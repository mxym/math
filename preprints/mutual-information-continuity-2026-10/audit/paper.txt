               A ternary counterexample to a proposed
                    mutual-information continuity bound
                                            Yongxian Zhang∗

                                             8 October 2026



                                                  Abstract
           We give explicit classical 3 × 3 probability tables at total variation distance ε whose
        mutual-information difference violates the general proposed bound in arXiv:2408.15226v2,
        Eq. (106), for every 0 < ε ≤ 1/16. The same construction defines commuting quantum states.
        Both marginals change: the version requiring one equal marginal is unresolved by this note.
        The complete classical counterexample has an independently verified Lean proof; the quantum
        diagonal embedding and the necessary-leading-coefficient corollary are established by written
        arguments.


1       Exact target and scope
Mario Berta, Ludovico Lami and Marco Tomamichel, Continuity of entropies via integral
representations, propose the general mutual-information continuity inequality
                                                                                     
                        |I(A : B)ρ − I(A : B)σ | ≤ h(ε) + ε log min{d2A , d2B } − 1                     (1)

for nearby bipartite states whose trace distance is at most a sufficiently small ε. This is Eq. (106)
of arXiv:2408.15226v2 and Eq. (54) of v1. The surrounding discussion first considers applications
with one equal marginal, then proposes this more general inequality without that restriction.
    The construction below refutes the general version with different marginals at arbitrarily
small distances. Both marginals change. It does not resolve the version in which one marginal
must remain equal.
    All logarithms are natural. Changing the logarithm base rescales both sides and does not
alter the strict violation. Write

                          h(ε) = −ε log ε − (1 − ε) log(1 − ε),       0 log 0 = 0.                      (2)

For a probability vector p, let H(p) = − i pi log pi . For a joint probability table R, let RA and
                                              P

RB be its row and column marginals and set I(R) = H(RA ) + H(RB ) − H(R).

4    Strict violation at arbitrarily small distances
Here dA = dB = 3, so the proposed right-hand side is h(ε)+ε log 8. The signed mutual-information
difference minus this bound is
                                                                
                       I(Pε ) − I(Qε ) − h(ε) + ε log 8 = h(ε) − ε log 16.                    (11)

For 0 < ε ≤ 1/16, monotonicity of the logarithm gives

                                            −ε log ε ≥ ε log 16.                              (12)

Since 0 < 1 − ε < 1, also
                                         −(1 − ε) log(1 − ε) > 0.                             (13)
Adding these proves h(ε) − ε log 16 > 0. The signed difference is positive and equals its absolute
value. Thus, for every 0 < ε ≤ 1/16,

5    Necessary leading coefficient
The exact loss 2h(ε) − ε log 2 implies that no modulus of the form c h(ε) + Cε, with finite fixed
C and c < 2, can bound arbitrary ternary mutual-information differences near zero. Indeed,

so (2 − c)h(ε) − ε(log 2 + C) > 0 for sufficiently small positive ε. This is a lower bound on the
necessary leading coefficient; it does not establish an exact optimal finite-distance modulus.


6    Formal verification, reproduction and scope
The complete classical probability-table counterexample is formalized in Lean 4.34.1. Its
public package is fixed to commit 363224e0f7cf1d7ea7b4ed2546f8ed372da7b04c, directory
formalizations/mutual-information-continuity-counterexample. The definitions are ac-
tual finite probability tables, Shannon entropy, row and column sums, mutual information and
half-L1 total variation. No entropy formula is supplied as an assumed hypothesis.
    The two main endpoints in namespace MutualInformationCounterexample are
     counterexample_family
     counterexamples_arbitrarily_close.

The first proves strict violation for every 0 < ε ≤ 1/16; the second proves valid witnesses in
every positive-distance neighborhood. The independently compiled LiteralSemantics.lean
also checks that both marginals change. The fixed verification records report fresh compilation,
all 38 owned declarations and their complete 16,161-declaration dependency closure replayed in an
initially empty kernel at trust level zero. The only logical axioms are propext, Classical.choice
and Quot.sound; an invalid-proof control was rejected. These are prior execution records, not a
claim that this editorial preparation reran Lean.
     For reproduction, read the fixed package’s README.md, case.json, lake-manifest.json
and reproduce.py. The driver requires the matching compiler and nine pinned dependencies
with their build caches; its explicit command builds a new owned module and performs the
kernel audit. It does not automatically install those prerequisites. The immutable v2 Release
contains source, full replay records, the compressed dependency graph, source binding and asset
checksums. The earlier written v1 Release is preserved unchanged.
     The quantum diagonal embedding in Section 2 and the necessary coefficient bound in Section 5
remain written arguments, rather than formalized quantum spectral-function or asymptotic
theorems. The equal-one-marginal question remains unresolved by this paper. No exhaustive
novelty or historical priority conclusion or external human peer-review certificate is asserted.
