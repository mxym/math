# A sharp Gaussian first-moment inequality for every prescribed mass vector

Yongxian Zhang (张永贤), South China University of Technology.

[PDF](paper.pdf) · [Self-contained TeX ZIP](paper-source.zip) · [Original proof and certificates](../../../research/gaussian-prescribed-mass-centroid-ellipsoid/README.md)

The inequality uses the mass-dependent label metric from the established perimeter-profile Hessian. It does not assert the false unweighted prescribed-mass simplex conjecture, and does not give the sharp value in fixed lower dimensions. Its full analytic endpoint is a written proof using the published multi-bubble theorem; Lean coverage is partial.

This signed article edition retains the earlier proof. Original archive: https://doi.org/10.5281/zenodo.23248386.
