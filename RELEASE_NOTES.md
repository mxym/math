# Source-slice notes

- Author proof and three checkers are reproduced byte for byte from `mxym/math` research commit `fd2cc6ef13127d07880a9d411978f96fb2435d61`. The separately authored audit script is reproduced byte for byte from its independent audit handoff.
- Mathematics and scope: unrestricted complex positive semidefinite order eleven, including the equality characterization; 12/13 only the stated small-entry caps. The earlier order-seven/order-nine replay is a supporting induction ladder, not a priority claim.
- The paper credits [McBee's order-ten theorem](https://hexagonmath.org/pdf/2611.01163v1), the two-border proof geometry, and the two lower-order polynomial schedules. His [upstream exact code at 203f6fd](https://github.com/coracle-us/conjectures/tree/203f6fdc6a007edcfe2fcbce80208d5746690468/results/chollet-permanent-through-10) was also replayed unchanged, with 480 checks passing, when preparing the research proof. This optional cross-reference is not a required dependency and the upstream program is not bundled.
- The independent author-external audit examined the analytic lemmas and uses separate executable arithmetic on the same analytic input. The small region is covered in the linear coordinate \(s/E\) using quarter-width cells instead of the author's adaptive \(\sqrt{s/E}\) partition. The large region uses unnormalized factorial monomials and an explicit path-matching sum for each leading principal minor instead of the author's tridiagonal elimination; it uses the same fixed rational schedule knots. It does not independently search for the schedule, and does not claim a different analytic proof.
- All four bundled scripts were rerun in ordinary Python 3 with assertions enabled, using the exact frozen bytes. [REPLAY.txt](REPLAY.txt) gives the output. [MANIFEST.sha256](MANIFEST.sha256) covers all artifacts except the manifest itself.
