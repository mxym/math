# Improved Constant Bounds for Nonunimodal Independence Polynomials at Prescribed Independence Number

The lower bound on the normalized excess order improves to 2.433302879 and the connected upper bound to 6.212567439. This does not determine the limiting constant or improve the cograph-specific upper bound.

This is a follow-up to [DOI 10.5281/zenodo.24615591](https://zenodo.org/records/24615591), not a replacement for the published order result. See [the proof](IndependencePolynomialConstantInterval.md). The new upper construction is connected but need not be a cograph. Run `bash replay.sh` for the exact finite checks.
