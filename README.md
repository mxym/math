# Fuglede for odd cyclic groups of order p²q²r with r > min(p,q)

The spectral-to-tiling implication is proved for the stated group family. The reverse implication uses Łaba–Londner. The included odd prime-power elimination theorem is proved directly. The case where r is the smallest prime and the unrestricted conjecture are not asserted.

Author: Yongxian Zhang. AI-assisted proof development and internal verification; no claim of external peer review or priority.
