# The Minimum Order of Nonunimodal Independence Polynomials at Prescribed Independence Number

With independence number fixed at r, the minimum graph order for a nonunimodal independence polynomial is r + Theta(sqrt(r)), both among all graphs and among connected graphs. The constants in the bounds are not claimed optimal.

See [the proof](IndependencePolynomialPrescribedRankGrowth.md). The exact finite examples and earlier ranks are separate; see [the previous sixteen-vertex results](https://zenodo.org/records/24614383). The replay checks exact coefficient ratios, second differences, and a connected double-peak witness; the asymptotic proof is analytic.
