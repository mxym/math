# The Sharp Four-Thirds Width Ratio for Exact Gaussian Discretization on Rectangular Lattices

The optimal asymptotic ratio of squared widths is 4/3 for exact Gaussian conversion on fixed rectangular lattices. All fixed lattices satisfy the necessity; the skew-lattice sufficiency and additive threshold remain open.

Read the [necessity](exact-gaussian-four-thirds-obstruction.md) and the [matching rectangular-lattice construction](exact-gaussian-four-thirds.md) together. This is for an unknown lattice-point center, an exact statistical comparison, not efficiency or a scheme claim. The earlier inequalities described as open in the construction are updated by the necessity manuscript.
