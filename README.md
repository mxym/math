# A rank-three reduction for five-point quartic energy

The maximum, over all ambient dimensions, of the optimal weighted quartic energy for five-point 60-degree spherical codes is attained already in three dimensions. This is a sharp scope reduction for the extremal problem, not a proof that the resulting optimum equals 1/4 or that any general kissing number is exact.

Run `python3 verify-kissing-five-point-rank-reduction.py` for the exact finite structural checks. Pinned research commit b951d2ba0c68c002beb43f9e24a55edeb3f23097.
