# Eventual Inclusion Monotonicity of Expected Random Hull Volume

**Yongxian Zhang (ORCID 0009-0000-3864-3536).** AI-assisted working paper, independently checked internally but not externally peer reviewed.

For every dimension there is a sample-size threshold independent of the two nested convex bodies. Above it, the expected unnormalized volume of the random sample hull is strictly larger in the larger body, with a quantitative lower bound proportional to the difference of the ambient volumes. This [proof, source and check archive](research/eventual-inclusion-hull-volume/README.md) contains the result merged in [#209](https://github.com/mxym/math/pull/209), with the threshold question credited to Meckes and Reitzner as recorded by Rademacher and restated by Beermann–Reitzner. It does not claim an optimal threshold, all-sample monotonicity, or a comparison of normalized volume fractions.
