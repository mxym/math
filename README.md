# Linear Extension Complexity of the Regular 2p-gon under Prime-Order Rotations

For every odd prime p, a regular 2p-gon requires exactly 2p facets in a linear extension in which each rotation of the order-p subgroup lifts to an affine automorphism. A coherent choice of lifts is not required. This is a theorem about symmetry-preserving extensions, not ordinary extension complexity.
