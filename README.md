# Effective determination of addition-chain stability

This archive gives a decision algorithm for ℓ-stability for ordinary positive addition chains, answering the effective decision question explicitly posed by [Harry Altman in Internal Structure of Addition Chains: Well-Ordering](https://arxiv.org/abs/1409.1627). It also computes the stable length and least stabilization exponent, with a finite bound and a separate star-chain variant. It does not claim an efficient practical algorithm or settle the Scholz–Brauer conjecture.

See [the proof](FactorEffectiveAdditionChainStability.md). Run `python3 verify_factor_addition_chain_stability.py` for the independent reproducibility checks. `SHA256SUMS` gives the original proof and verifier hashes.
