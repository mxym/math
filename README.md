# A quadratic speed bound for two-entry Lonely Runner modifications

Yongxian Zhang, ORCID [0009-0000-3864-3536](https://orcid.org/0009-0000-3864-3536).

Answers the polynomial-bound alternative in Yuhan Zhang’s Question 8.2 for two replacements: for n at least 5, every configuration with loneliness at most 1/n has maximum speed at most 130(n−1)^2. Also classifies the case in which one deleted speed is 1: only the scaled consecutive set {2,4,6,8} at n=5. The full Lonely Runner Conjecture and modifications of three or more entries remain open.
