# Sharp internal sunflower extraction in capped triple systems

**Yongxian Zhang** (ORCID [0009-0000-3864-3536](https://orcid.org/0009-0000-3864-3536)). Version 1.0.0. AI-assisted mathematics and internal verification; no external peer review claimed.

For a tripartite triple system with two injective pair projections and remaining pair multiplicity at most \(1\le D\le m\), the sharp worst-case retention orders are \(\Theta(m^{-3/2}D^{-1/2})\) for nonempty intersections only, and \(\Theta(m^{-2}D^{-1})\) for every intersection, including the empty set. All witnesses are \(m\)-petal sunflowers inside the retained family. The unpartitioned linear triple case is given separately. The unrestricted [Janzer–Jin–Sudakov–Wu question](https://link.springer.com/article/10.1007/s00493-026-00222-1#Sec6) is not resolved here.
