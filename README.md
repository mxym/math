# Common Minor Laws for Distinct-Support Givens Circuits and Alternating Rings

For Givens circuits using each coordinate pair at most once, we classify exactly which ordered support graphs have a common all-orders minor law for every choice of gates. We also characterize alternating rings at fixed gates by a phase-sensitive Walsh feasibility test.

The [classification](MarcusDistinctSupportClassification.md) is universal over gate choices. The [alternating-ring theorem](MarcusAlternatingRingPhaseCriterion.md) determines one fixed circuit's feasible common law, including the exact equal-angle interval. The [forest lemma dependency](MarcusForestedGates.md) and all six exact scripts are included. The two theorems concern the common minor-law certificate, not a disproof or a proof of the general Marcus–de Oliveira conjecture, and not repeated supports.
