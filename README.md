# The anchored cross-product inequality for linear extensions

We prove the all-index anchored inequality F(1,1)F(i,j) ≤ F(i,1)F(1,j) for all finite posets, as asked by Brightwell, Felsner, and Trotter in 1995, §3, p. 338. A filter-rank induction couples the first elements of nested filters and feeds into the original four-functions argument. A separate appendix extends the anchor to the two minimum feasible gaps. This does not settle the general adjacent cross-product conjecture at arbitrary indices. The archive contains the analytic proofs and finite checks, source comparisons, and internal reviews; it is AI-assisted and not externally peer reviewed.
