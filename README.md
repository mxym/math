# Thirty-Point Conditional Positivity for a Spherical Quartic and a 58-Point Counterexample

For at most thirty unit vectors the quartic kernel is positive on mass-zero directions. The worst 60-degree mixed energy through thirty points is attained in dimension n minus 2. An explicit 58-point code violates the positivity condition, not the rank conclusion.

Read [the 30-point argument and 58-point construction](KissingThirtyPointConditionalPositivity.md) with the [bipartite stress mechanism](KissingMixedEnergyBipartiteStress.md). This does not determine a kissing number or the first failure between 31 and 58. The scripts use the Python standard library.
