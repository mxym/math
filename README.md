# Exact alternating quantum max-flow on the periodic eight-cycle

Yongxian Zhang · November 2026 · Version 1.0.0

For the periodic eight-cycle with identical site tensors over the complex numbers and common physical and bond dimension q, the maximum odd-versus-even flattening rank is:

- 12 for q = 2;
- q^4 - 1 for q congruent to 3 modulo 4;
- q^4 in every other positive dimension.

The new result is the all-even-q proof for q at least 4. The odd-dimensional proof and the previously archived binary argument are included for a complete scoped record. This does not claim a result about arbitrary cycle lengths, cut patterns, or unequal dimensions.
