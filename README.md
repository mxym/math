# Sharp angular spacing for positive circle quadrature

When the 2m+1 nodes have adjacent gaps at least π/(m+1), nonnegative weights reproduce the first m ordinary harmonics and, with a separate weight system, the first m even harmonics on projective axes. The bound is sharp for each m; the proof gives the exact boundary support rule. In particular the optimal weighted quartic energy of a planar five-point code at minimum angle sixty degrees is 1/4. No higher-dimensional kissing-number bound is claimed.
