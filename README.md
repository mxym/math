# The smallest graph with a nonunimodal independence polynomial

The minimum order is 15 for simple graphs and for connected simple graphs. The explicit witness has independence coefficients (1,15,14,16,9,2). The lower bound uses the Frohmader/Frankl–Füredi–Kalai clique-vector bounds plus an exact finite counting argument, not enumeration of graphs.
