# The parity spectrum of nonantipodal odd-harmonic designs

This is a full answer to the even-cardinality question on slides 12–13 of [Munemasa's presentation](https://researchmap.jp/munemasa/presentations/51226116/attachment_file.pdf). For harmonic orders 1,3,…,2m−1, the minimum even size is 4m+2 on the circle and 4m in ambient dimension at least three. It credits the known odd-size result and Misawa's 4m construction. See the proof for the dimension-six single-order extension and precise definitions.

Run `python3 verify-odd-harmonic-parity.py` to replay the finite construction and algebra checks. Original research commit: 4095fa6c5d1edd9086efaffe1d71593123ed5100.
