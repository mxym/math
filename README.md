# The Exact Smoothing Cutoff for a Three-Factor Cyclotomic Tensor

For fixed positive side ratios and fixed positive error tolerance, the three-factor tensor smoothing width has exact squared-width offset minus log c-star. This does not identify the shrinking critical window or a total-variation cutoff.

Read [the cutoff proof](triple-cyclotomic-smoothing-cutoff.md) with the [macroscopic theta companion](triple-cyclotomic-macroscopic.md). The subcritical theta expansion, combined with the supercritical free energy, determines both sides of the fixed-error smoothing cutoff.
