# Exact internal sunflower extraction with capped pair codegrees

Yongxian Zhang · November 2026 · Version 1.0.0

For simple 3-uniform families with all pair codegrees at most \(D\), where \(1\le D\le m\), this archive gives the sharp worst-case retained fraction for both forms of the internal \(m\)-petal sunflower condition:

- \(\Theta(m^{-3/2}/D)\) when witnessing only nonempty realized intersections.
- \(\Theta(m^{-2}/D)\) when also witnessing realized empty intersections.

The new nonempty upper construction still has one injective pair projection and one part with fewer than \(m\) color neighbors at every vertex. At \(D=m\) it rules out the previously proposed stronger \(m^{-2}\) retention in that class. The unrestricted full question of Janzer, Jin, Sudakov, and Wu is not settled.

Start with [nonempty witnessing](InternalSunflowersGlobalCapSharpNonempty.md), [full witnessing](InternalSunflowersGlobalPairCap.md), and the supporting [linear case](LinearTripleInternalSunflowers.md). All constants are uniform in \(D\). AI-assisted and internally checked; no external peer review claimed.
