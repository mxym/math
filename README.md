# The Minimum Order of a Nonunimodal Independence Polynomial at Independence Number Nine

At independence number nine, the exact minimum order of a graph with a nonunimodal independence polynomial is nineteen, also when connectedness is required.

See [the upper witness and final exclusion](IndependencePolynomialRankNineMinimum.md) and the [previous finite envelope](IndependencePolynomialFiniteFollowups.md). This supplements the separate [asymptotic result](https://zenodo.org/records/24615591). The archive includes the prior dependency and two independent enumeration checks. Run `bash replay.sh` with Python 3; the full prior envelope takes longer than the local check.
