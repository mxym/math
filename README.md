# Finite Moments Do Not Make Tukey Depth Identify a Probability Law

**Yongxian Zhang (ORCID 0009-0000-3864-3536).** AI-assisted working paper, not externally peer reviewed.

Read the [proof, internal review and source comparison](research/finite-moment-tukey-depth-counterexamples/README.md). This isolated snapshot contains the reviewed project from [merged work #187](https://github.com/mxym/math/pull/187). For every dimension at least two and any specified finite moment order, the paper constructs distinct strictly positive smooth densities with identical mixed moments through that order and identical Tukey depth pointwise. The pair may depend on the order; no compact-support or common all-moments example is asserted.
