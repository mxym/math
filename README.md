# The internal sunflower problem for all triple systems

Yongxian Zhang · November 2026 · Version 1.0.0

This archive proves the sharp retained order of m^(-3) for simple 3-uniform systems, with every realized intersection including the empty set witnessed inside the selected subfamily by an m-petal sunflower. It answers exactly the k=3 case of Janzer–Jin–Sudakov–Wu §6; no assertion for larger k or for the classical sunflower conjecture. The proof develops a bounded-projection reduction, weighted peeling, and a two-stage sampling argument. The complete tripartite construction gives sharpness.

Start with [the theorem and proof](Proof.md). The three auxiliary workbench notes below are reproduced with their own scope for replay. Their narrower statements and open-status remarks are historical, and only the named lemmas are used here. AI-assisted and internally checked; no external peer review claimed.
