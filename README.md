# Extremizers and independence numbers for small nonunimodal graphs

This companion follows the [previous minimum-order release](https://github.com/mxym/math/releases/tag/independence-polynomial-minimum-order-v1.0.0), whose proof and checker are included for reproducibility. The additions are the unique order-15 isomorphism class (75,075 labeled copies), the order-16 independence-number spectrum, and exact fixed-independence-number minima. This is not an order-16 list of all isomorphism classes. Read the Order15Uniqueness and Order16Ranks manuscripts first. Run the corresponding Python verifiers from the archive root. The two stand-alone JavaScript scripts provide separately implemented checks.
