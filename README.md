# The Sharp Four-Thirds Ratio for Exact Gaussian Conversion on Every Fixed Lattice

For every fixed full-rank lattice, the infimum feasible squared output width for exact center-independent Gaussian discretization is 4/3 times the squared input width, up to lattice-dependent additive constants.

Read the [construction](exact-lattice-gaussian-four-thirds.md) and the [matching obstruction](exact-gaussian-four-thirds-obstruction.md). The earlier [rectangular-lattice archive](https://zenodo.org/records/24615445) contains the original general lower bound but only the old upper bound in the rectangular case. The current upper theorem is for every fixed full-rank lattice, with constants depending on the lattice. The exact endpoint, optimal additive constant and efficiency are not decided.
