# Stewart’s existence conjecture for three perfect powers in square-root intervals

A square, a cube, and a fifth power occur in infinitely many intervals from N through N plus the square root of N, with an explicit count and an exactly-three refinement for the constructed family. This proves the existence part of Stewart’s 2008 conjecture, not the separate universal upper bound.

- [Existence proof and count](FactorStewartSquareCubeFifth.md)
- [Exactly-three refinement](FactorStewartExactlyThree.md)
- Independent finite replays: `node verify_factor_stewart_square_cube_fifth.js` and `node verify_factor_stewart_exactly_three.js`.

Source question: [Stewart (2008), §4](https://doi.org/10.4064/aa133-2-1). Neither result requires prime bases or settles the separate global at-most-three question.
