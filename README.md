# Solutions to Fernando–Kousik Questions 6.1 and 6.3

For q>2 a power of two and e>0 even, we classify both open permutation-polynomial families from [Fernando and Kousik, Section 6](https://arxiv.org/html/2606.01037v1#S6).

- Q6.1: exactly q=4 and 4 divides e, or e=4 and q is not congruent to 3 modulo 5.
- Q6.3: exactly q=4 and 4 divides e.

This archive is separate from the earlier five-question archive. The [proof](FactorFernandoKousikQuestions61And63.md) treats all parameter ranges. Run `node verify_factor_fernando_kousik61_and63.js` to reproduce the exact checks.
