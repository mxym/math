# At Least Twenty-Four Edges in a Six-Partite Intersecting Ryser Counterexample

An intersecting six-partite six-uniform hypergraph of covering number six requires at least 24 distinct edges, with no restriction on part sizes.

Read [the 24-edge result](RyserSixTwentyFourEdges.md) and its [23-edge dependency](RyserSixTwentyThreeEdges.md). The conclusion excludes at most 23 edges, not all rank-six counterexamples. The bundle includes the exact independent enumeration as well as both source checkers.
