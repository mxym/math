# Exact Gaussian mixing on bipartite cycle tori

Exact theta behavior and a different total-variation transition for the Gaussian on the bipartite cycle-lattice torus, with any diverging aspect ratio. The cyclotomic interpretation covers two distinct odd prime conductors with the canonical Euclidean metric, up to scale. No cryptosystem, security or hardness claim.

See the manuscript for conventions and references. Run `python3 verify-bipartite-cycle-torus.py` for finite arithmetic controls; the asymptotic argument is in the text.
