# An unbounded counterexample to Kunisky’s effective-depth certificate

Yongxian Zhang, ORCID [0009-0000-3864-3536](https://orcid.org/0009-0000-3864-3536).

Disproves the universal statement in Conjecture 4.4 of arXiv:2111.02974. The proposed objective tends to n+1 on fixed minimally unsatisfiable formulas, as the resolution refutation varies. Includes an exact three-variable certificate and a proof that possible effective-depth laws are dense in the probability simplex for the same complete formula. Does not refute the weaker existential certificate or determine the sharp Komlós constant. AI-assisted and internally checked.
