# Exact odd residue class of the alternating eight-cycle quantum max-flow

**Yongxian Zhang** (ORCID [0009-0000-3864-3536](https://orcid.org/0009-0000-3864-3536)). Version 1.0.0. AI-assisted proof development and internal verification; no external peer review claimed.

For the periodic single-tensor complex eight-cycle with both dimensions equal to \(q\), the alternating maximum flattening rank is \(q^4-1\) for every \(q\equiv3\pmod4\). For \(q\equiv1\pmod4\), the lower bound is \(q^4-2\), not an exact formula. This archive contains the proof, exact small symbolic and modular certificates, and the base and quadratic analyses it uses.
