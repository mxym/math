# Exact asymptotic ranks of complete and wheel graph tensors

Yongxian Zhang (ORCID 0009-0000-3864-3536), version 1.0.0.

This release contains two AI-assisted research notes. It fixes the exact log asymptotic rank for complete graph tensors and wheel graph tensors over every field. The contribution for complete graphs closes the odd-order case; the even-order exact value was already known. For wheel graphs the new lower bounds match Huanyi Zhou's upper bounds, and the wheel note explains the scope for constant rim and spoke dimensions. The proofs use the pinned OpenAI rectangular-exponent theorem; this is an application of that theorem, not a proof of it. Single-copy tensor ranks are not determined here. This is a research note, not a claim of external peer review.
