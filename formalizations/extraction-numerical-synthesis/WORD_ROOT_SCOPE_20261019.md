# Canonical Boolean fraction-root backend

WordShifts implements the shift by a repeated false cons, retaining its executed shift trace. A single trim normalizes the result and retains the trim trace. Its numerical value is input value times 2^p, its actual width is at most input width+p, and its explicit action model costs at most 8(input width+p+1)+4. The power-two denominator is that same program on the one-bit word [true]. Negative numerator truncation is a Boolean sign test, and equals Int.toNat semantically.

wordScalarRootProgram stores its subprogram results once: select the nonnegative numerator, shift by 2p, execute the Boolean long division, execute the Boolean restoring square root, trim the root, and construct the power-two denominator. Every output component is canonical. No natural division/square root, integer arithmetic or rational decoding computes its output bits. The proofs establish exact raw numerator/denominator equality of the decoded result with IntegerScalar.root, and hence equality to rationalSqrtApprox.

From decoded input height A, actual input lists have width at most A+1. The explicit model charges all nested shift, division, restoring-root and trim trace actions and local frame work; its bound is 256(A+2p+2)^2. The canonical output widths are at most A+2p+1. These bounds include the division/root internal Boolean work through the already proved actual trace programs, not by assigning a unit charge to Nat.div or Nat.sqrt. The cost of evaluating annotations, precision-index arithmetic, and machine implementation is still separate.

This scope has narrow guarded author checks only, not a standard aggregate or independent-kernel claim. Every earlier source and metadata file remains byte-identical. It is unused by the frozen raw-resource scope.
