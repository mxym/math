# Real query reuse, cleanup and framed binary request installation

Six new mathematical modules extend the physical immutable-master cache reader
with one dedicated fifth Symbol stack carrying framed binary queries. The old
four stacks, alphabet, reader and every sealed source remain byte exact.

TM2ExtraStack is an actual generic syntax compiler for one extra physical stack
and mapped labels. Its stepAux, step and official EvalsToInTime simulation prove
that the embedded program never accesses the extra stack and preserves exact
time. No persistent sharing or host subroutine call is used at runtime.

PacketQuerySetup installs a fixed finite controller with three destructive clear
loops and a two-pass binary query installer. Clear loops really pop every old
payload/index, scratch and working-cache suffix cell. The input stack is really
popped through every bit and its field separator, with each bit pushed on scratch,
then popped onto the index stack in the original order. Its EOF checks, branching,
load and goto are actual TM2 syntax. The installer does not decode Nat, invoke
Nat.bits, calculate an index or manipulate a host list atomically. All machine
local memory and labels are finite, including the inlined master-cache reader.

For old working-stack total symbol length S and represented query width w,
setupRun has exactly S+2w+5 official transitions. The complete nextQueryRun
then performs the physical master working copy and actual binary-indexed packet
read, with internally derived bound

S + 2w + (2w+3)N + 4T + 10,

where T is actual master cache symbol length and N packet count. There are 16
labels, 80 label/local-memory combinations and statement depth at most seven.
A source-exhausted query stream is also handled by eofRun after real cleanup.
No desired final-correctness or total-cost certificate is a caller premise.

The real terminal state is in official eval. Its master is exactly the original
encodeCache ps, input query stack exactly the unconsumed tail, scratch empty,
working suffix exactly encodeCache(ps.drop(index.value+1)); a successful selected
output is exactly the original packet frame. Raw source-parser observation and
typed reconstruction inherit exact original fields, including canonicality and
positive denominator as input representation invariants.

PacketQuerySemantics derives the previous terminal working-data volume bound
w_previous+T from the actual terminal recursion. reuseRun therefore includes
clearing the concrete previous payload and suffix, and has bound

w_previous + 2w + (2w+3)N + 5T + 10.

With a uniform actual numerical packet height B, this becomes
w_previous+2w+(2w+25B+73)N+10 via the existing canonical encoding theorem.
queryCall is a literal CPS splice interface, so an explicit caller returns into
its real finite program instead of assuming a zero-cost machine restart.

PacketQueryTwice gives such a concrete caller with two query phases and a finish
label. First halt compiles to goto into the second destructive-clear loop. The
second installs the next actual input query, then reads the same unchanged master.
Both official runs compose into twoQueryRun without a host restart, pre-reset
working stacks or a supplied final-cost certificate. There are 33 labels/165
running control-memory combinations, bounded statement depth seven, and bound

S + 3w1 + 2w2 + (2w1+2w2+6)N + 9T + 21.

A real first-return execution prefix contains the exact first selected frame;
the second clears it and its old suffix with the proved time charge. Final output
is the exact second selected frame and the query stream tail after both queries.
The first result is observed at that actual prefix, not accumulated/delivered to
an arithmetic consumer for free. The final official terminal eval and height-bound
specialization are proved internally.

The query stream is supplied as real encoded input. Constructing that stream
from compiler requests, initial cache/index serialization and any normalization,
full typed field parser lowering, delivery to and integration with the actual
native AST evaluator, its remaining scalar/control primitives, allocation and
single-tape simulation are separate. This scope does not assert an unbounded
request-loop compiler or complete machine bit-time. Official multi-stack TM2 time
counts one finite bounded-depth statement per transition; annotations and proof-side
length/index observations are not running registers or counted computation.

Only newly added unused files are checked. Ordinary aggregate, OWNED feedback
and independent fresh/trust-zero replay are distinct evidence boundaries.
