# Native Boolean numerical recursion successor

This separate scope adds six modules. Earlier numerical sources and every
frozen core input remain byte exact. The native AST evaluator, fixed binary
0/1/frame constants, factor constructors, double correction recursion and
eager gate/target packet caches receive canonical Boolean word data directly.
Their value path calls neither Nat.bits nor rational construction nor the
proof-side interpretation.

The actual cached output word equals numericalPairWord on the supplied
binary packet providers. The length and approximation-error theorems are
proved internally, using the same fixed precomputed net and inverse-label
conditions as the previous numerical algorithm. Each retained score and
decision run belongs to the actual native execution. The generic total
numerical Boolean charge is at most twice wordNodeBooleanBudget(B) times the
interpreted structural operation budget, with B internally accounting for
all raw numerators and denominators. No final-correctness or polynomial-cost
certificate is introduced as an input.

Interpretation and its structural accounting budgets are proof semantics;
they are not executed by the native value programs. WordExpressionTrace is
reused only for numerical charges; its legacy literalAdapters field describes
the earlier host-input evaluator and must not be read as a native adapter count.

These six modules do not yet transfer the earlier p^338 numerical bound to
the new native constructors. Cache/index implementation, AST and output-list
construction/allocation, natural precision/control and annotation arithmetic,
input provider generation and whole-machine bit-time remain separate. A
correct provider of bounded-width output need not run in polynomial time.

OWNED feedback and ordinary guarded aggregate compilation are distinguished
from independent fresh or trust-zero replay. This successor is not covered
by the previous independent frozen audit scopes.
