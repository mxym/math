# Native binary synthesis polynomial refinement

This separate successor adds seven mathematical modules and its own check
and root files. All earlier committed numerical and frozen core sources
remain byte exact.

The fixed-factor relation is proved for every scalar/packet constructor,
the actual conditioned factor constructors and the complete selected double
correction recursion. Actual native and prior raw-expression traces have the
same output word, the same comparison count, paired expressions with equal
rational semantics, and native numerator/denominator and structural operation
budgets at most twenty times the raw-expression budgets. The factor twenty
absorbs fixed binary constants whose proof interpretation uses raw macros;
the native value program does not execute those macros or rational adapters.

nativeCachedRun_booleanActions derives a numerical Boolean charge of degree
2a+320 from queried binary packet height A(p+1)^a. The degree338 theorem takes
a=9. Both derive all recursive operand and operation budgets internally from
the supplied finite binary input height and fixed net table length. No
caller-provided final correctness, local fee or whole-program polynomial
certificate appears. nativeCachedRun_word/length/error from the preceding
native scope apply to precisely this value program.

The charge includes native numerical expression evaluation and actual stored
minimum/comparison decisions. Fixed-library/target provider generation,
eager cache construction, general indexed-access implementation, AST and
output-list construction/allocation, precision/control/counter arithmetic
and complete machine bit-time remain separate. Output height alone does
not imply provider runtime.

The proof separates record-free natural-number algebra from the native AST
budgets. Two initial monolithic author checks hit the M4000 interpreter memory
guard; these failures are preserved in D build logs. The split proofs pass
the unchanged guard and do not use increased memory or shared-cache builds.
OWNED feedback is not an independent fresh/trust-zero audit. Standard
aggregate status, if run, is recorded separately and is BUILD_ONLY.
