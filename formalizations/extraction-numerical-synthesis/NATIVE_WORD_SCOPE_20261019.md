# Native binary literal and packet-cache interface

NativeScalarExpression and NativePacketExpression use canonical WordIntegerScalar/WordIntegerPacket payloads for their literal constructors. Their actual mutual wordRun definitions receive those bit lists directly and never call Nat.bits, wordScalarInput, rational constructors or the semantic interpret function. A native scalar literal shares its canonical fraction. A native packet literal materializes its four coordinates and performs the actual common-denominator tuple assembly. The full unconditional mutual proof identifies its decoded raw result with integerProgramRun of the semantic interpretation. Interpretation uses the mature rawScalarExpression/rawPacketExpression literal macros and is proof-side only.

The underlying WordExpressionTrace data type is reused to record numerical primitive runs. Only its Boolean-charge projection is applicable to native evaluation. Its legacy literalAdapters statistic describes the host-input evaluator and is not claimed as an adapter-call count for native leaves. Native input data does not traverse the host adapter.

BinaryPacketInput is the narrow provider boundary: four actual sign bits, four actual LSB magnitude lists, one denominator list and its positivity invariant. binaryPacketInputProgram executes four stored signed normalizers and one denominator trim, producing a canonical WordIntegerPacket and the actual normalization traces. It preserves the decoded raw packet exactly. If all supplied lists have width at most B, its explicit Boolean/list/record charge is at most 64(B+1). This explicitly includes padding removal and zero-sign normalization; it does not treat output width as provider execution time.

buildNativePacketCache materializes provider Word packets once in a vector of length P+1. Lookup returns the stored binary packet, with a fixed binary-one default, and nativeCachedPacketOracle passes that packet directly as native literal data. No Rat/IntegerPacket intermediate or Nat.bits re-encoding appears in that value path. Semantic interpretation equals rawPacketExpressionOracle of the decoded stored cache. Provider construction and indexed access implementation costs still require their own concrete bridges.

This scope has guarded narrow author checks only. Native AST action/operation bounds and native synthesis constructor generation are not yet connected to the mature p338 bound for the host-input Word evaluator; that transfer is not assumed automatically. General AST/cache/index/counter/provider costs and a complete machine-time theorem remain open. All prior source/metadata is byte-identical, and the separately frozen raw-resource scope does not import these additions.
