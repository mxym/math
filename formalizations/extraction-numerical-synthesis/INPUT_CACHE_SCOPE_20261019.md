# Actual input-reference cache evaluation

This separate scope adds four modules. An input-reference packet leaf stores
only its gate/target label and precision. The actual mutual evaluator runs
the previously proved list-cache program when that leaf is visited, returns
its binary numerical record and retains the executed read record. Tuples and
scores are stored in vectors once; only the chosen branch executes.

The whole numerical evaluation record equals the prior native evaluator on
the proof-side resolved expression. Resolve is not run by the actual value
evaluator. Actual retained read count is at most executed numerical trace
nodes, hence at most resolved structural operations. The sum of those actual
cache-list read fees is internally at most 4(m+P+5) times resolved operations.
There is no assumed total-request or final-cost certificate. All fixed
arithmetic, word and conditioned-factor constructors commute with resolution.

These four modules stop at arbitrary actual expressions and their oracle
constructors. The complete word recursion and its aggregate p64 operation
bound have not yet been transported to the input-reference evaluator here.
In particular no whole-cache p73 or whole-program machine bound is asserted
by this checkpoint. Providers, eager cache/AST/list construction/allocation,
precision/control/counter arithmetic and full-machine bit-time remain separate.

Earlier numerical and frozen source inputs remain byte exact. OWNED feedback
and ordinary aggregate compilation are separate from independent fresh or
trust-zero replay; prior frozen audits do not certify this unused successor.
