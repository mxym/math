# Whole mutual Boolean-word AST evaluator

ScalarExpression.wordRun and PacketExpression.wordRun implement every constructor of the original mutually defined AST using the actual canonical Boolean fraction/packet backend. Every recursive operand is stored in one record. Tuple children and selector scores are materialized once in finite vectors. The selector reads those stored values, and only the selected branch is evaluated. Semantic decode functions are not called to compute bits or branch choices.

The unconditional mutual correctness proofs establish exact raw IntegerScalar/IntegerPacket equality with integerProgramRun, including numerator vector and common denominator. Consequently the resulting rational scalar/vector values equal the original AST eval for every expression. The runtime result retains a concrete execution tree containing each executed local primitive result and the actual child traces; four tuple/score traces are stored as four direct fields.

WordExpressionTrace.booleanActions sums all executed local Boolean/list/record charges, plus stated local frame work. Host literal input adapters, their Nat.bits execution, annotation arithmetic and general machine allocation/index implementation remain excluded. Separate inputVolume and literalAdapters statistics identify those leaves; volume is not adapter time. Executed nodes are bounded by the original AST operations, including the selected branch bound by the sum of all alternatives, and adapter calls are at most four times operations.

A generic trace induction proves total actions <= C times executed nodes from an explicitly named AllLocalBound C. That generic helper is not an end-to-end complexity endpoint: deriving AllLocalBound internally from the actual AST integerBitBudget and connecting p137/p64 remains successor work. No caller certificate of final correctness or polynomial cost is used in the unconditional evaluator correctness result.

Only guarded narrow author checks are claimed. No standard aggregate or independent-kernel result is claimed for this successor scope.
