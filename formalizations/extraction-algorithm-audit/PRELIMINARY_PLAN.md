## Semantic checklist before any freeze

1. Inspect every finite output type and runtime definition. Generated AngleAtom/AngleCode/SingleCode/GateCode/LabelGate fields must be finite discrete data, with ordinary computable recursion and no chosen real matrix in runtime data. Noncomputable matrix denotation is allowed. Inspect compiled dependency graphs, not merely the absence of a keyword. Exercise the finite generator at k=0 and small positive k; build an executable output-only smoke check whose runtime fields contain no matrices.
2. Follow explicit occupations, rank/unrank, decoder and alignment swaps through the new extractionCode. Verify original register size 2k, actual memory width 2*ceil(log4 occupationRank), compression pure-power action and the same physical local discard. Do not substitute equality to the old arbitrary-choice encoding circuit; prove the new circuit's actual output.
3. Resolve each descriptor's SU2 representative, its rational packet provider and its explicit global phase. Check inverses, signed half-angle degeneracies, product order and wordPhase norm. Verify telescoping norm error and phase cancellation in the very same approximateExtractionOutput.
4. For the mature numerical terminal, locate the actual runtime compiler and actual N(k). The dyadic precision q must be computed from max(1,N) and requested delta, then prove N*2^(-q) is within the budget, including N=0, k=0, zero/large delta boundaries and ceil-log conventions. Check q is selected before unknown input state z and the final finite labels are uniform over z. A generic synth parameter with a supplied per-gate error premise is not the terminal algorithm.
5. Inspect numerical residual thresholds, overlap stopping, conditioned chart denominators and factor normalization. The recursive word must be computed from finite packets with oracle accuracy assumptions stated separately. The final error/factorization bound cannot reappear as an assumed certificate.
6. Inspect cache request/precision demand as a bound on actual recursive calls. Check the eager cache equals the actual word and include all chart alternatives, stopping-threshold operations, packet reads and repeated expression nodes in the execution count. Verify finite traces and selective run semantics agree.
7. Check integer numerator/common-denominator packet multiplication against rational semantics, then input and actual synthesized-word operand-size bounds. Later scalar/factor bounds must refer to the executed factor-normalization program; a word-product height bound alone does not close those operands.
8. Keep the library-dependent finite-net table, inverse labels and offline constants explicit. A fixed library's precomputed finite table is a nonuniform constant; density plus Classical.choice is not a uniform table-construction algorithm. Gate/target packet providers require a separate cost hypothesis before any Turing-time claim. Arithmetic operation counts, integer bit lengths and whole Turing time are distinct statements.
