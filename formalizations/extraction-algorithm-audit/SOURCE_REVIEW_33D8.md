## Actual numerical word and honest cost boundary

- `CircuitNumerical/NumericalSK.lean:70-94`: numericalPairWord is explicit recursion on depth with two numericalCorrection applications. Its actual error theorem assumes only provider accuracy, exact inverse-label semantics and the fixed table's coarse cover, then proves the final error inductively; it does not take a final synthesis-error certificate as input.
- `CircuitNumerical/NumericalSK.lean:115-148`: the library-dependent table/C are existentially fixed before entry providers, precision p, target U and its packets. Density and inverse closure internally establish an offline table. The theorem does not compute a net uniformly from an arbitrary real library description. Dyadic inputs are providers; arbitrary functions Nat→packet have no efficient-provider cost theorem merely from their types.
- `CircuitNumerical/CachedArithmeticSynthesis.lean:7-20,48-74`: cachedArithmeticRun eagerly caches entry/target packets, runs the actual finite expression program and has its output word equal the cached numerical word. cachedArithmeticSU2Synthesis proves length, operator error and an arithmetic expression-count bound for that actual word. It explicitly leaves machine implementations and operand sizes separate.
- `CircuitNumerical/ExpressionCosts.lean:6-25,44-68`: executedOperations counts the selected branch after all chart scores, and its conservative upper bound includes all branches. Arithmetic literal access, rational operations, root and comparison primitives receive fixed weights. These are arithmetic-model weights, not bit-time costs or allocation/indexing costs.
- `CircuitNumerical/IntegerPackets.lean:158-207`: actual cached integer packet multiplication is proved equal to the rational word evaluator. For the actual synthesized word, cachedSynthesisWord_integerHeight gives the explicit exponent bound `(cachePrecisionBudget L p+3)*(32*L*(p+1)^5)` and binary_bounds gives bit-length≤exponent+2. This bounds the matrix-word product evaluator, not factor-normalization scalar operands. The latter is explicitly marked as remaining at182-184.
