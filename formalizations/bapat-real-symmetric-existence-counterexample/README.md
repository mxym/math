# Complete Lean proof of a real symmetric integer Bapat counterexample

The root theorem is `BapatRealExistence.exists_integer_real_symmetric_counterexample` in [BapatIntegerCounterexample.lean](formalization/sources/BapatIntegerCounterexample.lean). It proves, without mathematical hypotheses, the existence of a finite N > 4 and an integer matrix B whose real cast is positive definite, with B symmetric and non-diagonal, a negative q-permanent derivative at q = 1, and rational 0 < q0 < q1 < 1 for which P_q1(B) < P_q0(B). The q-permanent uses all permutations and their ordinary inversion counts in the chosen index order.

This is a finite existence result. It does not provide a numerical matrix, a specified dimension, or a dimension upper bound. Positive definiteness does not imply entrywise nonnegativity.

The mathematical reference is the [real symmetric existence note](../../notes/bapat-real-symmetric-existence-counterexample/), frozen for formalization at commit `2509263c1028d6814658174b2830a3d658e76c1c`. See [the publication report](PUBLICATION_REPORT.md) for the exact coverage and proof-route differences.

The archived original verification records report 67 freshly compiled modules, 776 owned declarations and a 54,739-declaration closure replayed into an empty Lean kernel at trust level 0. The negative proof control was rejected. Only `propext`, `Classical.choice` and `Quot.sound` occur as axioms; full standard-axiom signatures are checked. The publication owner independently verified the archive and source hashes, dependency graph, signature records and key semantic chain. The publication owner did not rerun Lean. These are AI-assisted checks, without a claim of external human peer-review acceptance.
