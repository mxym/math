# Lean formalization: Erdős similarity and growing logarithmic gaps

This package contains the kernel-checked deterministic, finite-routing, and finite actual-sequence blocker layers for the growing-logarithmic-gap preprint. The late-annulus bridge is now closed: a supplied `WindowFilling` sequence produces the finite certificate required by the actual-sequence blocker, and the countable-family Theorem 2 entry point is exposed in `Replay.lean`.

## Current theorem boundary

The finite routing/blocker construction, the actual-log signature and greedy-family estimates, the variable annulus parameter selection, the finite actual-sequence probability bound, the periodic repair, and the robust countable exhaustion are kernel-closed. The unrestricted `WindowFilling` bridge is also kernel-closed, yielding the stated Theorem 2 for every prescribed nonempty countable family whose logarithmic scales satisfy `WindowFilling`, and hence for families satisfying the consecutive-gap little-o hypothesis. The package does not claim the full Erdős similarity conjecture beyond this class.
