# Fully native actual target provider and finite-label compiler

Only successor files are added. Mature Cdc567 native AST/cache/synthesis sources
were brought in by a normal merge. Old compiled/imported files and all frozen
scope inputs are unchanged. The preceding native-literal preparation and
prepared-Pauli-context checkpoints remain sealed.

Actual runtime call graph:

1. `fullyNativeExtractionRun` executes `preparedNativeDescriptorRun` once. Its
   native triple occupation data, explicit Fin4 selector/pivot, packed endpoint
   ranking and stored swap stack need no semantic Sym value. Every active stage
   shares one prepared Pauli context across branches and alignment. The emitted
   continuous gate descriptions contain finite Nat/Bool syntax only.
2. Each SingleCode invokes `nativeTargetDescriptorRun` once. It executes
   `prepareNativeSingleInput` once, using actual bounded Boolean increments and
   a shared Boolean denominator for dynamic merge literals. The prepared records
   are retained and reused across all eager precision-cache requests.
3. `NativeSingleInput.packetExpression` uses fixed literal Bool words and those
   prepared dynamic literal words. Native halfCos/halfSin and phase formulas
   preserve exactly the prior precision shifts, signs, inverse recursion and
   global-phase SU2 convention. Native tuple/root/arithmetic implementations
   execute on actual canonical Boolean fraction data.
4. The target `packetProgram` directly returns WordIntegerPacket data. The
   native eager cache stores these packets once, alongside the gate dictionary's
   native Word packet cache. `nativeCachedRun` executes native AST construction,
   Boolean/list arithmetic, score/chart/base/stop decisions and only selected
   recursive corrections, retaining the actual records.
5. `compileNativeWord` stores each returned single program once. Output labels
   and later resource projections consume that same retained record. Final
   records retain precision, generated rank annotations, labels and all executed
   target/literal/cache/numeric program records.

None of this value path calls Nat.bits, a rational literal constructor, a host
IntegerPacket value conversion, a decoder or semantic oracle interpretation.
The library routine must itself supply actual Word packets. Decoded rational
quaternion oracles and matrices occur only in semantic statements/proofs.

decode equals the old SingleCode.rawPacket, including numerators/denominator;

`actualNativeTargetHeightCoefficient k L*(q+1)^9`. The complete finite-label word
equals the established numericalExtractionCode for the semantic native library
