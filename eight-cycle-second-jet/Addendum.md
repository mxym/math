# Addendum: residual rotation sectors and the even half-turn

Use the setup and perturbation from [the main note](README.md), always specializing u_h=d_h=e_h=0 for the self-inverse nonzero label h if q is even. Then the defect bounds sharpen to r for odd q and 8r+4 for even q, where r=floor((q−1)/2). Independently verified modular scripts: `verify_residual.py` and `verify_halfturn.py`.

## Two-zero opposite-pair blocks

Write E_j={0,0,j,−j}, for nonself opposite pair j. In the orbit-coordinate basis for any rotation eigenvalue ζ∈{1,−1,i,−i}, this 12-word block is 3×3 (three orbits, length 4). The modular verifier gives full base rank in the +1 sector and base rank at least 2 in each other sector. Each is a universal two-spoke block, independent of q and other coefficients. We show the ζ=±i directions attain full 3×3 rank under the deformation, thus retaining two dimensions per opposite pair beyond the earlier proof. Choose a generic base complementary minor for each; if the base rank is already 3 then retain its entirety. Otherwise choose a 2×2 complementary minor which is also invertible in the modular certificate and adjoin one unused left and right kernel coordinate after independent rank-revealing row and column changes. This dichotomy is enough: the proof does not need a separate symbolic exact upper bound of 2 for the base block. The rotation sectors are honest endomorphism matrices: a basis input is the orbit sum with ζ^k weights and the output coordinate is value at the representative. The same construction in the proof over C specializes to the residues 469 and 540 for i and −i, since they are opposite roots of x²+1 mod1009.

At first order every path flips the hub/leaf parity of exactly one slice relative to base, so the row and column overall number of zeros is odd. A two-zero E_j direction can interact at first order only with one- or three-zero blocks. With a tilted zero, all excursions are dimers; the smaller number of zeros fixes equal surviving monomer counts, so either the one-zero block retains both original nonzero letters (with possibly a third letter from a different class) or the three-zero block carries exactly one original nonzero label. With a nonzero leaf loop, the unique triplet supplies the one-position imbalance; it uses only inverse class j, giving three letters of class j in the one-zero case or one letter of class j in the three-zero case. Thus distinct E_j do not share intermediate base blocks: one-zero needs ≥2 of class j, three-zero needs its nonzero label from j. No intermediate can contain h under u_h=d_h=e_h=0. Every one- and three-zero block used here is base nonsingular, since the prior base certificates list no such exceptions without h.

Direct second-order entries between E_j and E_k for different classes vanish. Each nonzero row label belongs to class j and each nonzero column label belongs to class k. Every excursion has length at least two and includes both sides; an excursion containing a nonzero j on the row side must use a tilted 0 on the column side, and conversely for k. Neither family of excursions can share any label class with the other, because the only leaf-leaf transitions are loops preserving the state. Two perturbations can supply just one tilt per side, leaving no leaf loops: such dimers can handle at most one of the two nonzero letters on each side. This is impossible. Higher-order unsupported terms are irrelevant to the Schur coefficient.

Thus the 2nd-order Schur coefficient on these ζ=±i residuals is diagonal by pair class. It has no coupling to the zero-free K0 directions (only rotation −1). Other omitted kernels, including even h-related ones, need not be retained, since the rank bound is by a submatrix after choosing constant bases. For a fixed j, specialize all other tilt and leaf-loop variables to zero; then only the states 0,j,−j can matter in its intermediates (all other c can remain generic). The exact modular audit with j=1 in Z/5 computes the retained base ranks and nonzero Schur scalars 935 and 400 in eigenvalues 469 and 540. Since the coefficient is rational with modular-valid denominators, both are genuinely nonzero over C. As in the main proof take the product of these nonzero conditions jointly with all other required invertibilities. This gives +2r in both parities.

## Recovering two more dimensions per half-turn block (even q)

For the zero-free h-containing balanced type {h,h,j,−j}, there are three −1 coordinates (three length-four rotation orbits). Under the h-perturbation suppression, first-order one-zero intermediates cannot be obtained by deleting h: each such path would need a tilted zero directed along the h-spoke or a leaf loop furnished by A_h. Thus the only intermediates are {0,h,h,j} and {0,h,h,−j}, which are base nonsingular by the existing certificate (not listed among exceptions). They are disjoint from every other retained type's intermediates by inverse-class multiplicities. The direct second-order block for this type cannot meet a different retained zero-free type because every excursion contains both sides and retains its class, as in the main proof. In every universe of even q this local matrix is identical to the q=4 example h=2,j=1,−j=3 (walks never leave those three spokes). The half-turn verifier gives the exact block [[663,789,0],[759,0,789],[0,759,346]] over F_1009, using c=(2,3,11), u=(13,0,23), d_j=u_j, e_j=u_{−j}+13 except d_h=e_h=0. Its top-left 2×2 is nonsingular since determinant is −789·759. Thus retain two (not all three) −1 directions from each of these r classes. This gives another +2r in even q.

Combining with the original rank bound, at most r dimensions are omitted in odd q, and at most 8r+4 dimensions in even q. The even bound ignores additional potentially liftable directions involving h. No exact general rank claim.
