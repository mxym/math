# Nine scoped Lean-verified principal-result preprints

The papers, exact formal scopes, PDF/TeX and DOI indexes are at [the preprint collection](../../preprints/lean-certified-2026-10/README.md).

`PUBLICATION_STATE.json` contains public record identities and uploaded-file SHA256 values, not credentials. `PUBLIC_DOWNLOAD_AUDIT.json` records unauthenticated creator/ORCID/custom-rights/access checks, full anonymous file downloads and matching SHA256, plus DataCite `findable` registration. `ARCHIVE_AUDIT.json` records the independent fixed-Git-blob/archive/mode/metadata check for all nine source packages. These archival checks are not new mathematical proofs.

Run `python3 verify_public.py` for any pending entries. For a fresh complete download audit, move the existing PUBLIC_DOWNLOAD_AUDIT.json aside before running; this downloads every file, including large proof sources. No authentication is required. Large sources are losslessly split into documented parts; the attached reconstruction program validates each part and the complete original archive. Standalone PDFs and LaTeX ZIPs need no reconstruction.

Existing licenses are retained; unlicensed material remains all rights reserved. This archive supplies neither automatic worldwide priority nor external human peer review or arXiv acceptance.
