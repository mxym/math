## 重点修订

**Bapat：** 200 是被严格认证的显式复反例阶数，不是最小阶或理论临界点。发现过程与最终整数证书分开；指定微小扰动和参数来自保守的显式连续性界。实反例依次选择有限基本行数 m，再选择有限重复次数 L，最终阶数为 (m+4)L；收敛保证存在，当前证明未提供有效阈值。该过程最终给出有限整数正定矩阵，而不是浮点极限对象。新增完整书面推论：恒等补齐得到所有 N≥200 的复反例，正标量清分母得到 Gaussian-integer 反例；不把该推论标为新增 Lean 定理。两项原主结论的形式化范围保持不变。

**全图 Chollet：** 将短证明笔记重写为 9 页论文，包含主定理、全部原图度数约定、空矩阵约定、Lieb 与 Edmonds 两个明确的已发表输入、cycle-trace 上界、完整奇数集合约束、周期块、二连通非周期块、非负对角添加、单点拼接以及全图组装。分别处理孤立点、奇异、非连通和主子矩阵。非周期块的指数缺口只是已有比较链的显式整理，不是一般图等号分类或最优常数。书面路线与独立 Lean 路线区别已写清。结论仍只覆盖有限简单无权图；一般加权图和一般 PSD Chollet 猜想未解决。

这两项文章修订分别对应原建议的解释性修改和完整重写。这里不作期刊 Minor/Major/Accept 的决定。

## 执行的检查

- 从每个 TeX ZIP 独立提取并逐文件比对公开源文件，检查安全路径与唯一条目；递归读取实际参与编译的输入文件。
- 每稿三次独立 LaTeX 编译，禁用 shell escape；未留下未定义引用、重复标签、缺字符或超宽警告。最终公开 PDF 另查字体全嵌入且无 Type 3。
- 全部 136 页渲染及文字边界检查；用联系页检查版面裁切、重叠、表格分页与明显大块空白。两篇重点稿逐组六页检查，其余稿件使用全稿缩略图；这不是每个公式字形的放大校读。
- Bapat 两个不同整数算法重新执行通过，并拒绝优化执行和错误 rank-one 负控制。全部 200 行表格与 CSV 对应。
- 抽查 9 个关键 DOI 的注册书目。8 项成功取得；Mitchell 的接口当时限流，不能称为本轮全文重读。已有固定文献审查保留。书目字段正确不证明引用定理适用，主论文必须读正文列出的假设。

本轮修正的是来源和文章呈现问题；没有把未经再审查的新数学猜想写成定理，没有修改 Lean 证明源文件。

## 复现

需 Python 3、TeX Live、`pdflatex` 和 Poppler；页面渲染工具另需 Pillow（`python3 -m pip install Pillow`）。从仓库根目录执行：

```sh
python3 -B reviews/manuscript-quality-2026-10-08/audit_articles.py --output /tmp/manuscript-quality-fresh
python3 -B reviews/manuscript-quality-2026-10-08/render_articles.py --output /tmp/manuscript-quality-fresh
python3 -B submissions/arxiv-2026-10/build_bapat.py --output /tmp/bapat-fresh
python3 -B preprints/article-revisions-2026-10/build.py
```

第一条默认重新编译，不使用历史检查缓存。`--reuse-unchanged` 仅适合已有输入 SHA 与 ZIP SHA 均不变的同目录审计；检查默认启用，拒绝 `-O`／`-OO`。渲染记录固定公开 PDF 的 SHA，重新编译 PDF 可能仅因元数据不同而字节不同；同样源码的渲染对应另有记录。Lean 内核重放请分别按各固定工程命令执行，不在此排版工具中代做。
