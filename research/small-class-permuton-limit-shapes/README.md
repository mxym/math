# Finite-segment permuton laws for all small permutation classes

For every infinite permutation class of upper growth rate **strictly less than** the small-class threshold $\kappa\simeq2.20557$, the uniform permutation of length $n$ has a permuton limit in distribution along the full sequence. Its law has a finite description: choose a route and a finite boundary context, divide unit mass between the route’s phases by a uniform-simplex vector, and distribute fixed proportions of each phase uniformly along straight segments. Conditional on the discrete choice, the segment endpoints are explicit linear functions of the random phase masses. The limit need not be deterministic.

The [main proof](SHAPES.md) treats any fixed pair of first-order rules ordering all positions of a uniform regular word, when the trimmed input automaton has primitive dominant components. It uses the **proved forward, free-variable** Markström–Räty interpretation to obtain the small-class result. The [modular extension](MODULAR.md) permits arbitrary MSO rules and arbitrary regular input languages: it gives the same form on each eventually occupied residue class, not necessarily the same law across residues. Both statements use one output point per input position. Neither allows arbitrary copying, filtering, or an arbitrary distribution on the output permutations.

[Prior and scope](SOURCES.md) separates existing logical laws, geometric/monotone-grid and substitution results, standard Perron/semigroup theory and the new rank argument. The bounds on the number of pieces are per fixed input scheme, not universal over all classes. This is a research note prepared and internally reviewed with AI assistance, not external peer review, formal verification, or a guarantee of priority. No claim is made about every proper class or about large deviations.
