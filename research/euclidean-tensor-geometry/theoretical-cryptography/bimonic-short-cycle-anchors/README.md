# Short algebraic cycles in prime-support graphs

A public list gives exact polynomial relations between candidate prime values, with finite fibres of uniformly retained degree in both directions. The distinct prime divisors of an integer form a graph using those relations. If the graph is connected and contains a short labelled cycle whose diagonal elimination polynomial is nonzero, the prime factorization is determined in deterministic polynomial bit time without a supplied prime, factor count, edge pattern or multiplicities.

The cycle is a finite algebraic anchor. A one-variable chain of resultants is enough to obtain the anchor even for logarithmic-length cycles with bounded alphabets and degrees. The proof applies to a particular promise class only, not arbitrary integers. Both checkers take no external input and verify only finite algebraic and graph fixtures.
