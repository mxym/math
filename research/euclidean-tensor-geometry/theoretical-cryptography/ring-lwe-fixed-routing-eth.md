# A quasilinear-dimension fixed-design reduction for exact dyadic likelihood

The previous fixed design allocated a slot for every possible pair of input vertices, incurring a quadratic dimension cost even for sparse inputs. A rearrangeable permutation network reduces this to a quasilinear dimension while preserving fixed-by-dimension public coefficients. As a result the Exponential Time Hypothesis gives a nearly exponential dimension lower bound for a declared worst-case optimization problem. This does not change the scope to random designs or random observations.

## 1. Statement

Fix an odd prime \(q\). For infinitely many dyadic dimensions \(d\), there are deterministic uniformly polynomial-time fixed designs with at most \(d\) distinct unit rows in \(\mathbb F_q[X]/(X^d+1)\) such that:

* Returning an exact maximizer of the coefficientwise wrapped-Gaussian likelihood on rational-grid observations is NP-hard for every common \(0<b<1\) in \(f_b(x)=\sum_h b^{h^2}e^{2\pi i h x}\).
* Subject to the Exponential Time Hypothesis (ETH), no deterministic algorithm does this in worst-case time \(\exp(o(d/\log d))\) on this fixed family. For \(q=3\) the same statements hold for the coefficient-Hamming decision problem, which is in NP.
* The family can be chosen either with each row of weight exactly two, or with dense, linearly independent unit rows satisfying the bounded local coefficient-pattern estimates in [the prior dense fixed-design theorem](https://github.com/mxym/math/blob/d21809f0ebdf2c8982aeae91095ed929b05d0cf3/research/euclidean-tensor-geometry/theoretical-cryptography/ring-lwe-dense-pattern-balanced-hardness.md), for any fixed pattern order, offset window and exponent slack. Neither option gives independent uniform designs.

Running time here is measured as a function of the ring dimension, with the observation supplied explicitly. The deterministic reduction constructs the public family and its observation matrix in polynomial time. The ETH part concerns exact optimization (or the ternary finite decision problem), not arbitrary approximation, uniform random instances, or general Ring-LWE complexity.

## 2. A fixed graph supporting every bounded-degree constraint instance

First consider a finite constraint graph on \(N_0\) vertices with maximum degree at most three; each edge is declared equality or inequality over \(q\) colors. Pad to a power-of-two number \(N\) of vertices; fix \(M=4N\) inlet and outlet ports. Allocate three inlet ports to each source vertex, attached to it by fixed equality edges (leftover inlets are available as dummy ports). Pair the outlets in a fixed order: \((0,1),(2,3),\ldots,(M-2,M-1)\). Make these pairs additional fixed graph edges. Each original edge has two incidence ports, one at each endpoint, and can be assigned one outlet pair because there are at most \(3N/2\) constraints. Assign its two incidence inlets to the two outlets of that pair. Extend this partial assignment to a permutation of all \(M\) ports.

Between inlet and outlet sets use a fixed rearrangeable network on \(M\) inlets and \(M\) outlets. We require a graph in which each permutation has **vertex-disjoint** selected paths. The following construction recalls the relevant form of the [Beneš network](https://onlinelibrary.wiley.com/doi/abs/10.1002/j.1538-7305.1964.tb04102.x). At \(M=1\) it is a single edge between distinct ports. At larger powers of two, take two disjoint copies of the network on \(M/2\) ports. For each pair of consecutive external inlets, join both of them to the corresponding inlet in each copy; use the reverse construction at the outlets. If the requested map is a permutation, form a bipartite multigraph with input-port pairs on one side and output-port pairs on the other. The edge for each input records its input pair and its destination pair. Every vertex has degree two, so the even cycles (including parallel-edge cycles of length two) split by alternate colors. Give one color to each recursive copy. In each copy there is now exactly one request at each input and output index, forming a permutation, so recursion finds the paths. The ports used by different paths are distinct at every layer. The network has \(O(M\log M)\) vertices and edges by the recurrence with two half-size subgraphs and \(O(M)\) new vertices and edges, and the route can be found deterministically in polynomial time by following the cycles.

Activate equality along the selected paths; in the fixed outlet pairs corresponding to real constraints, activate the required equality or inequality. All other network edges are inactive, and the fixed source-to-inlet attachments are equality constraints. A satisfying assignment of the original graph propagates the value at each source along all of its allotted paths (unused source ports can take their source value and dummy paths any value). Vertex-disjointness of the routed paths prevents inconsistent demands at intermediate network vertices. Conversely a satisfying assignment to all active constraints transmits every source value to its assigned outlet and hence satisfies each original edge. All potential edges of this graph are fixed by \(N\) alone; only their active type changes with the instance.

An ordinary graph for \(q\)-colorability can be combined with this bounded-degree construction without loss in its size. For each original vertex with \(j>0\) incidences, make \(j\) copies, one per incidence, and join them in a chain by equalities. The original edges become inequalities on their own copies. Keep one unused copy for each isolated vertex if desired. Every copy now has degree at most three, the instance is equivalent, and the number of vertices and edges is \(O(|V|+|E|)\).

## 3. Turn the fixed routed graph into a likelihood design

Let \(\mathcal G_N\) be the full fixed graph of potential edges from §2, assigning all of its vertices distinct coefficient positions. Allocate \(q(q-1)^2\) row positions per edge (one group of \(q(q-1)\) rows for each nonzero scalar \(u\)). Set
\[
          d_N=2^{\lceil\log_2(C N(1+\log_2 N))\rceil}
\]
for a sufficiently large fixed constant \(C\). It accommodates both all vertex positions and all \(T=O(N\log N)\) allocated rows, and can be chosen to ensure \(d_N>4T\). As \(N\) ranges over powers of two, \(d_N\) strictly increases and determines \(N\) uniquely. Thus the public rows below depend on the dimension alone. Irrelevant dyadic dimensions may be assigned any public rows.

For an edge between distinct coefficient positions \(p,p'\), use the base row \(X^{-p}-X^{-p'}\) multiplied by the specified \(u\ne0\). Its product against \(s\) at coordinate zero is \(u(s_p-s_{p'})\). Multiply each allocated row by a public monomial shift \(X^t\), shifting its observations by the same signed coordinate permutation. These shifts do not change its objective because \(f_b\) is even. Use a fixed greedy shift making the two support sites disjoint from all previous supports. For each previously used support site at most two shifts are forbidden; there are two sites per previous row, so \(d_N>4T\) guarantees an available shift. If dense local patterns are desired, first space the vertex positions by \(J+1\), require distinct support sites at cyclic distance \(>J\), and enlarge \(C\) by a fixed factor; the same greedy bound as in [the dense theorem, §2](https://github.com/mxym/math/blob/d21809f0ebdf2c8982aeae91095ed929b05d0cf3/research/euclidean-tensor-geometry/theoretical-cryptography/ring-lwe-dense-pattern-balanced-hardness.md#2-spread-supports-in-a-fixed-design-coloring-reduction) applies. The binomial rows are units because after factoring a unit scalar and monomial the remaining \(1-W\), \(W=\pm X^h\) with \(0<h<d_N\), has \(W^{d_N/\gcd(d_N,h)}=-1\); the geometric factor gives an inverse up to the unit 2.

Write \(h_b=\log f_b\), \(H=\sum_{c\in\mathbb F_q}h_b(c/q)\), and write \(z=s_p-s_{p'}\) for an edge difference. For each group of \(q(q-1)\) rows at fixed \(u\), make each coordinate other than zero visit each observation phase \(q-1\) times. These terms are constant in the label. All instance dependence lies in the choice of coordinate-zero phases within that group, before applying its public shifts:
* An inactive edge uses each phase \(c/q\) exactly \(q-1\) times, so the slot is constant.
* An inequality edge uses each nonzero phase \(q\) times, no zero. Summing this coordinate over \(u\ne0\) gives
  \(q[(q-1)H-\sum_{u\ne0}h_b(uz/q)]\).
* An equality edge uses zero every time. Its sum is \(q(q-1)\sum_{u\ne0} h_b(uz/q)\).

For \(z=0\), the inner sum is \((q-1)h_b(0)\); for \(z\ne0\) it is \(H-h_b(0)\). Hence inequality satisfaction increases the total objective above the slot's baseline by \(\kappa=q(q h_b(0)-H)>0\), and equality satisfaction increases it above its own baseline by \((q-1)\kappa\). The positivity follows from the Fourier coefficients, since \(f_b(0)>f_b(c/q)\) for \(c\ne0\); the periodized Gaussian expression gives \(f_b>0\). In particular, if perfect satisfaction is possible then every exact optimizer satisfies all active constraints, and if impossible none can. This is a single-call optimization reduction checked by finite arithmetic on the returned label; no transcendental threshold is compared. At \(q=3\), all nonzero residual phases have the same density. If \(\gamma=h_b(0)-h_b(1/3)>0\), the likelihood is exactly \(Td_N h_b(0)-\gamma D(s)\), where \(D(s)\) is coefficient-Hamming distance. At \(s=0\) all active equalities hold and no active inequalities hold. Thus \(D(0)-6I\), for \(I\) active inequalities, is the exact integer threshold for perfect satisfaction. Membership in NP just multiplies a supplied label by the public rows and counts errors.

For the dense option apply the deterministic common unit multiplier of [the dense theorem, §3](https://github.com/mxym/math/blob/d21809f0ebdf2c8982aeae91095ed929b05d0cf3/research/euclidean-tensor-geometry/theoretical-cryptography/ring-lwe-dense-pattern-balanced-hardness.md#3-a-deterministic-common-multiplier-producing-all-the-local-statistics). That argument only uses the spaced, disjoint two-site supports and fixed \(q\), not any property of the edge enumeration in the earlier reduction. It gives precisely the bounded local-pattern estimate, and the common multiplier gives a bijection of label variables preserving the likelihood objective, distance, and observation data. Its construction remains polynomial in \(d_N\) for fixed pattern parameters.

## 4. Quasilinear dimension and ETH

For completeness, there is a linear construction from sparse 3-CNF to graph 3-colorability. Introduce a common Boolean reference variable \(z_0\); for each clause \(a\vee b\vee c\), use \(\operatorname{NAE}(a,b,c,z_0)\), where \(\operatorname{NAE}\) means the listed Booleans are not all equal. Because all these constraints are invariant under complementing every Boolean variable, one may take \(z_0\) false. With that choice the four-variable clause is equivalent to the original OR. Split it into two three-variable clauses
\(\operatorname{NAE}(a,b,w)\) and \(\operatorname{NAE}(\neg w,c,z_0)\) with a fresh \(w\). To check the split, equal first two values force \(w\) to their opposite, equal last two force \(w\) to their value, and the requirements conflict exactly when all four values are equal. If either pair is unequal its corresponding requirement is automatic.

For graph coloring, fix a triangle of palette vertices \(T,F,B\). Make both literal vertices of each Boolean variable adjacent to the palette vertex \(B\) and to each other, forcing opposite colors in \(\{T,F\}\). For every three-variable not-all-equal clause, add a new triangle with each of its vertices adjacent to the corresponding literal. If all three literal colors agree, only two colors are available to the added triangle, so coloring is impossible. If they are mixed, the two triangle vertices corresponding to the repeated literal color can take the opposite color and \(B\), and the third can take the repeated color. Thus the clause gadget is exact, with \(O(1)\) vertices and edges per clause. For fixed \(q>3\), add a universal clique of \(q-3\) vertices to reduce to \(q\)-colorability without changing the linear bound for sparse input. Apply the equality-chain degree reduction of §2. For a 3-CNF with \(n\) variables and \(O(n)\) clauses, the bounded-degree input size is \(O(n)\), so the resulting ring dimension is \(d_N=O(n\log n)\). The construction and all decoding of its certificate use polynomial time in \(n\).

The [Impagliazzo–Paturi–Zane sparsification lemma](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/ImpagliazzoPaturiZane_2001_jcss.pdf) gives the standard sparse-3-CNF consequence of ETH: a subexponential deterministic algorithm on sparse formulas would violate ETH. A target algorithm of running time \(\exp(o(d/\log d))\) would yield such a running time after this reduction, since \(d_N/\log d_N=O(n)\) and polynomial preprocessing is negligible on that scale. This proves the conditional statement. Without ETH the same reduction proves NP-hardness and ternary NP-completeness.

## 5. Scope

The [earlier fixed sparse argument](https://github.com/mxym/math/blob/305aab03fea43ba9748ff4a62badc6e76c8f466f/research/euclidean-tensor-geometry/theoretical-cryptography/ring-lwe-fixed-sparse-likelihood-hardness.md) uses all pair slots and thus has a quadratic dimension when called with a sparse graph. The new improvement is the fixed routed host graph with only \(O(N\log N)\) potential edges, plus equality/inequality switching at each observation slot. The routing overhead is optimal for this particular universal path architecture: if a fixed graph realizes all permutations by vertex-disjoint paths, the subset of edges in a realization determines its inlet-to-outlet pairing, so it needs at least \(\log_2(M!)=\Omega(M\log M)\) edges. This is not a lower bound on other kinds of fixed-design reductions. The theorem does not assert gap-approximation hardness with this new dimension; route violations could affect the fraction of satisfied constraints, which the exact reduction does not need to control. It gives no average-case implication, no recovery procedure, and no statement about actual cryptographic systems.
