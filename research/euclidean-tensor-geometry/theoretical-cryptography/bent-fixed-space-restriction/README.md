# When odd-order restriction preserves Boolean bentness

The fixed-space restriction of an odd-order-invariant bent Boolean function is bent in algebraic degree at most three, by Vono (ePrint 2026/2844). This note gives an explicit quartic bent function in eight variables and an order-three linear symmetry whose four-variable fixed-space restriction is not bent. Both the degree and ambient dimension are minimal. The counterexample extends to actual repeated-block fixed spaces of an odd-order coordinate rotation, without claiming invariance under the entire rotation group.

For a fully rotation-symmetric bent function on n=4ℓ^a coordinates, with ℓ odd prime and a≥1, we determine the following necessary period-four fold. For ℓ≥5 it is bent; for ℓ=3 it is either bent or an affine function changed at one rotation-fixed point. We express the two defining folded coefficients by exact ANF orbit parities and specialize them to quartics. A separate fully cyclic 12-variable quartic (not bent) has a balanced invariant cubic derivative whose period-four restriction is not balanced.

These results do not settle homogeneous quartic rotation-symmetric bent existence. The homogeneous n=12 case was already closed in ePrint 2026/2949. The modular argument is in the setting of the earlier ePrint 2026/2900, and modular-only nonbent examples were already published; the first counterexample here is an actual bent parent.
