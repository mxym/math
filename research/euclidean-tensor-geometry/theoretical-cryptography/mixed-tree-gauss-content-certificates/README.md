# Prime-content certificates for constant monomial fibres

A tree of mixed plane correspondences can have entire curve components on which a monomial is constant. In the predecessor note, sampling a common finite affine slice put the exceptional positive integer values in an explicit short list. This follow-up uses generic endpoint coefficients instead of evaluating them at an integer. It gives a computable prime-support certificate, and for certain high-height catalogues rules out all positive integer exceptional levels greater than one.

The primary result is about algebraic curves and rational monomial values. Its arithmetic corollary is limited to a fixed number of distinct prime factors obeying the stated connected-catalogue promise; coefficient magnitudes need not be polynomial. It is not a theorem about general integers. The two scripts check fixed symbolic and finite arithmetic fixtures only. Neither accepts an input integer to factor.
