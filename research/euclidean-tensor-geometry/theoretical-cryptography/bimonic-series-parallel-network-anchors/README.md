# Shared-variable anchors in two-terminal polynomial networks

An explicit series/parallel AND formula can be generically empty even though its constituent paths share a generic endpoint. The theorem gives an exact polynomial-size exceptional-source certificate for bimonic labels when the maximum leaf degree to the longest path length is polynomial. Each local operation guard is pulled back once along a canonical raw path.

For a uniform public catalogue, the arithmetic consequence gives deterministic polynomial-bit membership and full factorization **only** for connected prime supports with a genuine prime-labelled witness of a generically empty listed network. Support size and multiplicities are arbitrary. This is not a general factoring theorem or a catalogue-discovery result.

See PROOF.md for the proof, UPSTREAM.md for prior art, and RESULTS.txt for expected checker output. Run:

```sh
sha256sum -c SHA256SUMS
python3 -B verify_symbolic.py  # tested with SymPy 1.14
python3 -B verify_finite.py    # Python 3.9+ standard library
```

Both checkers are fixed-data validation only; neither accepts an integer to factor.
