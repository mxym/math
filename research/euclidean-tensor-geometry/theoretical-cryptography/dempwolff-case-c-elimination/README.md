# Addendum: case (c) cannot occur

**Claim.** In [U. Dempwolff, *Geometric and design-theoretic aspects of semibent functions II*](https://doi.org/10.1007/s10623-011-9511-3), *Designs, Codes and Cryptography* **62** (2012), 241–252, Proposition 3.3(c) has no examples. This answers the penultimate question of §4, Remarks (b) following Example 4.3, in the [author's manuscript](https://www.researchgate.net/publication/220638584_Geometric_and_design-theoretic_aspects_of_semibent_functions_II). The other three alternatives are realized by examples in the original paper.

**Proof.** Write $V=\mathbb F_2^{2n+1}$. Case (c) requires a type I.a semibent function $f=\mathbf 1_B$ and a nonzero $v\in B$ with $f(x+v)=f(x)$ for all $x$. Type I.a has $2^n+1$ pairwise trivially intersecting $n$-spaces, with $B$ their union. Thus $|B|=1+(2^n+1)(2^n-1)=2^{2n}$: $f$ is balanced, so its Walsh coefficient $W_f(0)$ vanishes.

The unnormalized Walsh coefficients $W_f(u)=\sum_x(-1)^{f(x)+u\cdot x}$ are $0$ or $\pm 2^{n+1}$. By Parseval their squared sum is $2^{4n+2}$, so their support has exactly $2^{2n}$ elements. Changing the summation variable to $x+v$ gives $W_f(u)=(-1)^{u\cdot v} W_f(u)$. Its support is therefore contained in $v^\perp$, which also has $2^{2n}$ elements. The sets must coincide. In particular $W_f(0)\ne0$, a contradiction. This excludes derivative **zero**, not all linear structures: a balanced semibent function can have a derivative identically one, as in alternative (b).

**Attribution.** This is an application, not a new spectral theorem. In particular the proof of Theorem 7 of [Canteaut–Carlet–Charpin–Fontaine (EUROCRYPT 2000), pp. 519–520](https://who.paris.inria.fr/Anne.Canteaut/Publications/Canteaut_Carlet_Charpin_Fontaine00.pdf) already uses the corresponding balance and hyperplane observation. Searches by the source title, case label and partial-spread terminology, including the original article's indexed forward citations, did not locate a paper explicitly applying it to Dempwolff's question (checked 2026-11-27). No general novelty is asserted.

Optional finite illustration: run `python3 verify.py` (Python 3.10+, no dependencies). In dimensions 3 and 5 it exhausts truth tables having derivative identically zero or identically one along one fixed nonzero coordinate and checks the entire Walsh support. The dimension-independent proof above does not depend on that computation.
