# Prime polynomial values between public root centres

Suppose a public catalogue contains monic integer polynomials, each labelled with one disk containing all its roots. Suppose the prime factors of an integer are themselves values of catalogue polynomials at hidden integer arguments in an unknown short interval.

Unlike the preceding one-sided result, the arguments can be between the disk centres, where the natural product is not monotone. A bounded integer sum from the first coefficients gives an effective centre for each group of roots. After this adjustment a second-order estimate locates all the hidden arguments using either a level point or a nearby critical point.

This is a deterministic polynomial-bit-time theorem on a specific arithmetic promise, not a general integer factorization algorithm. There is no fixed bound on the number of different prime factors, degrees or multiplicities. The two small checkers take no argument and test only finite mathematical fixtures. The stationary example separates candidate types for its true aggregate, not the behaviour of the full enumeration with one candidate type removed.
