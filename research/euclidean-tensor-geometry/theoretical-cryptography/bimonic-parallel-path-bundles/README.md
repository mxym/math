# Parallel algebraic paths as finite anchors

An arithmetic graph can have a connected prime support even though every genuine closed walk has an identically zero diagonal eliminant. Several public words with a common start and common end give a different kind of anchor: their generic endpoint polynomials can have no common root even when every pair does.

A length-uniform public catalogue may list bundles with a polynomially large number of words. The theorem gives deterministic polynomial bit complexity for complete prime factorization on the resulting promise. It does not enumerate arbitrary subsets of the word catalogue. Neither the primes nor their path witnesses are supplied, and arbitrary multiplicities are allowed. The scripts verify only finite algebraic examples; they take no external input.
