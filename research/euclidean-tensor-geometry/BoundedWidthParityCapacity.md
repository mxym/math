# Bounded-width parity codes have computable rational rate

**Yongxian Zhang.** AI-assisted proof development and internal verification; no external peer review or priority claim.

Fix a finite field \(\mathbb F_q\), a symmetric set \(D\subseteq\mathbb F_q\) containing 0 (the one-coordinate confusability differences), and a treewidth bound \(w\ge0\). For a parity-check matrix, define its check support graph on its rows: two rows are adjacent when some column is nonzero at both rows. A code in this restricted class is any affine subspace admitting a representation of this width for its parallel linear subspace. Column supports need not have size two: the treewidth bound forces them to have size at most \(w+1\).

**Theorem.** Among zero-error codes of this restricted class, the supremal normalized dimension is a computable rational number. More precisely the capacity is \(q^{1-\lambda_*}\), where \(\lambda_*\) is the optimum of an explicit finite rational linear program. In particular, for the seven-cycle the capacity is strictly below the Lovász value for every fixed \(w\). This does not give a uniform gap independent of \(w\). At \(w=1\) the [explicit forest proof](C7ForestParityCapacity.md) gives \(1-\lambda_*=3/5\).

## 1. Exact grammar on separator syndromes

The zero-error condition on \(\ker H\) is that \(Hx=0,\ x\in D^n\) forces \(x=0\). Translating the code has no effect. For a partial check system with a bag of currently exposed (named) rows, record the set \(S\) of all bag syndromes realized by coefficient choices in \(D\) that have zero syndrome on every hidden row. Retain a partial system only if its zero bag syndrome is realized uniquely by the zero coefficient vector. A zero violation in a partial system would extend by zero coefficients to a violation in the full system. Thus discarding it cannot lose a valid finished code. All residual sets are symmetric and contain zero.

There are only finitely many states: the bag is a subset of \(w+1\) slots and its residual set is a subset of the corresponding finitely many syndromes. Starting from an empty bag and no columns, use these productions.

- Introduce one row in an empty slot: append a zero component to all syndromes. There are no previously inserted columns at that newly present row.
- Forget a row: restrict to syndromes having coordinate 0 there, then project off that coordinate. Count one row at this step. The zero-fiber restriction is essential.
- Insert one column supported on the bag: join with the residual set \(\{d h:d\in D\}\) for the column vector \(h\) on the bag, provided this single column has unique zero. Count one column at this step; the other operations count none.
- Join two systems on the same bag, renaming their hidden rows to be disjoint. The result has residual set \(S_1+S_2\) and unique zero exactly when \(S_1\cap S_2=\{0\}\). Symmetry gives necessity since a shared nonzero residue can be canceled by its negative; sufficiency follows from uniqueness of zero in both children.

Accept at the empty bag, where the only residual state is \(\{0\}\). The represented systems automatically have check support graph of width at most \(w\): the introduction, forget, and join parse is a tree decomposition, and each column is introduced entirely inside one bag. Conversely start with any width-\(w\) tree decomposition, make it nice with empty root and leaf bags, and insert each column in a bag containing its entire support. Such a bag exists since column supports are cliques and subtrees of a tree satisfy the Helly property. Assign bag slots consistently along edges; a shared row preserves its slot, a new row takes a free slot, and fresh row names may reuse forgotten slots. Every row is counted once at its highest forget; at a join its shared bag rows have not yet been counted. Thus accepted parse trees exactly realize the attainable pairs \((n,m)\) of columns and check rows, with the zero-error requirement. The case \(D=\{0\}\) is also covered by allowing zero columns, but is trivial.

Deleting redundant rows keeps the code and cannot add support edges. Therefore optimizing \(1-m/n\) over represented systems with \(n>0\) is equivalent to optimizing normalized dimension: every code has a full-row-rank representation in this class obtained by deletion.

## 2. Potentials compute the best rate

Assign weight \(\lambda\) to each column insertion and \(-1\) to each row forget. A finite derivation has total weight \(\lambda n-m\). Eliminate unproductive states, and states that cannot occur in a complete accepting derivation; retain all productions that occur in some accepting derivation. These operations are effective by ordinary finite-state reachability for a grammar: compute states with a terminal derivation by bottom-up closure, then propagate reachability from the accepting root through the productive transitions.

Give each retained state \(s\) a real potential \(p_s\). Require, for each production with parent state \(s\), child states \(t_1,\ldots,t_j\), and local count pair \((\nu,\mu)\),
\[
p_s\ \ge\ \lambda\nu-\mu+\sum_{i=1}^j p_{t_i},
\]
and require \(p_{\rm accept}\le0\). Feasibility implies every accepting parse tree has weight at most 0 by induction. Conversely, suppose all accepting parse trees have weight at most 0. For each useful state \(s\), fix an accepting derivation with a hole of that state, including fixed derivations at all sibling subtrees along the path to the hole. Any valid \(s\)-derivation can substitute into this hole. It follows that its weight is bounded above by the negative weight of the fixed context; hence the supremum \(p_s\) of the weights of its derivations is finite (and not minus infinity, by productivity). The independent substitutions of child derivations show these suprema satisfy every production inequality, even if they are not achieved by single trees. The accepting potential is at most zero.

Thus the LP is feasible exactly for \(\lambda\le\inf_{n>0}m/n\); the terms with \(n=0\) impose no further restriction since their weight is \(-m\). Its finite rational coefficients and bounded objective give a rational computable maximum. Disjoint union preserves the width restriction and produces tensor powers of any code, so the normalized-dimension supremum indeed gives the asymptotic capacity as well. For exact finite lengths one can pad a code by one fixed coordinate, represented by a fresh single-row check, so the usual length limit exists by superadditivity.

## 3. Why C7 has a genuine bounded-width gap

For \(C_7\) the global Lovász upper bound is \(t=7u/(2+u)\), where \(u=2\cos(\pi/7)\). The element \(u=-(\zeta_7^3+\zeta_7^{-3})\) generates the real cubic subfield of the seventh cyclotomic field, since \(\zeta_7^3\) satisfies a quadratic over \(\mathbb Q(u)\) and is not real. Conversely \(u=2t/(7-t)\), so \(\mathbb Q(t)\) is that same totally real cubic field. If \(t=7^{a/b}\) with coprime positive integers \(a,b\), Bézout's identity gives \(\mathbb Q(t)=\mathbb Q(7^{1/b})\). Eisenstein at 7 forces \(b=3\) by degree, but \(\mathbb Q(7^{1/3})\) has nonreal conjugate embeddings, a contradiction. Thus \(t\) is not a rational power of 7. The LP capacity is a rational power and at most \(t\), hence is strictly below it at every fixed \(w\). Arbitrary finite affine codes are captured somewhere in the hierarchy, so taking the supremum over all widths recovers the ordinary *linear* capacity, with no assertion about whether that supremum equals the upper bound.

This combines the [linear Shannon capacity setup](https://arxiv.org/abs/2009.05685), [tree-decomposition automata](https://arxiv.org/abs/1605.03045), and [Lovász theta](https://doi.org/10.1109/TIT.1979.1055985). The finite grammar and weight-potential characterization above are given directly, without needing a black-box Parikh theorem. Searches for this parity-support width restriction found no directly equivalent result. Neither unrestricted linear nor ordinary Shannon capacity of \(C_7\) is determined.
