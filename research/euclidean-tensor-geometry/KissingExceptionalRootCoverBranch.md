# Exceptional roots: sharp (60^circ) covering multiplicities and a conditional kissing obstruction

Normalize the exceptional roots to unit length. Any unit vector other than these root points has inner product strictly above 1/2 with at least 5, 6 or 8 roots of E6, E7 or E8, respectively. These constants are attained. This is a finite chamber calculation; it does not state that all six-dimensional kissing configurations have at most 72 points.

Use simple roots of norm squared two on the chain 0--1--...--(n−2) with node n−1 attached at node 2. Weyl reflections reduce the unit vector y to the closed fundamental chamber. Set x=√2 y and w_i=⟨x,α_i⟩; then w≥0 and wᵀG⁻¹w=2 for the simple-root Gram matrix G. A positive root with simple coefficients r conflicts exactly when r·w>1; nonpositive roots cannot conflict. A conflicting subset is upward-closed in the coefficientwise order. Enlarge to an upward-closed subset of size k if needed, adding a maximal remaining root at each step. For every such subset, constrain only the maximal roots in its complement (each remaining root is dominated by one): r·w≤1. This defines a bounded polytope with w≥0. The positive definite quadratic wᵀG⁻¹w has its maximum at a vertex, and if every vertex has value ≤2 then equality can occur only at a vertex. Thus it is sufficient to remove k=4,5,7 general upward subsets, respectively, and disprove all norm-two vertices except the highest root in that chamber.

The exact checker generates the roots by simple reflections, enumerates every upward subset by adjoining a maximal remaining root, enumerates the active constraint bases at each vertex, and computes vertices and norms using rational Cramer's rule with fraction-free integer determinants. For the three tests respectively it finds two upward subsets and 42,34,40 feasible active bases; all vertex norm-two equalities give only the highest root. Repeated active bases at the same vertex are harmless. For sharpness, choose the direction of the nonnegative simple-inner-product vector e₁ for E6, e₅+e₆ for E7, e₇ for E8, using zero-based indices, scaled to norm squared two. Checking the squared integer inequalities after scaling gives precisely 5,6,8 strict conflicts. For E7 and E8, separately enumerate all upward sets of size 6,8; the only other points with norm squared two are (e₅+e₆)/2 and e₇/2 respectively. Thus each of those two ranks has a single Weyl orbit of non-root minimizing points. The E6 minimum is not claimed to be a single orbit.

## Application at maximal independent line subsystem

For a kissing code call x,y adjacent when x·y<−1/2. For an independent subset, the absolute inner-product condition is ≤1/2, including that there are no repeated unoriented lines. The maximum projective line code sizes for dimensions 6,7 are P=36,63, and the systems attaining those sizes are E6 and E7 respectively. Equivalently double the lines by taking both signs and apply [Kurt Anstreicher's classical antipodal bounds and uniqueness](https://optimization-online.org/2001/01/248/). Suppose a code of cardinality 2P+1 contains such an independent subset, orienting all P axes. Every outsider is a point not on those axes. If an outsider could be paired with its antipode, both signs could not avoid the strict conflicts with the P oriented roots, so every true pair must be on one of the P axes. If p is the total number of true pairs, u=P−p axes are unpaired, and there are exactly u+1 outsiders.

For each outsider y, some m of the root points have ⟨y,r⟩>1/2 (m=5 for E6 or 6 for E7 is enough). These belong to distinct axes, none paired. The selected code orientation on each of these axes must be −r, a negative neighbor of y. Therefore every outsider has a blocker set of at least m within the u unpaired axes. For adjacent outsiders y,z, their blocker sets must be disjoint: a common negative neighbor would form a negative triangle, whose three vectors would have sum of negative squared norm. If u<2m there are no negative edges between outsiders. Then choose one unit vector from each of the p true pairs, all u+1 outsiders, and no root singles. A vector in a true pair is compatible in absolute inner product with every other vector; the outsiders are compatible in absolute inner product by construction. This yields p+u+1=P+1 distinct eligible lines, contradicting the projective bound.

Thus, **conditional on containing a maximum-sized independent subset**, a 73-point six-dimensional code has at most 26 antipodal pairs, and a 127-point seven-dimensional code has at most 51. The unrestricted prior thresholds are different and those unrestricted results are unchanged. This proof does not require maximizing the number of true pairs. At u=2m, every negative edge between outsiders joins the fibers of complementary blocker masks of size m; in particular the negative graph induced on outsiders is bipartite (disconnected complementary-mask pairs and isolated vertices). This last observation does not yet rule out u=2m.

Related sources: the classical antipodal bounds/uniqueness above and [Cohn–Kumar](https://arxiv.org/abs/math/0607446) for spherical root-system configurations. The latter is not a citation for these multiple-cover counts. A focused search found no matching multiplicity theorem; no absolute priority claim. ## Why complementary blocker masks cannot be ruled out just from a pair

In E6 simple-root coordinates, with the same Gram matrix G as above, take
```
X=(49,98,126,88,50,66)
Y=(-37,-74,-111,-112,-113,-36).
```
Their squared lengths are 3054 and 11478, and their inner product is −3126. On normalization, their inner product is less than −1/2, since 4·3126²>3054·11478. An oriented root with coefficient vector r is a strict blocker for X precisely when rᵀGX>0 and 2(rᵀGX)²> XᵀGX; the same test applies to Y. Each has exactly five blockers and their blocker axes are disjoint, as the verifier shows. Orient the ten blocker axes away from their respective conflicts and take both signs on the other 26 axes. Adding X and Y normalized gives a 64-point partial kissing code with a negative outsider edge and complementary exact five-masks. Thus the mere existence of a negative edge among outsiders does not contradict the geometry at u=10. This is neither a 73-point example nor an exclusion of the u=10 branch.
