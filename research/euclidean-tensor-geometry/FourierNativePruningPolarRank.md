# Native radix pruning cannot cheaply convert the binary ETG residual

**Yongxian Zhang.** AI-assisted proof development and internal checks; no external peer review claimed.

Restricted obstruction for the binary prime tensor kernel in the primary OpenAI preprint, pinned [kernel.tex](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-finite-Fourier-transforms-November-24-2026/build/kernel.tex). This tests a different proposed compiler improvement, namely doing direct sparse recovery on each predictor residual row by pruning a classical radix transform, instead of paying full spectral conversions. No general sparse Fourier complexity or endpoint lower bound is asserted.

## Setup

Let V be the binary frequency space split into m distinguished blocks and a auxiliary blocks, each of dimension 2f, so n=2f(m+a), N=2^n. Each block carries the nondegenerate quadratic form q_i(X_i,Z_i)=X_i·Z_i of polar rank 2f. The query functions are Q_j=(-1)^(q_j+q_aux), with q_aux the sum on the auxiliary blocks. In the native construction m is odd, so the target T=product_j Q_j=(-1)^(sum_i q_i) has polar rank n. Fix any complex polynomial p(Q_1,...,Q_m) of multilinear degree at most d. Let S={v∈V:p(Q(v))≠T(v)}. In a matrix predictor take p to be any diagonal entry; the row support of the residual contains the mismatch for that entry. All coefficients may be arbitrary. This includes central-shift diagonal predictors, regardless of accidental equalities outside the interpolation band.

## Global reindexing and any order: at least the first half of the butterfly has full width

For every linear surjection \(L:V\to\mathbb F_2^k\), if
\[
 n-2k > 2f(d+a)+\log_2\!\left(\sum_{j=0}^{d}\binom mj\right),
\]
then L(S)=F_2^k. Here 0≤d≤m. Consequently, if a=o(m) and d=O(sqrt(m log m)), for arbitrary f≥1 and all sufficiently large m, every invertible (global, not necessarily block-local) affine basis change on frequencies and every radix-2 Walsh order produces a residual-output pruned butterfly with at least (1/2−o(1)) n full-width layers. Compensating transpose basis changes on ordinary inputs is just a permutation and possible diagonal signs, so does not affect this statement.

Proof. On any affine fiber v+K of L, dim K=n−k. A quadratic phase (-1)^q on K of polar rank r has exactly 2^r nonzero additive Walsh coefficients. Indeed, for a normalized coefficient at character lambda, square its absolute value and put one summation coordinate equal to the other plus h. Summing over the other coordinate gives zero unless h is in the radical of the polar form, in which case it gives the sign (-1)^(q(h)+q(0)+lambda(h)). Sum this over the radical: q(h)+q(0) is linear there, so the squared absolute value is either 2^(−r) or zero, and there are exactly 2^r lambda extending the required radical character. Translation by v changes only the affine terms and not the polar rank. For the target quadratic, the global polar form is nondegenerate, and the radical on K lies in K-perp, of dimension k. Thus r≥n−2k. The predictor is a sum of at most ∑_{j≤d} binom(m,j) quadratic phases (there is one possible monomial for each subset). Their quadratics involve at most d distinguished and a auxiliary blocks; their global polar ranks and therefore restricted polar ranks are at most 2f(d+a). The Walsh support of the restricted predictor is contained in the union of the respective supports and so cannot contain the target's on any fiber if the claimed inequality holds. In particular every fiber has a mismatch. In the parameter regime stated, log_2∑ binom(m,j)=O((d+1)log(m+2))=o(m) and 2f(d+a)=o(n).

For clarity, at Walsh butterfly cut k the coordinates are (k already transformed frequency coordinates, n−k still ordinary coordinates). An output set S keeps exactly |projection_k(S)| times 2^(n−k) nodes on this cut by ancestor pruning: all remaining ordinary values reach any final output with the same frequency prefix, and different prefixes never interact upstream of their cut. A retained output of a radix-2 butterfly is a nontrivial sum of its two predecessors. Therefore every full-width cut contributes at least N/2 nontrivial radix-2 butterflies, or N weighted scalar output operations in ordinary radix accounting. Keeping only paths that reach S takes Ω(N n) work. The transpose of this pruned DAG, forming an inverse transform from arbitrary supported spectral input (up to signs, permutations and normalization), has the same full-width early cuts in the opposite direction. This analysis concerns pruning the given graph, not algebraic refactorization.

## Blockwise reindexing and any interleaving: almost every layer has nearly full width

Suppose the basis changes are separate within each distinguished block and do not mix these with auxiliaries (coordinate order still arbitrary). At any cut with B incomplete distinguished blocks (each with at least one unseen bit), the fraction of retained nodes is at least Pr[Bin(B,1/2)>d]. In particular if B≥4(d+1) the fraction is at least 1−exp(−cB) for an absolute c>0.

Proof. For each incomplete block, choose any nonzero hidden direction h. The derivative q_i(x+h)−q_i(x) has nonzero linear part by nondegeneracy, so for uniformly random full block x it is one with probability 1/2. Thus at least half of the possible observed block prefixes admit a completion with derivative one and hence admit both values of q_i. This adjustability event is independent across blocks for a uniform observed prefix. Freeze the aux frequencies to any completion; they now provide only a common fixed sign. If L blocks are adjustable, reachable query tuples contain a full L-dimensional Boolean cube (freeze each nonadjustable block to any completion), on which the target is nonzero sign times parity and the predictor restricts to degree at most d. If L>d the two cannot coincide on that entire subcube by character independence. Binomial stochastic domination gives the result. If s bits remain unobserved then s≤2f(a+B), so only the last O(f(a+d+1)) cuts can have B<4(d+1).

## What this leaves open

The proof relies on actual direct transform outputs for each residual's support, with the native radix graph or its transpose. The preprint uses algebraic joint checks across many rows rather than this proposed direct rowwise substitute. The result does not rule out cross-frequency linear coding, a different sparse Fourier factorization, a joint nonlinear description of control with actual linear gates, or other cross-address circuits. No assertion is made about priority for the standard quadratic Walsh support identity.
