# Exact alternating quantum max-flow on every shared-tensor eight-cycle

**Yongxian Zhang.** AI-assisted proof development and internal checks; no external peer review claimed.

Let \(F_8(q)\) denote the maximum alternating flattening rank in the complex periodic eight-cycle with one shared tensor and both dimensions \(q\). The complete classification is:

- \(F_8(2)=12\), by the existing binary-optimum proof.
- \(F_8(q)=q^4-1\) if \(q\equiv3\pmod4\).
- \(F_8(q)=q^4\) for every other positive integer \(q\).

The odd cases are in the [verified odd-dimensional archive](https://github.com/mxym/math/releases/tag/periodic-eight-cycle-odd-quantum-max-flow-v1.1.0). The binary upper bound comes from [Gesmundo–Landsberg–Walter, Theorem I.5](https://arxiv.org/html/1801.09106#S1.SS4), attained by the [archived binary lower bound](https://github.com/mxym/math/blob/16a0c94c6893cff67780fbb64b0c4bc8addffbf1/paper.md). The new argument below covers every even \(q\ge4\) simultaneously; square dimensions were previously known by GLW Remark I.6. It does not claim a solution for cycles of every length or heterogeneous dimensions.

## Statement and witness

For q=2+2r with r>=1, let F8(q) be the maximum rank of the alternating 4-versus-4 flattening of the periodic, one-site, shared-tensor C8 state with physical and bond dimensions q. The construction below proves F8(q)=q^4 over C. It uses exact arithmetic on local modules of at most two opposite classes, not extrapolation of small q full ranks. The q=2 case is not included.

The physical labels and bond states are core {0,1} and r signed classes {a,-a}; negation fixes both core labels. In matrix-unit notation the unperturbed slices A0,A1 are supported on the two-state core with respective matrices [[4,5],[2,8]], [[3,7],[13,11]], and A_a=E_{0,a}+c_a E_{-a,0} for each signed noncore label a. The c variables are independent initially. Perturb by t times: (i) for each noncore slice A_a, arbitrary diagonal loops on its two leaves; (ii) for each core slice A_k, arbitrary tilted returns from each leaf to either core state. There are no other perturbations. An old mark of class i is a loop or tilted return at a leaf of class i.

Write M(a,b)=tr(A_{a0}A_{b0}...A_{a3}A_{b3}); the word rotation commutes with this matrix, including after relabeling columns b as the labelwise negative of b. Use rotation-eigenvalue orbit coordinates: input sum over cyclic shifts with weights z^j, output evaluation at the orbit representative, and discard orbits with z^orbit-length not 1. Work in the signed-column convention throughout; we do not need Pfaffians or skew-normalization for this proof.

## Base blocks and exact null coordinates

At t=0, every excursion to a leaf is a dimer consisting of an outgoing spoke followed immediately by its opposite-label return; each dimer contains one row and one column position. A word containing a core label therefore lies in a block indexed by its signed multiset of noncore labels (with relabeled columns). The matrix element can be evaluated by starting at a core label, multiplying its and other core slices as 2x2 matrices and each adjacent noncore dimer as c times E00 on the core. If no dimer tiling is possible the entry is zero. Noncore multisets have sizes 0 through 3 in such base blocks and occurrence types exhaust the ten cases in c8-even-core-base.js (classes or signed orientations may be renamed). That modular certificate at p=1009 shows all such blocks are full rank generically except the following:

* The core-only 16-dimensional space: sector dimensions (6,4,3,3) for z=1,-1,i,-i, with exact ranks (6,2,2,2).
* A nonself inverse-pair multiset {a,-a} with two core letters: 48 dimensions, 12 in each sector, with exact rank 10 in z=-1 and full in the other sectors.

The two required exact upper bounds here are verified by c8-even-core-sym-fixed.py over Q(i) for the fixed core matrices and over Q(c_a,c_-a) for the 12x12 mixed block. The nonzero modular minors certify generic lower bounds for the other mixed types and may be specialized separately by type. All c-only conditions can be intersected in a common generic open set. Thus the retained kernel has core-only two coordinates C in z=-1, one core-only coordinate in each z=±i, and two coordinates E_i in z=-1 for each inverse pair i.

In zero-core words all dimers are simultaneously in one of the two alignments. In each rotation orbit the matrix is aI+b rotation (in relabeled columns); the two c monomials agree identically iff the signed multiset is inversion-invariant. Consequently the sole generic null directions here occur in sector z=-1 and in balanced multisets: K_ii for a repeated class (2 coordinates) and K_ij for two distinct classes (6 coordinates). This is unchanged from the one-core model; inserting an unperturbed core transition without a core label is impossible. Denote their union by K0.

Choose base pivots within each multiset and sector; keep complementary residual representatives, replacing them conceptually by their kernel vectors using the pivots at order zero. This is equivalent to the exact Schur complement of the base pivotal block. For C and E_i use local pivot choices from the replay, chosen at c_+=2,c_-=3 for each signed class; these are nonsingular symbolic local choices and commute with class permutations once each E_i uses the same relative order of the core and its own signs.

## Quadratic locality

At order at most two a closed walk must visit the core: a walk staying at a leaf for all eight steps would need eight perturbations. Every excursion with exactly l marks stays within a single leaf class, and its noncore label count has parity l (a noncore loop adds one label, a tilted return deletes one, and unmarked dimers carry two). Its difference between row and column noncore counts is at most l in magnitude: deleting the possible core return label from its otherwise single-class string or inserting loop labels gives the stated bound, starting from a balanced dimer. The whole walk obeys these separate per-class bounds, and all unmarked classes occur as matched dimers. In the Schur complement the same budgets telescope along chains of positive-order steps separated by base inverses, since those preserve absolute counts. Complement corrections at order zero act only within the same multiset.

Every retained residual has even noncore total count and indeed even count in each class. Hence the first Schur coefficient is zero. From one perturbation a residual can contact an intermediate only by changing the total noncore count by 1 in the marked class. Intermediate counts are therefore: from C, one label; from E_i, one or three (three of one class, or two of i and one of another); from K_ii (all four labels of i), three of i; from K_ij (two of each), three distributed as 2+1. Only counts 1 and 3 and at most two classes occur. These entire base intermediate blocks are invertible at the symmetric copy, verified by exact modular ranks in the replay for q=4,6. In particular no three-distinct-class odd intermediate is needed, although the replay's odd checks certify all odd blocks it sees.

At order two both marks must be from the same class by separate parity. Therefore: K0-to-K0 can only connect the identical multiset, because the total count is 4 on both ends and only one class can change. The block K_ii depends only on i, and K_ij only on i,j: a virtual third marked class in a chain would require adding that class to an endpoint already of total count 4, forbidden at one mark. A direct contribution involving a class absent from both endpoints is also impossible (an excursion must start with an ordinary outgoing spoke carrying that label). The core-only residual has no order-two contact with K0. It receives a sum of local one-class contributions on the diagonal, and its coupling to E_i is local to i. Distinct E_i and E_j cannot couple directly at order two, since two classes would have unequal counts. An E_i diagonal receives a term using only i and a sum over one extra marked class at a time. The only K blocks touching E_i are K_ii or K_ij, with data on the respective one or two classes; if E_i adds another class j, the two-mark budget is fully consumed in j. These observations follow either directly by the difference bound or by the stated list of odd intermediates. They apply to the quadratic coefficient S2 of the formal base Schur matrix.

## Symmetric copy and final rank certificate

Specialize all signed-class parameters to the same pair of arrays (retain signs and distinguish classes as labels). In this operation the quadratic coefficient is a rational function with well-defined limit even if accidental base kernels appear in other even-count blocks at the symmetric copy. Indeed the formula for S2 is the base-kernel pairing of M2 minus the M1 passage through a base inverse; by parity only the odd-count blocks can occur in the latter. Kernel-coordinate corrections depend solely on the invertible base minors within their own retained block. Thus no complement inverse in an unrelated even-count block is needed. In particular the extra unbalanced even-count residual coordinates detected by the modular rank computation at the symmetric copy are omitted from its S2 matrix, as the script does. Near the copy use the generic base complements from the preceding section; the resulting S2 tends to the modular-certified rational matrix. No claim that the actual full M(0) attains generic rank at the copy is needed.

The K0 part of S2 is block diagonal, with one repeated-class and one mixed-class matrix by symmetry. Their determinants modulo 1009 for trial 0 are respectively 822 and 576, and for trial 1 are 294 and 274. Thus eliminate K0 in S2. In the resulting W on C and E_1,...,E_r, there are fixed two-by-two matrices G,D,F,A,B,C' independent of r, with C-to-C block rG, C-to-E_i block D, E_i-to-C block F, each E_i diagonal A+(r-1)B, and every E_i-to-E_j for i!=j equal to C'. To see this, the Schur correction uses one shared K block at a time. A diagonal E_i obtains its intrinsic one-class piece and a sum over other classes; the off-diagonal E_i,E_j can only come from K_ij. No additional virtual class is possible by the preceding locality statements. Thus the constants are determined by the q=4 and q=6 replays, and equality of the blocks for two classes follows abstractly by permutation. The replay also verifies the requisite block equalities directly in these local cases.

Over Q split the E vectors into the constant vectors and the sum-zero vectors; C is fixed. For r>=2 the sum-zero part uses the 2x2 matrix A+(r-1)B-C', repeated r-1 times. For r=1 that part is absent. The trivial part, in C coordinates and the common E vector, uses the 4x4 matrix
  [[rG, rD], [F, A+(r-1)(B+C')]].
Its determinant is exactly r^2 times the determinant of [[G,D],[F,A+(r-1)(B+C')]]. Use the normalized determinant modulo p=1009, not the determinant of the unnormalized trivial part. This keeps the proof valid for r divisible by p; the splitting and extraction of r^2 took place over Q before reduction.

The executable c8-even-core-jet.js supplies the two modular arrays (trial values 0 and 1) with the fixed core and c_+=2,c_-=3. It computes the local matrices by closed-walk enumeration through degree two, base Schur elimination in each sector, and K0 elimination for z=-1. It finds union of bad residues for the standard and normalized trivial determinant exactly {652} for trial 0, and exactly {395} for trial 1. These sets are disjoint; therefore for every integer r>=1 choose one successful trial. The core-only quadratic scalar in z=i and z=-i is r times the corresponding nonzero local value (640 and 522 in trial 0; 46 and 624 in trial 1). Factor r in characteristic zero here as well. The +1 sector has no generic residual.

A nonzero determinant at the rational symmetric limit implies a nonzero rational function in the independent c and perturbation variables. Choose generic nearby c with base complements nonsingular and all desired sector determinants nonzero; put another way, intersect finitely many nonempty algebraic opens. Then in each sector the base Schur matrix has leading term t^2 S2 with S2 invertible on its entire residual, so that the determinant of the full sector is a nonzero polynomial in t. The simultaneous nonvanishing of these determinants over C proves F8(q)=q^4. This is exact, with no claim of a universal nonvanishing witness for every t or by using the singular symmetric copy directly.

## Replay

Run `node c8-even-core-base.js`, `python3 c8-even-core-sym-fixed.py` (SymPy), and `node c8-even-core-jet.js`. For an extra modular check, `node c8-even-core-jet.js --audit-q8` tests the replicated second-jet blocks with three identical classes, not just the minimal local cases. This optional check is not a substitute for the locality and symmetric-limit argument.
