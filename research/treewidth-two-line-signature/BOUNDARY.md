# Pullback check: constraints, singular pivots, and substitution

Let the terminal map be any linear map S:V→ℝᵖ (its rows may vanish or coincide). A constrained state (C,U,Q) acts on that host by the stated restriction S⁻¹(U). All pullbacks here are *before* signatures; no claim that signature itself commutes with pullback is used.

In series, let the internal scalar x be a fresh variable and take as the initial host V⊕ℝ with map (v,x)↦(S(v),x). Each child comparison applies on that space with the other child's actual interior variables retained as additional host variables. After one replacement, its domain is a subspace W of that same host. Apply the second comparison on W, by restricting its host form and terminal map to W; the comparison is valid there since it was quantified over arbitrary real spaces/forms/maps originally. Thus both replacements are valid regardless of whether individual endpoint-equality conditions become redundant. In parallel no new x is added; intersect the pullbacks of the children’s domains in the same way. The same reasoning handles one-port decorations and forgetting one terminal.

It remains to justify that eliminating x to compute an output on **formal** terminal coordinates is valid after **any** such exterior map. Write the prior constraints as a_i x+ℓ_i(z)=0. If some a_i≠0, the constraint space above any exterior v is the graph of the same linear function x=−ℓ_i(Sv)/a_i. Substitution is an isomorphism onto the preimage of the residual exterior constraints and commutes exactly with S. If no a_i≠0, first restrict V to the preimages of those exterior constraints. The polynomial in x there is dx²+2x λ(Sv)+H'(v). For d≠0, shifting x by λ(Sv)/d is an invertible shear of this product space. It contributes sign(d) independently of the pullback. For d=0 let b=λ∘S on the already restricted space. If b=0, x is an uncoupled zero mode and does not change the signature. If b≠0, choose e in that space with b(e)=1 and split v=t e+v₀ with b(v₀)=0. The cross t-terms in H'(v) are removed by shifting x since its coupling is 2xt. The (x,t) plane is hyperbolic and has signature zero. What remains is exactly H' on ker b. Both cases therefore give the formal additional condition λ(z)=0 and zero signature offset after pullback. This argument does not choose an inverse on a projected boundary nor presume that the boundary has full rank. A dummy unused output coordinate (for the one-port test) can in particular be set identically zero.

The domination loss in the manuscript is uniform for the same reason. For W=U∩V, the map S carries S⁻¹(U)/S⁻¹(W) injectively into U/W. Thus its codimension is ≤dim U−dim W (and analogously for the competing domain). On S⁻¹(W) every positive-definite subspace of a pulled-back difference maps injectively to a positive-definite subspace of the original difference. The positive index bound and interlacing therefore hold for singular, zero or coincident terminal maps. This proves the required universal comparison property.
