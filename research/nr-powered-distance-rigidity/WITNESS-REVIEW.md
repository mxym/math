# Optional witness limit: independent PASS

Checked the separate note (SHA-256 3629d38e prefix); this is only a limitation of its function B, not a counterexample to the original conjecture. Fix a primitive Nth root w. Let S(z)=∑_{m=0}^{N-1}(1−m/N)z^m. The rational numerator of N(1−z)^2 S(z) is N−(N+1)z+z^{N+1}; at w this equals N(1−w), and its derivative vanishes. Hence wS′(w)=2w/(1−w)^2=−1/(2 sin²(π/N)). In the top-s-degree limit, each mth mode acquires t^{2k−m}. Fejér vanishing gives ∑_{m≥1}(1−m/N)Re(w^m)=−1/2. Differentiating this finite sum gives −2k+csc²(π/N) at t=1. For N≥19 this is positive, since sin(π/N)<π/N, π<22/7 and N²/(N−1) increases for integers N≥2, starting at 19²/18>2(22/7)² on the required range. Thus select a fixed t<1 sufficiently near 1 for a negative limiting B, and only then choose a sufficiently large finite s by pointwise convergence. This establishes failure of positivity at some (t,s,φ) for every such N. There is no construction of an entire constant-potential site configuration.
