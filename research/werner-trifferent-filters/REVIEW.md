*Parameter and bounds.* The filter succeeds with probability |A|/d^n, because the unfiltered Alice marginal is maximally mixed. This is nonzero also at t=1. At each site, W=I-t|Ω⟩⟨Ω| is one on unequal-letter coordinates, and is I-tJ on the equal-letter sector. This produces exactly the advertised mismatch sectors. Each symbol in the rearranged coefficient matrix belongs to a unique sector.

*Disjointness and rank.* For a parent (T,a,b), the mixed position (x,y_j) mismatches exactly on T and supp(x-j), with x,j equal on T. A third root agreeing with x on those sites contradicts separation of x,j and that third root; j itself is impossible. Competing charges j,j' give incompatible values for y on a separating site. Once j is specified the parent mismatch set is exactly supp(y-j). The left and right row/column restrictions are independent isometries, so each mixed matrix X_E has rank at most the original rank. Its singular-value estimate is valid for complex nonsymmetric matrices, as required. In particular, summing rank bounds across sectors is neither needed nor true in general.

All sectors and nonnegative uncharged singletons are included. For odd equidistance the all-ones vector on r chosen diagonal positions gives strict negativity after t_r, so the threshold is both necessary and sufficient. At t=1 modify the columns on the agreement set to avoid a zero common factor; choose relative sign to match the parity of h. At equality t=t_r the chosen test is a genuine zero, not negative. Rank 1 is trivial for any partial transpose; ranks≥M cannot exceed the Alice row dimension. The simplex code gives D=3^(k-1), n=(3^k-1)/2, M=3^k, including k=1 and the four-qutrit k=2.

This establishes single-block rank testing, not many-block distillability.
