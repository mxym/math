# Complete Caccetta–Häggkvist theorem map

Prepared before the mathematical phase,14October2026; all statements below refer to ordinary finite digraphs.

- **CH0 Original complete target.** For every integer n>=2, every r with1<=r<=n-1, and every loopless simple directed graph D on n vertices with minimum out-degree at least r, some directed simple cycle has length at most ceil(n/r). Antiparallel arcs are allowed; repeated arcs and loops are not.
- **CH1 Equivalent girth form.** For every positive integer r and every integer g>=2, minimum out-degree>=r and directed girth>=g imply n>=r(g-1)+1. Positive minimum out-degree ensures that girth is finite. The n=1/positive-r domain is infeasible; degree zero is outside the cycle-existence premise.
- **CH2 Actual matrix domain.** A is an n-by-n binary matrix, A_ii=0, with every row sum>=r. Set k=ceil(n/r). A legal counterexample has trace(A^j)=0 for every1<=j<=k, while n,r remain integers. Each diagonal term is a nonnegative exact count of closed directed walks; a closed walk contains a simple cycle no longer than itself.
- **CH3 Positive acceptance.** A complete ordinary proof must cover CH0/CH1 for all parameters and all digraphs. A triangle-only theorem, fixed r, finite n, Eulerian/regular/vertex-transitive class or improved constant is not a complete solution.
- **CH4 Negative acceptance.** Preserve one explicit actual binary adjacency matrix with its full n,r, row degrees and exact shortest-cycle/counted-walk certificate. Weighted, fractional or spectral lists without a realizing actual graph are inadmissible.
- **CH5 Equivalent out-regular reduction.** Deleting arcs to leave exactly r outgoing arcs at each vertex creates no cycle. Thus a complete theorem for every r-out-regular binary graph implies CH0; this does not assume equal indegrees.
- **CH6 Strong connectivity reduction.** A sink strongly connected component of an r-out-regular graph retains all r outgoing arcs per vertex and has at most n vertices. Solving the complete out-regular strong component gives a cycle within ceil(n/r).
