# 发散熵阶下实际 APPT 谱的两尺度归约

本专题保留两份各自独立审读的完整证明：先有增长 m 的归约，再有全维数扩展及更强的固定 m 矩缺口桥。两者不是两个独立重大问题。

| 稿件 | 精确范围 | 完整证明与审读 |
| --- | --- | --- |
| 增长维数的原归约 | m→∞、有限 α→∞，所有 n≥m；不要求 α/m 或 α/D 的关系 | [完整稿](growing-dimensions/PAPER.md)、[独立审读](growing-dimensions/INDEPENDENT_REVIEW.md) |
| 全维数扩展 | 全部实际 2≤m≤n，甚至固定 D，α→∞ 的物理谱归约；显式标杆的相对等价另需 D 与 α 共同趋无限 | [完整稿](all-dimensions/PAPER.md)、[独立审读](all-dimensions/INDEPENDENT_REVIEW.md) |

对实际有序谱 y_i=Dλ_i，保留一个实际峰、主体均值／宽度／权重以及实际弦损失，形成非负量 Z 和 K=1+Z。主体弦损失仍从实际谱计算，不假设主体已经只有两个端点。qubit 的主体从第 2 个特征值开始，峰恰计一次。稿件分别证明相对于最优矩缺口的误差和相对于最优熵缺口的对数误差。

联合 D→∞、有限 α→∞ 时，显式标量标杆 T 给出

    (M−1)/(M*−1)→1  iff  Z/(T−1)→1,
    eα/Eα→1         iff  log(1+Z)/log T→1.

其中 M=D⁻¹Σy_i^α、M* 为实际 APPT 最大值。允许固定、增长或振荡的较小维数。固定 m 的相对矩缺口桥单独证明，不能由旧的相对熵值误差替代。无限阶端点另用精确式 log y₁/log[3D/(D+2)]，不向有限幂矩代入无穷。

[源与审读对应表](OWNER_SOURCE_BINDINGS.json)保留两份证明的独立来源、原始状态文本和各自审核范围。全维数稿明确归功于前稿的核心方法，并复证所需论证。最优值输入沿用既有 G/V/A 与已注明的外部 qubit 分类。

这是保留实际谱函数量的归约及近优判据，不是全正阶的全部主体几何律、任意有限维精确优化态、有效最小阈值、本征基刚性或 APPT=ASEP。
