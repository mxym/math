# A rank-36 same-N18 contradiction from the saturated seed bound

If selected `016,024,228,230,337` all vanish, then the actual oriented number of norm-18 fields at rank 36 must satisfy
```
32,401,736 N18 ≥ 1,161,489,967,988,   hence N18 ≥ 35,848.
```
This is an exact identity after retaining nonnegative charged-unit, angular-atom, marginal, mandatory mark, and extension-compatibility terms, written out and replayed in [the native verifier](norm18_rank36_saturated_seed.py). It uses the established rank-36 absence of all Fano fields (the signed N14 equality term), and the usual original graph normalization N18=2402 U018 in the native averaged chart. It imposes no upper bound on that chart's N18 while deriving the lower.

If U127 is also absent, the [saturated seed packing](norm18-saturated-seed-cap.md) gives actual oriented N18≤35,298 from N16=U127=0. This contradicts the lower on the same labels. No rank-36 support can therefore be contained in **{018,020,026,121,125,226}**. This excludes the four-type candidate {018,020,026,125}; it does not require U121 or U226 to be absent, and does not exclude rank 36 altogether.

After this and the [mixed discriminant comparison](norm18-rank36-mixed-discriminant.md), the sole size-four support not eliminated by the accumulated filters is `{018,020,024,026}`, the four neutral norms 18, 20, 24 and unit 26. This is not the sole remaining rank-36 case: higher-cardinality supports still pass these necessary tests.
