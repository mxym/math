# An unconditional 27-site forbidden configuration

This is an exclusion of one induced configuration, not a solution of the Conway 99 graph question. No automorphism of the graph, global prism closure, rank, or short-shell assumption enters the exclusion. The finite checker is [verify.py](verify.py), SHA-256 5c887d19e82acfffefc15f4132edec7a7954972d97e9fb2888099ca8842369b1. Complete raw per-table output: [Replay.txt](Replay.txt).

**Statement.** An SRG(99,14,1,2) cannot have nine disjoint graph triangles indexed by cells of a three-by-three array such that triangles in different rows and columns are anticomplete, triangles sharing a row or column connect by a perfect matching, and each triple along a row or column forms a nine-site literal rook grid. The 27 sites have internal degree six. Every vertex outside an induced nine-site rook grid has exactly one neighbor in it: the grid already fills every pair's common-neighbor quota internally, so an outsider can have at most one contact, and the grid sends exactly 90 edges to the 90 outsiders. Applying this to the three row grids and to the three column grids gives exactly three contacts for every exterior vertex, in three cells forming a permutation transversal. The two nonattacking cells of a specified transversal have 18 pair common-neighbor slots and six inner witnesses (two intermediate cells each contributing three). Thus each of the six permutation types has 12 vertices. No two vertices can have the identical three-site word since a pair may share at most two neighbors.

**Phase I, marked core and tables.** Relabel the three sites in each of the nine cells. Actual rook grids require the product of each row's three edge matchings to be identity, and likewise each column. Give the sites in each row a common horizontal label so all horizontal edges preserve label. Give each column its own vertical labels. The resulting change-of-labels nine-entry array is considered modulo independent changes of labels in each row/column, so first row/column can be made identity; the four other entries range independently over S3. Permuting the rows/columns, transposition (with inversion), and simultaneous conjugation preserve the marked construction. The checker ranges over the 1,296 gauge matrices, using explicitly described relabelings. Given the 27 simple adjacency bitsets, it rejects excessive internal common neighbors; it enumerates every fully present 9-grid to impose the independent one-contact rule. It does **not** reject any other nonclosing prism. For each permutation p and its three cells of three labels, storage is a 3×3×3 zero-one array with the three pair margins 2 minus inner common neighbors at the two corresponding sites. Enumerate the subsets at each of 9 cells of a two-dimensional marginal, consuming the other pair deficits, requiring every actual grid to have exactly one hit. Only 416 gauge matrices admit six arrays. The five orbit representatives in stored order have multiplicities 108,216,54,36,2. Corresponding numbers of raw table products are 4,36,324,56,64. Relabelings explicitly verified as graph automorphisms of the marked core reduce the 484 tables to 2,21,51,6,6 orbits. No global symmetry of an extension is posited.

**Phase II, exact exterior completions.** For a fixed 72-word table let W_y be exterior y's three-site word and r_y its unknown row of exterior neighbors. Necessarily y is absent from r_y, its size is 11, and no candidate z with two or more shared inner neighbors is adjacent to y. For each core site i, the number of selected words having contact i must be 2−[i∈W_y]−|N_core(i)∩W_y|. The optional-in-principle pruning from the six transversal types follows just by summing two-walks into a cell: all common-neighbor slots from y to that triangle sum to 6−δ, with δ=1 if y hits it, else zero. Its three core-neighbors contribute exactly 2: the other two sites in its own contacted fiber, or one each from its row and column otherwise. The two exterior permutation types p,p' through the cell therefore have neighbor counts n_p+n_p'=4−δ. The nine cells give every opposite-parity pair in S3 exactly once. Thus, if y has type q, n_p equals a single integer v on the opposite parity, and 4−v−[p=q] on q's parity, v∈{0,1,2,3}. The row enumerator loops over these four exhaustive cases, solving the actual 27+6 multicover by branching over *all* subsets containing a rarest still unfilled slot. It consumes negatives only by rejecting and rejects no genuine incidence.

Next choose one row from each of 72 domains. For i≠j impose reciprocity r_i[j]=r_j[i] and |r_i∩r_j|=2−r_i[j]−|W_i∩W_j|. These, the above constraints, and the core table already check every original degree and common-neighbor equation, so a feasible full assignment would realize the SRG. The MRV recursion exhausts every completion. All 86 tables reject with no node/time/depth budget. Only operations on finite integers are used to evaluate constraints; NumPy vectorizes two exact uint64 popcounts, and --audit also calculates every compatibility mask independently with native Python bit_count. Full command: OPENBLAS_NUM_THREADS=1 python3 -B verify.py. Tests on individual tables or congruence shards are supported. Python 3.12.14, NumPy 2.3.5. Fresh unbudgeted four-shard run: 86 exact rejections, 270.7203 process CPU seconds, 70.3344 s longest shard wall. An independent checker compared all 1,296 gauge transformations against site-preserving graph isomorphism; several tables were independently replayed with --audit.
