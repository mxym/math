# Exact classical minimax error for seeded randomness extraction

A public random permutation followed by a balanced partition is **minimax optimal** for strong extraction over any classical source class closed under relabeling the input, with no seed-length restriction. The proof reduces balancing to a convexity inequality for subset masses.

For a flat source of size K and an output alphabet of size D, its exact error is a finite hypergeometric expression. The no-side-information formula extends to any real bound on the largest atom. With classical side information and an average guessing-probability bound, the exact optimum instead is the upper envelope of the flat-source points; two flat sizes suffice. For example, with four input symbols, one output bit and guessing probability at most 1/2, the exact worst-case error is 1/4 with classical side information versus 1/6 without it.

This is a source-oblivious finite minimax theorem, not a seed-length optimization, fixed universality-order theorem, noncommuting quantum converse or evaluation of an actual protocol. It complements the use of balanced hashing in [Regula and Cheng, §IV.5](https://arxiv.org/html/2611.33270v1). It supplements the [existing full-list output-model correction](https://github.com/mxym/math/tree/8b07ee5d6d29575c8d1f27cb76d1c0d7f078f5d9/research/public-seed-list-privacy-amplification) by computing ordinary classical extraction error exactly, without revisiting the list-specific results.
