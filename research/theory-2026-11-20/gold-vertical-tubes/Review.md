# Independent review (21 November 2026 UTC)

The full proof was reviewed without using finite-field experiments as evidence for its infinite bounds. The four-input block count uses the integer identity (b−4)(b−5)≥0; common nonzero zeros of the trace quadratics follow by Boolean parity. The exact threshold uses signed occupancy autocorrelation and the unique assignment of each hole/positive pair to an unordered input difference, then the rank bound on Gold component quadratic forms. In dimension four the sharp 18-point witness was independently checked in `check_sharp16.py` against all 153 pair sums, the two-space orbit count, and all projected derivatives for the exceptional orbit. A clean extraction passed the original manifest and `python3 -O verify.py`.

The July–21 November search checked, in addition to the references in the theorem, [Carlet–Thornburgh, arXiv:2608.23888v2](https://arxiv.org/abs/2608.23888v2) (7 September; crooked functions and ortho-derivatives), [Bellini, arXiv:2611.10269v1](https://arxiv.org/abs/2611.10269v1) (6 November; Walsh projections and CCZ permutability), [Xie–Wang–Wu, arXiv:2610.35372v1](https://arxiv.org/abs/2610.35372v1) (26 October; a Gold-graph uniqueness input to binary code structure), and [the trace-product switching manuscript](https://github.com/KuznetsovKarazin/apn-trace-product-switchings). Those adjacent results do not supply the same extremal bound for **arbitrary** subsets of a full tube. Historical APN maximality, APN distance and 0-extendability concern different questions, as detailed in the proof. Exact keyword/code searches found no duplicate in this repository. This is a bounded search, not a global priority claim.
