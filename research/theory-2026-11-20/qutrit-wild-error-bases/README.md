# 三能级非群型酉误差基的最小投影群

回答 [Svegborn 等人提出的群阶问题](https://arxiv.org/html/2607.16396)：在局部酉等价下允许更换代表，非群型 qutrit 酉误差基的最小投影群阶仍恰好是 27，恰有两个互为复共轭的等价类取到。其一参数族的 36 阶例不能靠更换等价代表降低阶；论文也计算该一参数族的完整群阶公式。对单项矩阵基给出分类，不声称已分类任意三能级误差基。
