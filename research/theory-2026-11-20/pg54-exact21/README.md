# Two extremal configurations of 21 points in PG(5,4)

A set of points is **4-general** if every four are projectively independent. The maximum in PG(5,4) is **21**. Exactly **two** extremal sets exist up to projective linear equivalence; the same two orbits result if field automorphisms are also allowed. One is Pavese's construction. The other has 72 hyperplanes meeting it in nine points, as against 63 for Pavese. Equivalently, no quaternary linear [22,16,≥5] code exists, and the optimum distance of a [22,16] code is **4**. This does not settle the unrestricted binary Sidon problem in dimension 12.

[Lu, Yang, Fu and Song, October 2026, §8](https://arxiv.org/html/2610.03272v1#S8) explicitly ask the 22-point existence and 21-point classification questions. They report a proved range of 21–30 and exclude overlap ≥13 with a fixed Pavese set. Their example outside Pavese's specific parameterized family is not claimed inequivalent under all collineations. [Pavese, Theorem 4.6](https://doi.org/10.1007/s10801-025-01383-w) supplies the known 21-point lower bound. [Grassl's quaternary linear code table](https://www.codetables.de/BKLC/BKLC.php?q=4&n=22&k=16) listed 4–5 at the 20 November 2026 baseline. No prior resolution was found in a search of papers, open-problem listings and the relevant repositories; this statement is not an assertion of independently adjudicated priority.

Read **proof.pdf** or its editable source **proof.tex** for the reduction and exhaustive certificate. Two independently implemented extension algorithms check all 327 branches at each size. Their complete, normalized 21-point outputs agree, including multiplicity. Both produce the empty list for 22. The replay takes a few minutes on a current CPU and needs only GNU C++17 and standard Python 3; there is no solver, external dataset or network requirement.

    bash replay/replay.sh

The generator replaces its small representative tables; the independent labeled-mass pass then certifies their completeness. Log files generated by the two endpoint checks are independently cross-checked against explicitly verified collineations. Finite-field integer coefficients and the encoding are documented in the proof.

**Contents.** `replay/plane.hpp`, `generate.cpp`, `planes.cpp`: projective-frame classification and affine-plane endpoint. `replay/common.hpp`, `census.cpp`, `secants.cpp`: independent orbit masses and secant endpoint with no hyperplane-capacity inequalities. `pg4_7.txt` through `pg4_11.txt`: small representative lists. `extrema21.txt`: the two extremizers; `maps21b.txt`: 26 explicit matrices mapping the full output onto those representatives; `twist.txt`: field-conjugating automorphism for the second. `verify.py`: independent polynomial-arithmetic, rank, spectrum, matrix and branch-completeness checks. `replay.sh`: clean replay driver. `EXPECTED.txt`: recorded successful endpoint. `SHA256SUMS`: archive-content integrity manifest.
