# Twelve-dimensional binary Sidon sets: improved upper bound 78

The unrestricted interval is now **66–78**. The [stability theorem for dimension eleven](../binary-sidon-eleven/exact48/stability47/README.md) proves that every 47-point Sidon set uniquely extends to a 48-point Chen extremizer. The three 47-point affine classes all have fewer than 17 compatible opposite points. Combined with the earlier no-48-section result, this forces any size-79 example to have a 46-point maximum half. The existing 46/29 exclusion and 32 signed integer certificates rule it out. The known 66-point construction is unchanged; the exact maximum and size 78 remain open.

The same work completely classifies binary `[46,35,5]` codes (33 coordinate-permutation classes) and binary `[47,35,6]` codes (three classes). It closes the distance gaps for [binary `[78,66]`](https://www.codetables.de/BKLC/BKLC.php?q=2&n=78&k=66) and [binary `[79,66]`](https://www.codetables.de/BKLC/BKLC.php?q=2&n=79&k=66), whose optimal distances are **4** and **5**, respectively.
