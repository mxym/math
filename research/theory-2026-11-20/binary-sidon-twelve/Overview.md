# Twelve-dimensional binary Sidon sets: improved upper bound 83

The bound is now **66–83** for an unrestricted Sidon subset of F₂¹². A hypothetical size-84 set must have one of three four-layer shapes; all are excluded by 69 integer Fourier-moment certificates. There is no symmetry assumption. The corresponding optimal minimum distance of a binary linear `[83,71]` code is **4** (dimension-12 Sidon nonexistence rules out 5; an affine parity-check column set supplies 4). The exact Sidon maximum is still open.
