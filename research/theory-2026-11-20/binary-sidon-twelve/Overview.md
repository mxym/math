# Twelve-dimensional binary Sidon sets: improved upper bound 81

The unrestricted interval is now **66–81** for the maximum size of a Sidon subset of F₂¹². A size-82 set would have maximum half-section 47 or 48 by exact second/fourth moment bounds and the dimension-eleven theorem. The [unique 48-point section and its opposite extension](../binary-sidon-eleven/exact48/classification/Overview.md) rule out size 48 here. Five exact integer signed Fourier-moment inequalities eliminate the sole remaining layer shape (29,18,18,17) for maximum section 47. No symmetry hypothesis is used. The 66-point lower witness is unchanged, and the exact maximum remains open.

The optimal minimum distance of a binary linear `[81,69]` code is **4**: distance at least five would give 82 Sidon points by adjoining zero to the 81 parity-check columns; [distance four is achievable](https://www.codetables.de/BKLC/BKLC.php?q=2&n=81&k=69). The earlier `[83,71]` distance-four result remains valid.
