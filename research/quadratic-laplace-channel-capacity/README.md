# The scalar Laplace channel under a quadratic input-power constraint

For additive Laplace noise and every power $P>0$, the unique optimum under $\mathbb E X^2\le P$ has a positive density on an interval *and* an atom at either endpoint. Its output has a Gaussian core and exactly exponential tails. The proof gives the capacity in nats, the two laws and a strictly increasing scalar equation determining the support radius. Thus a log-concavity restriction on the input entails a strictly positive loss for each positive power in this channel. No numerical optimization or formal proof system is needed.

Read [the theorem and proof](PROOF.md); [the source note](SOURCES.md) separates the exact computation from qualitative consequences of older results. In particular, this is **not** a determination of the best symmetric log-concave noise. [The review](REVIEW.md) is an independent internal AI check of the frozen proof, not external peer review, and no priority claim is certified.

**Evaluating the formula.** At scale one, set $a=1/(2(R+1))$, $K=\int_0^R e^{-ax^2}\,dx$, and $B=e^{-aR^2}$. Then $A_R=2(K+B)$ and the simpler equivalent power equation is $P=R-K/(K+B)$. Indeed integration by parts gives $\int_0^R x^2e^{-ax^2}\,dx=(K-RB)/(2a)$; the remaining half-line contributes $B(R^2+2R+2)$. Adding these, dividing by $K+B$, and subtracting 2 gives the asserted expression. For prescribed $P>0$ the unique radius therefore lies in $(P,P+1)$. The capacity at this power is $\log(K+B)+a(P+2)-1$. As an example, $R=1$ corresponds to $0.457751153927<P<0.457751153928$.

**Reproduce.** Run `python3 -B -O verify.py` using only the standard library and compare [the log](CHECKS.txt); `sha256sum -c SHA256SUMS` checks the contents. The auxiliary script checks exact polynomial identities for a separate two-tail integration of the dual certificate and six rational Taylor enclosures for the power; the all-power argument is analytic.
