# A non-Gold example for Carlet–Thornburgh Open Problem 5.10

An explicit switched-cube quadratic APN in six variables has an APN exclude parity adjoint. Its ortho-derivative sums to a nonzero value on every affine four-flat. The graph-translation code ranks 1146 and 1102 separate it from the Gold class.

Gold examples already follow from the results in [Carlet–Thornburgh, arXiv:2608.23888v2](https://arxiv.org/html/2608.23888v2). The addition here is a non-Gold example, an exact adjoint polynomial, and reproducible finite certificates. No self-adjointness or new APN equivalence class is claimed.

Run `sh replay.sh` (Python 3.10+, standard library only). The field example is generated from a short formula and needs no datasets. The proof also gives an optional six-dimensional catalogue check using public source data; see [PROOF.md](PROOF.md), [SOURCES.md](SOURCES.md), and [RESULTS.txt](RESULTS.txt).
