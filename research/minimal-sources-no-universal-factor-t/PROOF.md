# One nonlinear gate does not force a factor-t coin overhead

## 1. Statement and resource model

Take integers t≥3 and even n≥2t+2. There are n original input parties, each with its own private bit x_i. Every party receives the same single output

    F_n(x) = x_1 x_2 + Σ_{i=3}^n x_i   over F₂.

We use perfect correctness and static perfect semi-honest privacy over authenticated private pairwise channels. A full coalition view includes its inputs, consumed private coins, received and sent messages with addresses and round numbers, and its outputs. A fixed set of sources can use independent fair private bits, and nobody else can toss any. The number of bits is the worst-case total across inputs and all executions. All polynomials used for sharing are sampled with degree *at most* the indicated bound. There are no pre-shared coins, additional helper parties in the construction, or computational assumptions. For the general string input domains, extend the functionality by reading the first bit (zero if empty) and ignoring the rest; every output is a one-bit string.

Let R_t(F) be the least worst-case fair-bit count of any perfectly t-private protocol for F, and R_t^src(F) the same minimum with at most t fixed source parties. The source choice in R_t^src is part of the protocol, fixed before inputs and executions. The construction below uses D={1,…,t}, so both nonlinear input owners are sources.

**Theorem.** Define s=⌈log₂(n+1)⌉. Then

    F_n has no perfectly (n/2)-private protocol,
    
    R_t(F_n) ≥ (t−2)²/2,

    R_t^src(F_n) ≤ (3t²+3t)s + t·min(n−1,ts).

The upper bound has a deterministic polynomial-time protocol description and an exact polynomial-time coalition simulator. In particular for n=2t², and also for n=2t+2, R_t^src(F_n)/(tR_t(F_n)) tends to zero as t→∞. Thus the common asymptotic lower bound R_t^src(F)≥c t R_t(F) for a universal c>0 on the class stated in Couteau–Rosén Conjecture 13 is false. We do not claim to characterize R_t(F_n) or give a universal compiler for its upper-bound half.

The result is about minimizing over protocol/source placement for each functionality, as in the AICR c/0102 wording. It also defeats a lower bound that is claimed for every functionality at one arbitrary fixed source set: relabel the two nonlinear owners into that set. It does not give the same upper bound for a fixed labelled function at every possible source set, or for a separately defined maximum over placements.

## 2. A self-contained XOR subprotocol on the same sources

For reference, a standard sequential masking protocol computes XOR of n arbitrary input bits u_i with only D={1,…,t} tossing coins. This paragraph and its variants are prior XOR machinery, not the counterexample's novelty.

Source d samples n−1 independent uniform cut bits a^d_j, where 1≤j≤n−1, and fixes a^d_0=a^d_n=0. In a setup round source d privately sends a^d_(i−1)+a^d_i to party i, computing its own value locally. Party i adds the contributions to get r_i. A chain starts at Y_0=0; party i receives Y_(i−1) and sends Y_i=Y_(i−1)+u_i+r_i to the next party for i<n. At the end party n sends Y_n to every other party. Induction gives Y_j=Σ_{i≤j}u_i+Σ_d a^d_j, proving correctness for each tape.

Fix C of size at most t, and let J consist of the internal cuts j=i−1 or i for i∈C. The data of C include the full corrupt source tapes, outgoing packets determined by them, and every individual setup packet from each honest source to C. The adjacent differences in those packets are a linear map B on F₂^J, extended by zero at the two endpoints. Conditional on a given source's packets to C, the honest source's restriction to J is uniform on the corresponding coset of ker B. This follows because its starting projection is uniform and B is linear. Source tapes are independent, so with at least one honest source their combined projected mask is uniform on an affine coset of ker B (the sum of any number of nonempty independent uniform coset laws on the same subspace is uniform on the sum coset). The corrupt sources give fixed shifts. For two XOR inputs agreeing on C and on the final XOR, prefix differences on J belong to ker B: every adjacent difference at a corrupt index is zero, as are both endpoint differences. Thus all observed chain messages, jointly with all setup values and full corrupt tapes, have the same law. All remaining local computations and addresses in the view are deterministic from these data. If all sources are corrupt, C=D because |C|≤t. Then all chain messages seen by C are precisely the prefix cuts 1,…,t, which depend only on the first t inputs and known tapes; the only additional value from the chain is the intended final XOR. This separately proves privacy in that case. A polynomial-time simulator fills any nonempty set of honest slots with bits satisfying the final XOR and runs the protocol, keeping the full view of C.

For a shorter public description of the cut sampler at large n, use K=GF(2^s) and select n−1 distinct nonzero α_j. For each j form the binary column obtained by expanding the t field coordinates

    v_j=(α_j, α_j³, ..., α_j^(2t−1))

in a fixed binary basis of K. Each source takes ts independent bits and forms their binary inner product with each column. Any set of at most 2t distinct columns is F₂-independent: a nonempty subset of size k≤2t summing to zero would have zero sums of all displayed odd powers. Repeated squaring then gives zero sums of all powers 1,…,k, since the odd part of any such exponent is at most 2t−1. The k-by-k matrix with rows of powers 1,…,k at the chosen distinct nonzero points is a Vandermonde matrix times an invertible diagonal. It cannot send the all-one vector to zero. This is the standard binary BCH-column argument. Since |J|≤2t, each source's projection to J has exactly the uniform law used above. In the all-sources-corrupt case only the deterministic formula for chain values was needed. Thus the smaller of the full vector and the BCH sampler uses exactly t·min(n−1,ts) bits, with the same source positions and privacy. For t below the range of this note it is not an optimality claim.

## 3. The multiplication-and-parity protocol

Use the field K=GF(2^s), 2^s>n, with distinct public nonzero points a_1,…,a_n. Fix an F₂-linear functional L:K→F₂ with L(1)=1, for example the constant coefficient in a polynomial basis containing 1. View 0 and 1 as field elements. Fix a set T of t+1 parties for interpolation of degree-t polynomials at zero and its public Lagrange coefficients λ_i for i∈T; other λ_i are zero. Thus for every polynomial R of degree at most t,

    Σ_i λ_i R(a_i)=R(0).

1. **Input sharing.** Party 1 samples a uniform polynomial A of degree at most t with A(0)=x_1. Party 2 independently samples B of degree at most t with B(0)=x_2. Each privately sends its evaluation at a_i to party i, keeping its self-evaluation.
2. **Double-share masks.** Each source d∈D chooses an independent uniform pair (L_d,H_d) of degrees at most t and 2t, with common constant. To sample the pair, take one common uniform constant and all t+2t remaining coefficients independently uniform in K. Source d privately sends each party i its two evaluations. Write R_1=Σ_d L_d and R_2=Σ_d H_d; only their respective local evaluations are computed by parties.
3. **Open the masked polynomial.** Party i sends V(a_i)=A(a_i)B(a_i)−R_2(a_i) to all other parties. Since deg V≤2t<n, the vector of these evaluations uniquely determines V=AB−R_2. Every party can interpolate V(0). Sending the same value over each private channel suffices: no external broadcast channel or randomness is required.
4. **Output without opening the product.** Party i locally forms b_i=L(λ_i R_1(a_i)). It supplies b_i to the XOR subprotocol of Section 2 if i=1,2, and b_i+x_i otherwise. The subprotocol uses fresh independent tapes and the same source set D. All parties receive its result y. They all output y+L(V(0)), keeping the actual field input-sharing values and their b_i local.

Correctness holds for all coins, since Σ_i b_i=L(R_1(0)), V(0)+R_1(0)=x_1x_2, and L acts as identity on the two embedded bits. All public constants, field operations and interpolation can be produced in polynomial time in n. For example, search degree-s monic binary polynomials for an irreducible one by testing divisibility by monic polynomials of degrees at most floor(s/2). This takes polynomial time in n because 2^s≤2(n+1), and the construction is public and deterministic. An exact uniform field element takes s fair bits, with no rejection overhead. Input sharing costs 2ts bits, the double masks cost t(3t+1)s bits, and the XOR phase alone costs t·min(n−1,ts). No other step tosses a coin. The sum is exactly the claimed expression for this chosen sampler, not an expected cost.

## 4. Proof of full-view privacy

Fix C⊆[n], k=|C|≤t. Let E_C denote the vector of evaluations at points a_i for i∈C.

**A. Evaluation fibers.** On degree-at-most-t polynomials with any fixed constant, E_C is surjective onto K^k: interpolate on the k distinct nonzero points and zero, using degree at most k≤t. Hence for an honest input owner's polynomial the evaluations received by C are uniform and have a law independent of that owner's input. The corrupt owner's input and all its sharing coins are known, so its full sends are deterministic given those data.

For each honest masking dealer d, condition on its two separate packets E_C(L_d), E_C(H_d), keeping their full pair, not just aggregate shares. The conditional coefficient law is uniform on a nonempty affine fiber. For any polynomial H of degree at most 2t compatible with that high evaluation packet, the number of compatible L of degree at most t with the prescribed low evaluation packet and L(0)=H(0) is exactly |K|^(t−k). The k+1 constraints are independent by degree-k interpolation; the dimension left in a degree-t coefficient space of dimension t+1 is t−k. This count does not depend on H. Thus the conditional high marginal is precisely uniform over the affine set of degree-at-most-2t polynomials with the fixed evaluations. In particular its constant is not inadvertently fixed by the low packet. The conclusion applies also at k=t, where the count is one.

When conditioning on all corrupt mask tapes and all such honest packets, the honest dealer choices are independent because their original tapes were independent and the conditioning splits by dealer. Their independent uniform high marginals are on cosets of the *same* kernel of E_C in degree ≤2t. If any dealer is honest, their sum plus the fixed corrupt masks is uniform over the affine set of all R_2 compatible with the aggregate high evaluations known at C. This can also be seen by conditioning on every other dealer and using the uniform translated coset from one honest dealer; the resulting coset is the same for every choice of the others with the specified evaluations.

**B. Coalition omits at least one source.** The phase-1 and phase-2 data available to C consist of known inputs, its own tapes and deterministic outgoing traffic, evaluations from honest owners, and each honest dealer's two packets separately. Their law depends only on the corrupt inputs by A and because mask generation is input-independent. Local evaluations at C are then known. Conditional on all these data **and on any full pair A,B of input polynomials consistent with them**, the high mask R_2 remains uniform over its affine high-evaluation fiber. The input-sharing tapes and double-mask tapes were independent. Translation by AB sends that fiber bijectively onto all degree-at-most-2t polynomials V with evaluations

    V(a_i) = A(a_i)B(a_i)−R_2(a_i),     i∈C.

The right side is already known to the coalition. The resulting conditional law of V is the same for every such full A,B, so it also holds without conditioning on A,B. This proves simulation of the entire masked opening, not just its constant. All sent and received packets in the public opening follow from its full evaluation vector.

Next each corrupt participant's XOR input is known from its own x_i when applicable and its low mask packets. The actual result sent by the XOR stage must be y=F_n(x)+L(V(0)), by correctness. Given any fixed complete execution of the first three phases, the XOR stage's tapes are independent and its coalition view law depends only on these known XOR inputs and y, by Section 2. Consequently its conditional law given the simulated first three phases is obtained by the XOR simulator, without knowing the full previous tapes or any honest x_i. In particular the public value y does not reveal the product separately after seeing V. This gives the full joint distribution in this case by conditioning and iterating.

**C. Coalition contains every source.** Then C=D, hence both nonlinear owners' inputs are among the corrupt inputs. Both input polynomial tapes and every double-mask tape are known in C; A,B,R_1,R_2 and the complete opening V are consequently determined by them. There is no appeal to an honest, unknown high mask in this branch. For all phases before the XOR, every packet and intermediate computation in the coalition view is determined by the known data; the sends by deterministic parties during the opening introduce no dependence on their other inputs. As in B, the coalition's XOR inputs are known and the XOR output is exactly the specified F_n(x)+L(V(0)); the XOR simulator works even with all D corrupt. This covers that branch as well.

The preceding simulators are exact. If desired, a single simple polynomial-time simulator takes C, its inputs and the ideal output, fills all unknown bits with arbitrary values except one honest parity input, sets that input to ensure the given output, and runs the full protocol on the completion. Such an honest parity slot always exists because n−2≥2t>t. Equality of views proven above means this procedure gives exactly the target distribution, even for inputs with the same output but different products. It also covers C empty by returning an empty view.

## 5. Two separate lower bounds, and the consequence

**Half-size privacy is impossible.** Fix x_i=0 for i≥3 and divide [n] into two groups of n/2 parties, with party 1 in one group and party 2 in the other. A hypothetical perfectly (n/2)-private F_n protocol gives a perfectly private two-party AND protocol. Each superparty emulates all parties in its group with independent local tapes, and sends only the intergroup messages across the two-party channel. The input and ideal output of each superparty are its one AND input and the common AND result; the complete group view is private under the original guarantee because the group has size n/2 and its other inputs are fixed. The resulting two-party emulation is therefore private against either party.

For completeness, two-party AND with a common output is not perfectly privately computable in this model. After appending the common output to the interparty transcript, identical ideal views for inputs (0,0),(0,1) with first party input zero force equality of those transcript laws; likewise inputs (0,0),(1,0) with second party input zero force equality. Appending the already-known output preserves privacy. For a fixed transcript τ, each party's predicate that its tape and local input yield its dictated messages given the incoming messages of τ depends only on that party's tape and input. Thus Pr[τ|a,b] factors as A_a(τ) B_b(τ). This holds for synchronous rounds as well, and the final appended message has the same property. Take any positive-probability transcript at (0,0) (transcripts are discrete). It ends in output zero and also occurs on (0,1) and (1,0). The positive factors then force it to occur at (1,1), contradicting perfect correctness. This argument excludes n/2-privacy and hence every larger threshold; the contradiction is about ideal functionality feasibility, not an implementation.

**Random-bit lower bound at the target t.** In any perfectly t-private protocol for F_n fix x_1=x_2=0, leaving ordinary XOR of m=n−2 input parties. Emulate the two fixed-input roles inside two distinct remaining participants (say 3 and 4), as follows. Each of these participants runs its own role and the assigned fixed role, keeps independent local tapes for both, and sends messages for both using private channels with fixed labels indicating the original sender and recipient. Messages among roles inside one emulation are local computations. The distribution of the virtual execution is exactly the original protocol with its first two inputs fixed, and the total worst-case random-bit count has not increased. For a coalition of at most t−2 new participants, add to it the emulated roles whose hosts it contains. This gives an old coalition of size at most t. The complete new view is a deterministic projection/relabeling of that old coalition's view, whose inputs on fixed roles are known zeros. Its privacy simulator is therefore inherited, with threshold t−2. All remaining parties output the parity. This transfer, not an assumption that emulation preserves threshold t, supplies an m-input XOR protocol with no additional participants.

Goyal–Ishai–Song ePrint 2022/799 §4.2 Theorem 2 gives at least (t−2)²/2 fair bits for this protocol: m=n−2≥3, 1≤t−2≤m−2, and parity is a nonconstant symmetric Boolean function. Their bound already permits actual helper parties, but the explicit emulation shows the claimed bound without relying on how helper outputs are specified. The cost model is the same worst-case total of consumed independent fair bits. Since every originally allowed protocol for F_n gives this XOR protocol, minimization yields the stated R_t(F_n) lower bound.

Finally, along n=2t² or n=2t+2 we have s=O(log t), so the restricted upper bound and the unrestricted lower bound give

    0 ≤ R_t^src(F_n)/(t R_t(F_n)) ≤ O(log t/t) → 0.

This family meets the conjecture's feasibility hypothesis by the separate half-size reduction. It uses a nonlinear single-bit output and every original participant has a genuine input. In particular the argument does not purport to use pure XOR, which is excluded by the hypothesis, as the counterexample.
