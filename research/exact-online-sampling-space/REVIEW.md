All finite codeword histories from the deterministic start have pointwise nonnegative law-loss because their dyadic path weight is at most the total probability of their output word. The shortest-path potential is bounded on the finite reachable states; appending one edge gives nonnegative slack, and the sum of slacks is the original path loss plus a bounded difference. A reachable closed irreducible class supplies a state with positive Cesaro occupation for every one of its vertices, even if periodic and notwithstanding transient hidden-state bootstrap. Any one positive-slack codeword there would contribute a linearly growing expected sum, so each recurrent internal edge is tight. This reasoning allows infinite support and infinite Shannon entropy because the path-loss expectation never subtracts two infinite quantities.

For a fixed state s in that recurrent class, prefixing one particular positive-probability path from the original start bounds every Q_s(u)/p_u by the same constant, without requiring hidden-state conditional iid. Tightness fixes each path likelihood to p_u times one of finitely many positive endpoint weights. Prefix-decodability at a fixed number of rounds, even with the empty codeword at some states, ensures these path events are disjoint. The uniform likelihood bound therefore bounds their endpoint multiplicities in fixed finite integer ranges. This proves the finite-valued ratio and dyadic-rational Q_s(u). At a word maximizing the ratio the identity as a weighted average over all next symbols forces every positive-probability extension to attain the same value, also for countably many terms. In particular every p_x is rational, and the same maximum word can be extended by arbitrarily many x. A run of |C| such letters contains a repeated state between round boundaries, so its zero-slack cycle gives p_x^k=2^(-m). Rationality and prime factorization imply an integral reciprocal power of two. The sufficiency uses the classical exhaustive code with exactly the dyadic lengths and no persistent storage; ordering lengths nondecreasing makes each successive interval a binary cylinder, with coverage in probability also for countably many positive atoms.
