# 圆分生成函数：最小参数前缀不等式的反例

Billey 与 Swanson 的猜想 33 包含两个命题：按升序排列的分子、分母参数，**最小**的前 k 项与**最大**的后 k 项分别作和，均应由分子占优。本研究针对最小项。2026 年 10 月已有一份未同行评审的稿件给出最大项反例，原合取命题此前即已有反例主张；这里不把那个贡献归给本项目。

[三页完整证明（PDF）](prefix.pdf) · [LaTeX 源码](prefix.tex) · [来源、复核与结论边界](REVIEW.md)

1. **有限反例。** 一个 228 次的基础圆分生成函数有 229 个严格正整数系数，最小九个分子参数的和为 18，分母为 19。两组参数均有 60 项，已约去公共参数。该例恰在第九个前缀失败；不声称次数或参数项数最小。
2. **指定初始系数。** 对每个长度至少为二、首项为 1 的严格正整数序列，存在一个首一圆分多项式乘积，其所有系数严格为正，且初始系数正好是给定序列。允许重复圆分因子和任意次数，不宣称存在单个不可约圆分多项式满足此条件。
3. **定量失效。** 对所有上述正系数基础生成函数及其约简等长参数表，最小 k 项分子和除以分母和的下确界为零。没有与函数及 k 无关的正乘法常数能挽救该不等式。此结论为全称参数的书面论证，不由第一个例子外推。

**复现。** 在本目录执行：

```sh
python3 verify.py > observed.json
diff -u certificate.json observed.json
python3 -O verify.py > observed-optimized.json
diff -u certificate.json observed-optimized.json
```

脚本仅用 Python 标准库；逐项比对短因子的整数卷积与约简参数的整数幂级数递推。两种实现都必须产生同一个 229 项系数表。摘要为各系数的十进制 ASCII 表示按次数升序、半角逗号分隔、无结尾换行的 SHA-256。数学状态为完整书面证明与有限精确证书，另有独立内部重算；未整体 Lean 形式化，也未经外部同行评审。AI 辅助研究；不声明绝对优先权，不作全局重大问题计数或日志以外的发布操作。
