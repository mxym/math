The nine-page preprint proves the common capacity and exact all-rate fidelity
exponent for LO, LOCC and completely PPT postprocessing **after collective
global-unitary preprocessing on the original system**. It uses deterministic
variable-dimension Bell packing. It does not solve ordinary fixed-input
entanglement distillation or remove the global-preprocessing resource.

The complete written proof is public, but it is **not Lean-formalized or
externally peer reviewed**. The Rains SDP and Lami's prior quadratic entropy
converse are explicitly credited; no first-discovery claim is made for the
entropy-deficit bound. No new DOI, arXiv submission, exhaustive priority
certification, or efficient circuit result is asserted.

`PORTABLE_CHECKS.json` records the exact checker and source-corruption tests run
