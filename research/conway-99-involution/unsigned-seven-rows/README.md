# Conway 99 图：二阶对称强制七条正交稀疏记录

假如 Conway 99 图存在，并有一个只固定一个顶点的二阶自同构，其余顶点成对交换。把固定点的邻居做成七对，剩余 84 个顶点做成 42 对。用 42×42 矩阵 $T$ 记录每个外层顶点在另一对中有几个邻居。我们证明，$T$ 必须同时有七条两两正交的整数向量 $x$，满足 $Tx=-4x$。每条恰有七个 $+1$、七个 $-1$，其余为零；每种符号的七个位置内部至多出现两条边，双边按两条计。

这个条件适用于两个带符号模 7 秩分支，不只适用于秩 13。它是必要条件，不代表已排除二阶对称，也不决定整图是否存在。
