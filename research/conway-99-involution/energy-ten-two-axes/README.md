# Two supported axes at folded energy ten: compact replay

Suppose a strongly regular graph with parameters (99,14,1,2) has an involution fixing a single vertex. No integral eigenfunction of eigenvalue −4 which changes sign under that involution has folded squared energy 10 and exactly two supported pairs in the fixed vertex’s neighborhood. Folded energy sums one square per moved pair. The result makes **no** assumption on the rank of an auxiliary matrix. It does **not** rule out folded energy 10 with zero or four supported pairs, all involutions, or the graph.

[Proof.md](Proof.md) gives the reduction. The two possible intersection patterns of the support edge with the axes yield 2,880 and 0 labeled support cores; the 2,880 form one orbit, verified by direct set equality. Enumeration of five remaining axis pairs yields **194** charts. Equivalence between these charts is not assumed: every necessary chart is tested. On each chart, a graph completion must select exactly one of the enumerated incidence styles in each of 34 exterior-orbit groups.

## What is reproducible here?

Run `bash verify_first_layer.sh` in a fresh copy with a C++17 compiler, Python 3, NumPy and SciPy. No optimization library is called. The script checks the input manifest, regenerates the support orbit and 194 charts, reconstructs each chart's integer equations, checks **156** whole-chart separation certificates and the included conditional exclusions of single styles. It names the 38 unresolved-by-this-layer charts. Assertions must be enabled (do not set PYTHONOPTIMIZE).

The other **38** chart exclusions are **not** independently replayable from this compact directory alone. The full offline replay completed: 29 unbranched RUP, 7 pruned or partitioned RUP, 1 unbranched PB-RUP, 1 exhaustive-domain-tree. Its actual transcript is in [FULL_REPLAY_TRANSCRIPT.txt](FULL_REPLAY_TRANSCRIPT.txt); this transcript and checksums are not substitutes for the omitted witnesses. [coverage.json](coverage.json) gives every case-to-proof mapping. [OMITTED_PROOFS.sha256](OMITTED_PROOFS.sha256) lists all **94 missing gzip files** by name and SHA-256. All mathematical models and proof-checker sources are included.

## Full replay or smaller offline shards

[ARCHIVES.txt](ARCHIVES.txt) records exact filenames, byte sizes, SHA-256 and the 38 charts' nine disjoint terminal-certificate batches. The full archive is **239,757,948 bytes**, SHA-256 `31945fe506f234c50042263fcb0be7eef833b4d77611402686c9d3a1569855af`. Each shard contains its own copy of the model and checkers plus proof streams for the specified batch. In a fresh extraction of a shard, run `bash verify.sh 34 80` for shard 1, for example (use the printed list for each other shard). To check all 194 from this compact directory after obtaining the full archive, copy its entire `proofs/` directory here, or restore the union of the nine shards’ `proofs/` directories, and run `bash verify_full_when_restored.sh`. Allow several GB of working disk and substantial CPU time; no solver or network connection is needed. Registration of an archive by digest does not imply that the archive is hosted here.
