# Historical inconclusive spin-alignment reports

These are discovery-only numerical search summaries, not certificates or a
systematic exhaustion. No counterexample was found. Wall-time stopping rules
make the numbers of trials machine-dependent. The interrupted three-qutrit
attempt is not counted. The analytic APPT proofs in the parent directory do not
use these experiments as assumptions. Their purpose here is to record why this
search route was parked instead of being described as a new theorem.
