# Conway 99 图的三阶自同构分支

**计算机辅助定理。** 参数为 $(99,14,1,2)$ 的强正则图没有三阶自同构。推导使用已发表的无不动点定理，以及下文给出程序的有限枚举。这一结论排除的是三阶对称分支。一般的 Conway 99 图存在性问题仍然开放。本研究笔记尚未经外部审稿。

本定理的冻结证明、枚举程序和分批记录见[不可变 release](https://github.com/mxym/math/releases/tag/conway99-order-three-exclusion-v1)及[版本 DOI 10.5281/zenodo.24331664](https://doi.org/10.5281/zenodo.24331664)。

由柯西定理，三阶分支的排除等价于 $3\nmid |\operatorname{Aut}(G)|$。再结合 Behbahani 的素因子限制与 Cesarz–Woldar 关于偶数阶自同构群的定理，剩余的群候选为平凡群和二阶群。[Behbahani，定理 4.14](https://spectrum.library.concordia.ca/id/eprint/976720/) · [Cesarz–Woldar，2025](https://alco.centre-mersenne.org/articles/10.5802/alco.418/)

## 1. 一个必须存在的整数矩阵

设 $g$ 是三阶自同构。Behbahani 的定理 4.14 给出 $g$ 无不动点。于是 99 个顶点分成 33 个等大的轨道。每个轨道在内部诱导三角形或独立集。定义 $B_{ij}$ 为轨道 $i$ 中一个点在轨道 $j$ 的邻点数。$B$ 对称，每行和为 14，且满足

$$
 B^2+B=12I+6J.
$$

将全图邻接矩阵的整数特征多项式约化到 $\mathbb F_3$，它等于 $B$ 的特征多项式的三次方。理由是每个三循环的置换模在 $t-1$ 的三层过滤上都给出同一个轨道商。全图的谱为 $14^1,3^{54},(-4)^{44}$，其中特征值 3 是唯一约化到 0 的值。因此 $B$ 的谱为 $14^1,3^{18},(-4)^{14}$。迹等于 12，故恰有六个三角形轨道。[Crnković–Maksimović，定理 7.1、7.3](https://cdm.ucalgary.ca/article/view/62323) · [商矩阵与特征多项式的详细推导](../../README.md)

三角形的每条边已有一个公共邻点，所以外点最多接触其中一个点。所有非对角项至多为 2，否则一个轨道中的两个点将有至少三个公共邻点。把六个三角形轨道放在前面，有

$$
 B=\begin{pmatrix}2I+C&X\\X^t&Y\end{pmatrix}.
$$

$C$ 是六顶点简单图，$X$ 是 $6\times27$ 的二进制矩阵。$Y$ 对称、对角为零，取值 $0,1,2$。每个独立轨道的完整一行满足 $\sum B_{ij}^2=18$ 和 $\sum B_{ij}=14$，所以恰有两个 2。两个半正定矩阵将用于全程剪枝，

$$
 K_-=9I-3B+J,\qquad K_+=44I+11B-6J.
$$

在全一向量、3-特征空间、$-4$-特征空间上，$K_-$ 分别取 $0,0,21$，$K_+$ 分别取 $0,77,0$。

## 2. 穷尽六行关联

$XX^t=M=6I+6J-5C-C^2$。前篇使用 $K_-$ 的主块与整数分离证书，从 156 个六点图中排除 130 个。余下 26 个代表都有实现 18 个上部点的度数及其两两公共邻点数的显式关联。验证器独立检查 156 个代表的重标号轨道恰好覆盖全部 $2^{15}$ 个六点图。[分类证明与复核数据](../README.md)

对每个剩余 $C$，$X$ 的列 $v$ 是六比特向量。七阶扩充主块的半正定条件见前篇。若 $v_i=v_j=1$ 且 $ij$ 是 $C$ 的边，则 $M_{ij}=1-(C^2)_{ij}$ 必恰为 1。这唯一的外轨道必须给实际匹配边提供公共邻点。因此它在两端三角形中的邻点彼此相邻。若 $C$ 在 $v$ 的支撑中有一个度数至少为 2 的点，该点对应的上部邻点与外点已经有至少两个公共邻点，却又彼此相邻。故允许的支撑在 $C$ 中诱导的最大度数至多为 1。

用 64 个非负整数记录每种列的重数。程序从一个含 27 个空前缀的组出发，逐行添加比特。在一个大小为 $s$ 的相同前缀组中，只需选一个 $n\in\{0,\ldots,s\}$，令 $n$ 列的下一位为 1。每行的总和为 $M_{rr}$，与前面每一行的内积为 $M_{rj}$。可用列前缀及未处理各组所能贡献的上下界均直接由这些条件给出。六行完成后，只保留在 $\operatorname{Aut}(C)$ 作用下重数向量字典序最小的代表。程序同时计算每个代表的稳定子，检查轨道大小之和等于合并前计数。另用 Python 检查输出代表互异，且每一个都满足给定的二阶矩。[列多重集枚举](incidences.cpp)

## 3. 从给定的六行扩充至 33 行

固定一个代表，从已填满的六行及其对称列开始。设 $S$ 为已完成的标签集，$i\notin S$ 是将要填的独立轨道行。对每个 $j\in S$，未填部分必须满足整数等式

$$
 \sum_{k\notin S\cup\{i\}}B_{ik}B_{jk}
 =6-B_{ij}-\sum_{k\in S} B_{ik}B_{jk}.
$$

另有该行还缺的度数、1 和 2 的配额。对任意未填的 $j$，行和及已有的 2 限制 $B_{ij}$，而 $B_{ij}+\sum_{k\in S}B_{ik}B_{jk}\le6$。再以第 4 节的二阶主子式检验候选值。程序优先选择可取值总数最小的行，这只决定顺序。

其余标签按在 $S$ 上的整列以及允许的 $B_{ij}$ 值分组。每组内可以在固定 $S$ 和 $i$ 的同时任意重标号，所以依次尝试这一组中 0、1、2 的每种合法个数即已穷尽。若某个等式的余额为负，或大于剩余组所能贡献的上界，则当前分配无法完成。填完一行后更新主块并递归。到达 33 行时，程序会直接重新检查对称性、全部行和和完整矩阵恒等式，遇到完成矩阵即输出它并中止排除流程。[行枚举](search.cpp)

## 4. 用整数进行半正定剪枝

对 $K_-$ 和 $K_+$ 分别乘以正整数 $2^{16}$。在未填标签中，矩阵的非对角项存为已知整数偏移加上 $B_{ij}$ 的固定整数倍。因此，对于每个候选值，两个主对角项 $r,s$ 和交叉项 $a$ 都可精确取得。半正定要求 $r,s\ge0$ 且 $a^2\le rs$。

填完一行后消去它的主元 $p$。若 $p=0$，该行对未填标签的交叉项必须全零。若 $p>0$，记这些交叉项为 $u_j$。精确的 Schur 补需要减去 $u_ju_k/p$。程序将此商向零截断再相减。对每个除不尽的**非对角**位置 $j,k$，再分别给两个对角项加 1。

这里的取整保持必要性。所得矩阵减去精确 Schur 补，每个非对角误差的绝对值小于 1。对角除法的被除数 $u_j^2$ 非负，其误差非负。补加的对角量覆盖了该行全部非对角误差的绝对值之和，故差矩阵半正定。归纳可知，任何真实完成矩阵都通过所使用的二阶检验。

在 33 阶问题中，初始对角至多 $60\cdot 2^{16}$，每次消元给某对角补加至多 32，消元前的二阶检验还给出 $|u_ju_k/p|\le\sqrt{r_jr_k}$。这把整数偏移的绝对值限制在 $2^{28}$ 以下，即使加入待试边权的系数也在该界内。程序以有符号 64 位整数作乘法。排除过程中没有浮点特征值、数值容差、求解超时或节点数上限。

## 5. 复核与正例

在本目录运行以下命令。复核需要 Python 3.10 或以上及支持 C++17 的编译器。请启用普通 Python 模式以执行断言。并行度可按机器核数调整。可用 `--atlas 53` 等参数单独复核指定核心。

```sh
python3 ../check_cores.py
c++ -std=c++17 -O3 -Wall -Wextra -Wpedantic incidences.cpp -o /tmp/conway-incidences
c++ -std=c++17 -O3 -Wall -Wextra -Wpedantic search.cpp -o /tmp/conway-quotients
python3 verify.py /tmp/conway-incidences /tmp/conway-quotients --jobs 6
```

同一搜索程序先恢复九点网格在对角平移下的三个权 2 轨道对。第二个正例在 $\mathbb F_3^5$ 上用 22 个步长构图，直接检查所有点对，得到参数 $(243,22,1,2)$。取一个非邻接方向的三阶平移，得到 81 个独立轨道。只交给程序前 40 列，其中两个未填轨道对这 40 列的取值完全相同但在完整矩阵里有不同邻接。程序必须补齐其余 41 个标签之间的边并通过完整轨道恒等式。两个正例用于检验实现。非存在结论来自对全部 161,320 个 Conway 输入的穷举，完成矩阵数为零。[复核入口与正例构造](verify.py)
