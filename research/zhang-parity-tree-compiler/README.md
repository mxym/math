# Polynomial-time randomized compilation of shallow parity decision trees

[Zhang, arXiv:2611.03452v1](https://arxiv.org/html/2611.03452v1#S4) gave a parity decision-tree depth bound depending on the binary degree and Fourier norm of a Boolean phase, and left efficient construction open. This note gives a randomized, output-sensitive compiler from a sparse ANF. Given fixed compiler coins, it generates an ordinary deterministic parity tree with polynomial work per output node. It also gives a **compact description of that same tree**: each query or leaf can be generated in polynomial time from its preceding branch labels. An exact sparse Walsh list gives a second input model with an additional correctness guarantee.

* **Sparse ANF input:** given the monomials of the phase polynomial, one tree is simultaneously correct at every input and has Zhang's depth with probability at least \(1-\delta\). Both compilation and each node computation are polynomial in the input length and \(\log(1/\delta)\).
* **Exact sparse Walsh input:** given the nonzero coefficients of the phase, no degree bound or degree oracle is needed. Every compiled tree computes the function, with the depth bound holding with probability at least \(1-\delta\). Only the ANF model can fail correctness on a bad draw.
* **Dense truth-table input:** a fast Walsh transform gives the second model. Explicit tree construction is polynomial in table length. It can be made Las Vegas by checking the depth and resampling, with constant expected repetitions.

The construction samples anchors as low-degree binary polynomials in a **single** variable. A random sample attains the generic contraction rank, to which Zhang's vanishing proof applies. A polynomial-time valuation elimination then returns a binary subspace of the same codimension. Two subset dynamic programs make the contractions accessible from the respective succinct inputs. The shallow depth bound is Zhang's, not an improvement of its degree dependence. This gives a randomized answer to the algorithmic direction, not a deterministic-construction result or a solution of Zhang's other open problems.

Run `sh replay.sh` for deterministic small-instance checks of the contraction evaluations, valuation step, and tree constructions. These checks supplement the mathematical proof.
