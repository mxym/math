# L0-L2: choosing an entropy order for the earliest final APPT bulk onset

New target, 15 October 2026, Asia/Shanghai. Complete ordinary proof required;
K0-K3's independent read does not automatically cover these minimizations.

Let I=[ell,r] be ANY FIXED compact interval with
0<ell<alpha_0<r<infinity. Use the original all-global-unitary APPT density
matrices and the exact integer projection bulk. Define N_alpha(m) as the
minimal FINAL onset for ALL larger integer n, or +infinity if none exists.

L0: Prove a common lower barrier, for every alpha in I and all sufficiently
large m, N_alpha(m)>=d_alpha*m^2-C_I*m. It must use actual feasible states
and actual integer ranks, including alpha=1, not a pointwise asymptotic
silently asserted uniform on I.

L1: Prove the minimum M_I(m)=min_(alpha in I) N_alpha(m) is finite and
attained for sufficiently large m, with closed minimizing sets. Preserve
the infinite all-larger-n definition and allow +infinity for other orders.

L2: With sigma_+>0>sigma_-, A_s from K, and
u_c=(A_--A_+)/(sigma_+-sigma_-), a_c=A_++sigma_+u_c, prove

    M_I(m)=d_0*m^2+a_c*m+O_I(1),

and for EVERY order attaining that actual integer minimum,

    alpha=alpha_0+u_c/m+O_I(m^-2).

For every fixed B>=0 the same O_(I,B)(m^-2) localization must hold for
EVERY alpha with N_alpha(m)<=M_I(m)+B. Do not assume a unique minimizing
order from a strict continuous limiting cusp: integer thresholds can tie.

Not a minimization over all alpha>0 or over m-dependent growing intervals;
no orders approaching zero/infinity, effective cutoff, exact finite N,
unique finite minimizer, new Lean or additional major-conjecture solution.
