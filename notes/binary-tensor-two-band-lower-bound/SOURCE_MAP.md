# Source map

The new theorem in this directory was derived from the binary tensor
framework already published in this repository.

- Parent framework: notes/sharp-binary-tensor-rigidity/paper.md, first
  published in commit af766e707a0d4952a2dc33a37f4cd8e29b30ae11.
- Imported notation: \(d_p\), \(R_p\), \(C_p\), the ordered-contraction
  convention, and the previously proved upper asymptotic constant
  \(2^{-1/2}\).
- Reproved here for standalone checking: the projection-distance identity and
  the binary Gram determinant identity.
- New in this note: the two-band family \(U_p\), its exact projection
  maximum, exact Gram entries, finite-order lower bound, and improved
  asymptotic lower constant.

No OpenAI/math theorem is required for the new lower-bound proof.  This file
records mathematical dependence only and makes no novelty or priority claim.


The later Section 7 finite-band optimality theorem is also new in this note.
It uses only the same binary distance/Gram identities plus a direct
second-variation calculation and an elementary exact profile optimization.
