# Reproduction and verification

Tested on 7 October 2026: Python 3.12.14 (standard library only), Pandoc 3.1.11.1, pdfTeX 3.141592653-2.6-1.40.26 (TeX Live 2025/dev/Debian), kpathsea 6.4.0/dev, Poppler 26.05.0. TeX requires geometry, AMS packages/fonts, xurl, hyperref and the ordinary article class; the upper collection additionally uses lmodern, microtype, fancyhdr, mathtools, mathrsfs and needspace. No download, credentials or network access is used by replay/build/packaging. If an installed Debian TeX tree is unconfigured, build.sh creates its format/font-map cache under build/ from installed distribution files; it installs nothing and writes no system settings.

sh replay.sh runs both Python modes with explicit exception checks and compares the deterministic mathematical reports, certificates and logs. sh build.sh performs a two-pass PDF build with fixed SOURCE_DATE_EPOCH, suppressed PDF dates and a path-independent trailer identifier. paper.txt is the Poppler layout extraction. Exact tested-toolchain bytes are expected to reproduce; another TeX/Pandoc/Poppler version may alter layout or extraction bytes without contradicting the proof.

The source archive excludes itself, all build products and cache files. It includes the reading PDF, source and exact results. Its extraction can be integrity-checked before rebuilding with python3 check_package.py --extracted; replay and build then reproduce the archived results and proof PDF. The publication QA separately renders and visually checks every page. Byte manifests certify bytes and membership only. Analytic proof and independent audit scope are described separately.
