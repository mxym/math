# Fractional-cover rigidity through four logical qubits (finite certificate)

In continuation of [the logical-qubit reduction](THREE.md) the next theorem is computer-assisted (not a general analytical proof). A pure n-qubit state of stabilizer nullity s≤4 flat on all positive-weight bases of a fractional Pauli cover is stabilizer. This implies the same for one spread in arbitrary n, and rules out any measured support of affine dimension ≤4 in a nonstabilizer solution. THREE.md deals separately with s≤3 and justifies the passage to a fractional cover after removing stabilizer qubits. Below assume s=4, no stabilizers, D=16.

**Support and phase parameterization.** Let h be the least support in a positive context. Every support affinely spans four-space, so h≥5. Purity gives h≤floor(17/2)=8. The affine group acts on the seed labels through Cliffords. Fix an affine frame within S and send it to {0,1,2,4,8}, indexing four-bit strings by integers. The routine canonical4 in orbits4.py lists all subsets with this frame and eliminates those equivalent under a frame change. Starting from each representative, for each base point and ordered independent frame directions in that S it computes all 16 affine images and removes the resulting frame-containing set. This is exhaustive because any affine image with the reference frame arises from one such frame. The eight lists in order are explicitly stored in scope4.py and phase4.cpp; scope4.py checks equality with the result of canonical4. There are 1,2,2,3 orbits for h=5,6,7,8, respectively.

Write the seed vector on S as z_x/sqrt(h), |z_x|=1, with z_0=1. Every Hermitian Pauli expectation is a signed sum of equal probabilities in a context containing that Pauli, hence has the form t/j with h≤j≤16, |t|≤j and t≡j mod 2. Pauli expansion of the pure density matrix therefore sends hρ_(x,y)=z_x conjugate(z_y) into (1/B) Z[i] with B=16·lcm(1,…,16)=11,531,520. The exact nonnegative-quadrant circle check in scope4.py enumerates all integers 0≤a≤B, tests b²=B²−a² by integer square root, and verifies the full phase alphabet is
     {i^u A^e C^f : u=0,…,3; e,f=−1,0,1},
     A=(3+4i)/5, C=(5+12i)/13.
It verifies the 36 elements are distinct norm-one points and checks all differences e,f∈[−2,2] to ensure no exponent of magnitude two is also representable with magnitudes ≤1. Thus each exponent, across all z_x, has width at most one. Since z_0=1, it takes either {0,1} or {−1,0} (or just 0).

For each shift a with exactly one unordered pair x,y in S, its Pauli expectation for different choices of b has magnitude (2/h)|Re(z_x conjugate(z_y))| or (2/h)|Im(z_x conjugate(z_y))|. Both types occur, since b·a may be 0 or 1. The finite rational check in scope4.py shows that for each h the only such pair of scaled components from the t/j range on the unit circle is (1,0) or (0,1). Thus the two prime exponents are constant on connected components of the unique-difference graph. Finally, the phase-part u at all four independent frame directions can be made zero by four one-qubit diagonal Clifford S gates (choose independently their powers); the seed 0 phase is already fixed. This conjugates the permissible cover; no specific spread is being held fixed.

**Exact screening (phase4.cpp).** On the components independently choose, for each of the two exponents, a subset of components different from that of zero and a common sign (count the empty subset once). For the other h−5 seed points enumerate u=0,…,3. For each nonzero shift a and phase pattern, the Pauli expectation scaled by 65h, in absolute value, is
    2 |Σ_pairs (−1)^(b·x) comp(65 z_y conjugate(z_x))|,
where comp is Re if b·a=0 and Im otherwise; x is any fixed selected first endpoint of each pair. The harmless global Hermitian sign for the odd case does not matter. Pair values are exact integers since their denominator divides 65. Keep only magnitudes equal to 65h|t|/j for the allowed j,t, and reject a nonzero stabilizer magnitude 65h. Zero shift can safely be omitted at this screening step (failure to reject would only enlarge the final list). Cases with a nonoccurring shift give zero, which is among the allowed expectations since h≤8. Each row's candidate and survivor counts:
    (1,1), (4,4), (4,4), (16,16), (144,16), (64,64),
    (4,161,600,56), (61,504,64).
The total 225 survivors all have e=f=0 (detected, not assumed). The survivor codes printed by phase4.cpp represent (e+1)·12+(f+1)·4+u; 16,…,19 encode ordinary fourth roots. The included list phase4.survivors can be regenerated byte for byte.

**Cover exclusion (cover4.py, sympl.py).** Generate all isotropic subspaces by repeated adjoining of independent commuting labels up to rank four; deduplicate and verify there are 2,295 Lagrangians. For each candidate independently recompute all 256 signed expectations using i^(a·b) X^a Z^b, multiplied by h, with a·b taken mod 2. For each L choose an ordered basis and take its products to obtain the consistent commuting lift: when adjoining (a,b) on the right of (a',b') add the exponent (a·b mod 2)+2(b'·a). Integer inverse Walsh transform gives the 16 probabilities times 16h. All are checked nonnegative and normalized; keep exactly flat contexts with support ≥h.

Each uncovered nonzero label must have total weight one. If no remaining contexts contain a still-uncovered label, this is impossible. If exactly one contains it, that context must have weight one and all other contexts meeting it at a nonzero point must have zero weight. Remove its covered labels and these contexts; repeat. All 225 cases are impossible: 217 give uncovered labels immediately and 8 after one forced context. This exclusion applies to fractional as well as ordinary covers. It does not rely on a numerical LP, tolerances, or failure of a heuristic search.

**Replay (Python 3, NumPy, C++20).** All checks use exact integer operations; the largest matrix entries are bounded by 256 and all sums far below int64. Set the working directory to the folder containing this note, then run:
    python scope4.py
    g++ -O3 -Wall -Wextra -std=c++20 phase4.cpp -o /tmp/phase4-cert
    /tmp/phase4-cert > /tmp/phase4-cert.survivors
    cmp /tmp/phase4-cert.survivors phase4.survivors
    python cover4.py /tmp/phase4-cert.survivors
