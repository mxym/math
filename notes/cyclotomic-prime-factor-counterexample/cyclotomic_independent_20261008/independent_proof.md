# 对 Billey–Swanson Conjecture 48 的独立反例核验

核验日期：2026-10-08（UTC）。

## 结论与范围

多项式

\[
 F(q)=\bigl(\Phi_4(q)\Phi_9(q)\Phi_{25}(q)\Phi_{30}(q)\bigr)^6
\]

确实反驳 Billey–Swanson 的 **Conjecture 48 按已发表文字作出的陈述**。
本核验独立构造多项式，没有读取、导入或执行原候选附带的验证脚本。

## 1. 原文与定义核对

原文：Sara C. Billey and Joshua P. Swanson, *Cyclotomic generating functions*,
Electronic Journal of Combinatorics **31**(4) (2024), #P4.4,
[DOI 10.37236/12687](https://doi.org/10.37236/12687)。

- [期刊 PDF](https://www.combinatorics.org/ojs/index.php/eljc/article/download/v31i4p4/pdf/)：Theorem/Definition 1（印刷第2–3页）、Definition 3（第4页）、Definition 45（第31页）、Conjecture 48（第32页）。
- [arXiv v3 完整原文](https://arxiv.org/html/2305.07620v3#S6.SS1) 对应定义和猜想一致；[arXiv 版本记录](https://arxiv.org/abs/2305.07620) 当前列出的最新版本为 2024-09-13 的 v3。

Definition 1 要求非零、非负整数系数，CGF 可以写成正整数、q 的幂及分圆多项式的乘积。
Definition 3 的 basic 排除前述正整数常量缩放和 q 的幂，等价于相应参数 α=1、β=0。
Definition 45 的 Φ^uni 为其中系数单峰者。
Conjecture 48 断言：若 1≠f∈Φ^uni，则存在素数 p，使 Φ_p(q) 整除 f(q)。

没有不可约、无重因子、非真幂或额外的 primitive 限制。
不可约元素只在相邻 Lemma 46(i) 的生成元讨论中出现，不是本猜想的前提。
Lemma 46(iv) 已证明的是存在 **素数幂阶** 因子 Φ_(p^k)；猜想要求更强的 **素数阶** Φ_p。
因此本例的 Φ_4、Φ_9、Φ_25 符合该引理，却并不满足猜想的结论。

## 2. 明确多项式及其有理表示

分圆多项式由恒等式 q^n−1=∏_(d|n)Φ_d(q) 唯一递归确定。
依次精确整除得到：

\[
\begin{aligned}
\Phi_4(q)&=1+q^2,\\
\Phi_9(q)&=1+q^3+q^6,\\
\Phi_{25}(q)&=1+q^5+q^{10}+q^{15}+q^{20},\\
\Phi_{30}(q)&=1+q-q^3-q^4-q^5+q^7+q^8.
\end{aligned}
\]

令 B(q)=Φ_4(q)Φ_9(q)Φ_25(q)Φ_30(q)。则

\[
 B(q)=\frac{(1-q^4)(1-q^9)(1-q^{25})(1-q^{30})}
 {(1-q)(1-q^6)(1-q^{10})(1-q^{15})}
 =\frac{[4]_q[9]_q[25]_q[30]_q}{[1]_q[6]_q[10]_q[15]_q}.
\]

这里 [m]_q=1+q+⋯+q^(m−1)。该式可通过上列分圆多项式直接相乘并清除分母验证。
B 的次数为 2+6+20+8=36，首项和常数项均为1，所以 F=B^6 次数为216，首项和常数项均为1，且 F≠1。

B 的全部系数（按 q 的升幂排列）为：

```
  0–  7: 1, 1, 1, 1, 0, 0, 1, 1
  8– 15: 1, 0, 0, 0, 1, 2, 1, 1
 16– 23: 1, 1, 2, 1, 1, 1, 1, 2
 24– 31: 1, 0, 0, 0, 1, 1, 1, 0
 32– 36: 0, 1, 1, 1, 1
```

各因子均为回文多项式，因此 q^216 F(q^−1)=F(q)。

其意义是下列完整的多项式恒等式：

\[
\boxed{F(q)=\sum_{i=0}^{108}w_i q^i[217-2i]_q.}
\]

每一项 q^i[217−2i]_q 都在次数 i 到216−i上取系数1，其余位置取0。
因此在 k≤108 时，右侧的 q^k 系数是 ∑_(i=0)^k w_i；在 k≥108 时则由回文性确定。
表中 w_0=1，其余108项全部≥5。
故全部217个 c_k 都是正整数，且

\[
1=c_0<c_1<\cdots<c_{108}>c_{109}>\cdots>c_{216}=1.
\]

特别地，F 严格单峰，唯一峰位于108。作为分圆多项式乘积且系数非负、首项及常数项均为1，F 是非平凡 basic CGF。

### 如何独立核对这张有限表

这不是基于浮点图像的判断。附带程序使用 Python 标准库和整数运算，以三种关系核对全部217个系数：

1. 从 q^n−1 的因式分解递归重建所有 n≤30 的 Φ_n；每次要求整除余数为0；随后整数卷积得到 B，再连乘六次得到 F。
2. 完全另从上节有理式展开。对分母使用 (1−q^m)^−6=∑_(t≥0) binom(t+5,5)q^(mt)，对分子使用 (1−q^m)^6=∑_(t=0)^6 (−1)^t binom(6,t)q^(mt)，取至216次，全部系数与第一种方法一致。
3. 由有理式的对数导数导出下列递推关系，并逐项核对 n=1,…,216：

\[
 c_0=1,\qquad n c_n=6\sum_{j=1}^{n}A_jc_{n-j},
\]

\[
 A_j=\sum_{\substack{m\in\{1,6,10,15\}\\m\mid j}}m
     -\sum_{\substack{m\in\{4,9,25,30\}\\m\mid j}}m.
\]

该递推从 c_0 开始唯一确定每一项；配合附录中全部217项，它也是不依赖任何分圆多项式软件的逐项算术检查方法。
再由这些系数计算 w_i，核对上表，并将右侧109个 q-integer 项展开，逐项等于 F。

注意计数：**109个正权重包括 w_0=1；前半段实际相邻差是108个，最小5。**
不能把109个权重的最小值说成5。

## 4. 对所有素数排除 Φ_p 因子

分圆多项式 Φ_n 在有理数域上不可约，不同 n 的根的精确阶不同，故两两互素。
F 的分圆因式分解已经明确给出，出现的阶只有4、9、25、30，四者均不是素数。
因此对任意素数 p，有 gcd(F,Φ_p)=1，特别地 Φ_p 不整除 F。
也可直接说：F 的每一个根，其精确乘法阶都属于{4,9,25,30}，不可能是素数。
这覆盖所有素数，无需依赖有限计算代替一般证明。

附带程序另外作了冗余的直接检查：若 Φ_p 整除次数216的 F，必须 p−1≤216。
它枚举所有 p≤217 的47个素数，分别以系数按模 p 的次数归并，以及普通多项式长除法计算 F mod Φ_p；每个余式均非零，两种算法逐项相同。
p≥223 时 deg Φ_p≥222>216，因此不能整除 F。

## 5. 结论、校验值与可复现性

由第3节，1≠F∈Φ^uni；由第4节，不存在素数 p 使 Φ_p|F。
这正是 Conjecture 48 已发表陈述的反例。

其他精确校验值：

- F(1)=(2·3·5·1)^6=30^6=729000000，与217个系数之和一致。
- c_108=11434392，是唯一最大值。
- c_107=c_109=11395986，故峰旁差为38406。
- 前半段108个相邻差的最小值为5，出现在 c_1−c_0。
- 原冻结证书 SHA-256 为 64b10e5427ecaaaf9076e5d8b592831393db9fcb2b412c5894fd928d5fd4dfad；仅在以上独立计算完成后才比较，原证书全部217系数、109权重以及47个素数余式均逐项相同。

文件 `independent_verify.py` 可直接用 Python 3 运行，生成 `independent_certificate.json`。
后者包含四个因子、全部系数、全部权重、全部素数余式及上述检查信息。
不需要第三方数学库，不运行原作者的验证脚本。

## 6. 后续文献排查的一个关键区别

2026-03-23 的 [Cyclotomic generating functions, empty weighted complete intersections and positivity](https://arxiv.org/html/2603.22226v1) 摘要说解决 Billey–Swanson 的一个问题，但其 Problem 1.5 明确指原文 Problem 60（HSOP monoid 成员判定），由 Proposition 3.3 处理。不能把这一成果误认成 Conjecture 48 已解决。其他已检查的一手来源和检索范围见来源审计文件。
