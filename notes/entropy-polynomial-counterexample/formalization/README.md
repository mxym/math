# Lean counterexample, including the original real-power definition

The final theorem is `EntropyCounterexample.wakhare_conjecture_two_false_original_real_power`, with no outer hypotheses. It negates the universal two-root assertion using the paper's real-power parameter equation directly, on the positive coprime domain already sufficient to refute Conjecture 2. The proof includes the original finite sums, exact parameter existence/uniqueness, five strict signs, four distinct interior roots and the multiplicity-count inequality.

The [five-module core](source/README.md) and [real-power addendum](realpower-bridge/source/REALPOWER_BRIDGE.md) retain their unchanged authored source snapshots and original archives. The [core independent audit](independent/AUDIT.md) verified five fresh modules, 37 explicit theorems, all 79 owned declarations and a 16,089-declaration empty-kernel closure. The [independent bridge audit](realpower-bridge/independent/AUDIT.md) then verified six additional theorems/owned declarations and an 18,783-declaration empty-kernel closure explicitly containing the new final theorem. Both replays started at trust level zero with no skipped owned roots; the original invalid-proof control was rejected. The bridge audit reused that negative control and the independently fresh core, and did not rerun either. There are 43 explicit theorems and 85 audited owned declarations cumulatively. The two overlapping closure sizes are not summed.

See [REPRODUCING.md](REPRODUCING.md) for exact toolchain/dependency pins, explicit source-build and kernel-check commands, and the boundary between completed independent audits and unexecuted relocated publication instructions. The original run scripts refer to an unbundled sibling cache and are preserved as historical launchers, not advertised as a ready-to-run public wrapper. The public machine records only normalize absolute build-location fields and bind their unchanged original hashes.

The result remains at least four roots, not exactly four, a minimality result or a novelty certificate. It does not refute the entropy inequality or solve Frankl. Standard Lean axioms and the same official Lean kernel remain part of the trust boundary; no independent kernel implementation or full Mathlib rebuild is claimed. No new license or author assignment is made.
