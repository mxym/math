## Reader verification

Obtain the two repository checkouts, or extracted source trees, at the commits above. Run:

    python3 verify_dependencies.py --upstream-root /path/to/openai-math --mxym-root /path/to/mxym-math

The verifier checks repository-relative files against fixed byte counts, SHA-256 hashes, Git blob hashes and source labels. It exits nonzero for missing or altered files. It makes no network requests, writes nothing, and cannot replace expected hashes. Matching files in an extracted tree suffice; a .git directory is not required. Git can additionally be used to inspect the specified commit history.

The external files are not required to compile the PDF. They let readers check the imported hypotheses and their provenance.
