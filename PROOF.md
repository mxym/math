# Symbol incidence and the divisibility of an agreement number

## 1. Definitions and statement

Let \(Q\) be an alphabet of integer size \(q\ge2\). A code \(\mathcal C\subseteq Q^N\) of cardinality \(q^k\) has dimension \(k\) in the cardinality sense; no algebra is assumed on \(Q\) or \(\mathcal C\). Let \(d\) denote the minimum Hamming distance and \(s=N-k+1-d\) the Singleton defect. A length-maximal code in Alderson's terminology satisfies
\[
 N=(s+1)(q+1)+k-2 .
\]
For such a code \(d=(s+1)q\).

**Theorem.**
1. If \(k\ge3\), then \(s\le q-1\), and if \(s\le q-2\) then \(s+2\mid q\). This answers Problem 3 of [Alderson v2, §5](https://arxiv.org/html/2604.03784v2#S5) in its dimension-\(\ge3\) setting.
2. With \(k=4\) and \(s=q-1\), a length-maximal code exists if and only if \(q=2\). This answers the full-weight dimension-four subquestion of Problem 5.

The proof rederives the structural input used from Alderson for completeness, and then gives the additional spectral obstruction.

## 2. Shortening and pair agreements

For \(M\) words of length \(L\) and minimum distance at least \(d\), summing the ordered distances over pairs gives
\[
 M(M-1)d\ \le\ \sum_{\ell=1}^L \left(M^2-\sum_{a\in Q}M_{\ell,a}^2\right)\
 \le\ L M^2(1-1/q),                                                       \tag{1}
\]
where \(M_{\ell,a}\) counts words of symbol \(a\) at position \(\ell\). The last inequality follows from Cauchy–Schwarz. Equality throughout forces constant distinct-pair distance \(d\) and an equal number of occurrences of every symbol in each position.

A shortening fixes a symbol in one position, retains precisely the words with that symbol there, then removes the fixed position. It does not reduce minimum distance or identify any two retained words. Shortening a length-maximal code \(k-2\) times by choosing a most common symbol at each step leaves at least \(q^2\) words of length \(L=(s+1)(q+1)\) and minimum distance \(\ge(s+1)q\). Equation (1) implies \(M\le q^2\) for such a code: after canceling \(M\) and \(s+1>0\), the inequality is \(q(M-1)\le (q^2-1)M/q\). Thus equality holds after these shortenings.

In fact each symbol at each coordinate of the original code is held by exactly \(q^{k-1}\) words. For \(k=2\) this follows from equality in (1). For \(k\ge3\) any slice of size \(>q^{k-1}\) would, by choosing most common symbols for \(k-3\) further shortenings, leave \(>q^2\) words of length \(L\), a contradiction. The slices at a coordinate partition the code, so all attain \(q^{k-1}\). Each first shortening is again length-maximal of dimension \(k-1\) and defect \(s\): it has the requisite number of words and length, and its minimum distance cannot be \(>d\), since another \(k-3\) shortenings would then contradict (1) with at least \(q^2\) words and length \(L\). This also proves that any specified symbols on any two positions occur together in exactly \(q^{k-2}\) words for \(k\ge3\). These facts are the symbol uniformity, shortening and orthogonal-array properties of Alderson Lemma 3.13, Theorem 3.16 and Corollary 3.17.

We can therefore reduce to a size-\(q^3\) shortened code of length \(n=(s+1)(q+1)+1\) at the same \(d\) and \(s\). If two distinct words of this code share any position, shorten in that position at their common symbol. The resulting size-\(q^2\) code is equidistant by (1), so their original distance is \(d\). If they share no position their distance is \(n\). In particular their agreement count is \(0\) or
\[
 h=n-d=s+2,\qquad n=h(q+1)-q.                                             \tag{2}
\]
This is the dimension-three case of Alderson Theorem 3.18.

For a fixed word, by coordinate balance the sum of agreements with all other words is \(n(q^2-1)\). Since the number of other words is \(q^3-1\) and each agreement count is \(\le h\), we get \(n(q^2-1)\le h(q^3-1)\). Substitution of (2) and simplification gives \(h\le q+1\). This recovers the defect cap of Alderson Lemma 3.20.

## 3. Incidence-spectrum lemma and dimension three

Suppose \(M\) distinct words of length \(n\) over \(Q\) have every distinct-pair agreement count divisible by an integer \(h>0\). Form the \(M\)-by-\(nq\) matrix \(B\) with row \(u\) and column \((i,a)\) given by \(\mathbf 1_{\{u_i=a\}}\). For a fixed \(i\), summing its \(q\) symbol columns gives the same all-ones column. The entire column span is therefore generated by the all-ones column and at most \(q-1\) columns from each coordinate, so
\[
 \operatorname{rank} B\le 1+n(q-1).
\]
The diagonal of \(BB^{\mathsf T}\) is \(n\), and its off-diagonal entries are agreement counts. Thus
\[
 BB^{\mathsf T}=n\,\mathrm{Id}+h A
\]
with \(A\) a symmetric integer matrix (and a \(0/1\) adjacency matrix if all the counts are \(0\) or \(h\)). If \(M>1+n(q-1)\), rank-nullity yields a nonzero vector \(v\) with \(B^{\mathsf T}v=0\). Then \(Av=-(n/h)v\). The characteristic polynomial of \(A\) is monic with integer coefficients, so its rational root \(-n/h\) must be an integer. Indeed, if \(a/b\) is a reduced rational root with \(b>0\), multiplication by \(b^{\deg}\) makes \(b\) divide \(a^{\deg}\), forcing \(b=1\). We conclude \(h\mid n\).

For the shortened dimension-three code in §2,
\[
 q^3-\big(1+n(q-1)\big)=(q-1)(q+1)(q+1-h)>0
\]
whenever \(h\le q\). The lemma therefore gives \(h\mid n\), which by (2) is exactly \(h\mid q\). At \(h=q+1\) this rank gap vanishes: the \(q\)-ary simplex code, for prime-power \(q\), realizes the length \(q^2+q+1\) and has \(h=q+1\nmid q\).

For the smallest parameter singled out in Problem 3, \(q=5,s=1\), one would have \(n=13\), \(d=10\), and \(h=3\), contradicting \(3\mid5\). In fact any code of length 13 and minimum distance \(\ge10\) has at most 125 words before using the new obstruction, by applying (1) to each of its five symbol slices on the first coordinate. If it has exactly 125, the preceding equality analysis forces minimum distance 10, and the obstruction excludes it. Thus \(A_5(13,10)\le124\); no exact value is claimed.

The dimension hypothesis is essential. For dimension two and any prime-power \(q\), the affine-line evaluation code on the projective representatives \((1,t)\), \(t\in\mathbb F_q\), and \((0,1)\) is an equidistant \((q+1,q^2,q)_q\) length-maximal code of defect zero. For instance at \(q=3\), \(s+2=2\nmid3\). The dimension-three discussion in the source identifies the intended scope of Problem 3.

## 4. Dimension four at the full-weight boundary

Here \(N=q^2+q+2\), \(d=q^2\), and put \(t=N-d=q+2\). Agreement counts between distinct words lie in \(\{0,1,t\}\): if there is a shared coordinate, shorten there and use the dimension-three agreement counts of §2, adding one for the deleted coordinate. The next calculation rederives the vanishing of the distance-\((N-1)\) class from Alderson Theorem 3.32 and Corollary 3.33(3).

Fix a baseword. Let \(A_i\) be the number of other words agreeing with it at exactly \(i\) positions. The first two factorial moments given by the symbol balances of §2 are
\[
 A_1+t A_t=N(q^3-1),\qquad
 \binom t2 A_t=\binom N2(q^2-1).
\]
The first identity sums per-position agreements; the second sums over unordered pairs of positions, each pair of prescribed symbols occurring in \(q^2\) codewords including the baseword. Thus
\[
 A_1=N\left(q^3-1-\frac{(N-1)(q^2-1)}{t-1}\right)=0
\]
because \(N-1=q^2+q+1\) and \(t-1=q+1\). This holds around every baseword, so every distinct-pair agreement is either \(0\) or \(t\). The gap \(q^4-[1+N(q-1)]=(q-1)(q^3-1)>0\) now lets us use §3 with \(h=t\). Since
\[
 N=(q+2)(q-1)+4,
\]
this requires \(q+2\mid4\), hence \(q=2\). In particular \(q=4,7,10,16,34\) cannot occur.

At \(q=2\), evaluate all affine Boolean functions on \(\mathbb F_2^3\). There are 16 words of length eight, and the difference of two distinct evaluations is either the constant-one word or a nonconstant affine word of weight four. This is the extended binary Hamming code (first-order Reed–Muller code), with distance four, defect one and the required length. It establishes existence at the remaining parameter.
