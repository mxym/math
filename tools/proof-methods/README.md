# 可复用的证明套路

这是一份研究工具手册，不是原创方法或研究成果声明。先找在哪类问题里反复有效，再决定是否值得实现成程序。每条都要写清能证明什么、不能证明什么。

## 1. 把大问题压成少量可核验的局部证书

先选一个可解的基准构造，算清它为什么失效，而不是直接搜完整答案。用对称性、守恒量或剥离把缺陷拆成若干类型，只精确求解这些类型；最后补一条独立的覆盖证明，说明任意参数都落在已核验的类型中。

- **仓库实例：** [十二环的项链分解与局部 Schur 补](../../research/euclidean-tensor-geometry/twelve-cycle-odd-hub/)：基准构造的缺陷按项链分类，二阶修正只需要核验几十维和一百多维的局部矩阵，而不是扫描所有维数。 [非交替切分](https://github.com/mxym/math/releases/tag/periodic-nonalternating-cuts-v1.0.0) 用一个拓扑顺序把可能消项的行列式变成单位三角矩阵。
- **外部参照：** [Mulmuley–Vazirani–Vazirani 的匹配隔离](https://people.eecs.berkeley.edu/~vazirani/pubs/matching.pdf)、[Schwartz 的多项式恒等检验](https://pages.cs.wisc.edu/~cs787-1/Schwartz1980.pdf)。不是同一证明，但都把难算的整体性质换成能核验的非消项证书。
- **工具化：** 把“列出类型”“验证覆盖条件”“检查证书算术”拆成三个接口。未验证覆盖时，输出只对实例有效。有限域非零子式可以证明整数矩阵在特征零上的秩下界；有限域的零结果不能证明特征零上界。支持图有完美匹配也不等于行列式非零，例如全一的 \(2\times2\) 矩阵。

## 2. 用两套语言分别做“能做到”和“不可能更好”

不要只优化一个下界。让下界搜索构造，令上界独立地给每一份资源记账；当两份证书用同一计量单位对上，问题才收束。

- **张量：** 分组或限制给具体下界；[Zhou 的共正约束](https://arxiv.org/html/2610.34273v3#S5.SS3)可以拿来做独立上界。[带悬边的三角形](../../research/euclidean-tensor-geometry/TrianglePendantStarExact.md)正是分组构造和四点上界相遇的例子。
- **组合：** [三元向日葵的有界码度情形](https://github.com/mxym/math/releases/tag/internal-sunflower-global-pair-cap-v1.0.0)中，一边是冲突着色后抽取，另一边是刻意造出难抽取的随机样例；两个方向的机制不同。
- **工具化：** [张量界工具](../tensor-bounds/)已实现分组、路径消元和一种上界路由证书。下一步值得把上界写成通用的精确不等式组合，而不是再加一套只报数值的搜索器。没有找到证书不等于证书不存在。

## 3. 给一类无效操作找守恒量，而不是无限加算例

找出操作无法增加或破坏的量，把“是不是再试几十次就能成”改成对所有操作序列的定理。[五环分组上限](../tensor-bounds/C5-four-party-limit.md)就是一个例子：固定最后如何分组，先做局部限制还是先分组可以交换。因此四方或更少的普通秩证书有统一上限。这只排除方法类，不是原题上界。工具可以要求每种操作附上守恒量及其证明，再把失败原因反馈给候选生成。

## 4. 先按第一次失败收费，再在剩下的结构里抽样

一边剥离不满足阈值的对象，一边把每笔损失记录到触发删除的对象上，防止重复收费。保留下来的核心满足好结构，再做抽样、去冲突和补见证。适用于超图抽取、稀疏结构和其他“局部条件先坏掉”的问题。[向日葵的宽纤维证明](../../research/euclidean-tensor-geometry/InternalSunflowersUniformWideFibers.md)与 [ALWZ 的抽样背景](https://annals.math.princeton.edu/2021/194-3/p05)可作对照。

最常见的错是把剥离前的最小度当成分组后仍成立，或拿已经删除的对象充当内部见证。若预算无法覆盖删除，再调抽样概率通常不能补这个逻辑缺口。

**优先实现顺序：** 先做小证书与覆盖检查，再把构造和上界配对。用不同题做回归：一个能闭合，一个只能缩小区间，一个能严格排除搜索路线。不要用发了多少 release 衡量方法是否有效。
